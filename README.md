## 게임 추가와 관리

게임은 각각 `games/<slug>/` 안에서 독립 실행·관리합니다. 공개 게임 목록은 홈페이지 `index.html`의 게임 영역에서 관리하고, 각 게임의 설명·규칙·실행·검증·저장 정책은 해당 폴더의 `README.md`에 둡니다.

새 게임을 추가할 때는 독립 폴더 생성 → 게임과 README 작성 → 홈페이지에 플레이 링크 등록 → 대상 게임과 이동 경로 검증 순서로 진행합니다. 공통 [작업 안내](AGENTS.md)에는 게임별 목록을 추가하지 않습니다.

게임 수가 늘어나도 검색·의존성 설치·테스트는 작업 대상 폴더로 한정합니다. 홈페이지에서는 게임 코드나 대용량 리소스를 미리 실행·로드하지 않고, 실제 공통 코드 변경 시에만 영향을 받는 게임으로 검증 범위를 넓힙니다.
