# 원본 메시와 색상 변경 아트 기준

2026-10-31 기준. 사용자가 제공한 `Burger Please!` 31.6.0 본체 APK의 정적 추출물에서 선택한 실제 메시를 사용한다. 이전 파스텔 요정 얼굴·머리방울·하트 장식은 제거했다. 원작 전체 렌더러를 복제한 것은 아니며, 색상·웹 좌표 크기와 피벗·운반 피드백·애니메이션은 이 게임에서 적용한다. 세부 파일·원본 해시는 [burger-source/manifest.json](burger-source/manifest.json), 권리·변환 범위는 [SOURCES.md](SOURCES.md)에 기록한다.

## 원본 형상과 색

- 일반 손님은 원작 `customer`의 얼굴 없는 둥근 머리·몸·팔 **196 triangles**를 그대로 사용한다. 많은 손님에게 별도 얼굴·머리 장식을 덧붙이지 않는다.
- 주인공·조수·수호대·적은 원작 `main-Character` **1,274 triangles**와 모자·앞치마 `player_cloth` **566 triangles**를 하나의 스킨 메시에 합친다. 원본 T 자세의 팔은 내려놓은 자세로 변환하고, 원본 가중치를 웹의 8본으로 묶어 기존 걷기·운반·착석·공격에 연결한다. 원작의 애니메이션 클립과 셰이더를 그대로 이식한 것은 아니다.
- 기본 인물 높이 **1.3**, 역할별 배율·전투 카메라 가드는 유지한다. 원작처럼 주인공의 모자·앞치마와 일반 손님의 단색 몸을 구분한다.
- 카운터·그릴·식탁·의자·버거·컵·빈 포장지·돈은 선택한 원본 메시의 면과 정점을 사용한다. 시설은 기존 작업 좌표계에 맞춰 폭·높이·깊이를 정규화하고, 작업대 위 재고는 실제 상판에 배치한다.
- 화덕과 연금 시설은 원본 그릴 옆에 원본 식탁 형상의 출력 선반을 조합한다. 주방도 같은 방식이며, 배식대는 원본 식탁 형상을 사용한다.
- 원작 이미지·아틀라스·UI 로고·음원·코드는 추가하지 않는다. 형상에 단색·층별 정점색을 입혀 역할과 품목만 다르게 읽힌다.

## 색과 명암 구분

파스텔로 씻겨 보이던 바닥의 분홍·민트 혼합을 제거하고 지역 바닥색을 중간 밝기의 중립색과 섞는다. 벽·가구 받침은 어둡게 하고 시설 몸체는 남색/초록, 상판은 밝은 나무·금속색으로 나눈다. 인물·상품의 색은 회색이나 흰색을 더해 연하게 만들지 않는다. 피부는 따뜻한 살구색이며 모자·앞치마의 역할색과 구분한다. 같은 원본 메시·비율·동작을 유지한다.

음식은 황갈색 빵·짙은 갈색 속·초록 층으로 나누고, 장비 버거의 선명한 보라 층과 초록 컵을 구분한다. 식탁의 다리·의자를 어둡게 해 바닥과 구분하고, 사용한 포장지는 진한 갈색으로 표시한다.

행동 원은 흰 운반·선명한 초록 수금·파랑 강화·보라 정리를 쓴다. 각 링과 기호에 어두운 테두리를 같은 geometry 안에 넣어 기존 **4개 인스턴스 배치**를 유지한다. 테두리의 바깥 끝은 실제 행동 반경과 일치하며 다른 위치로 화면 표식을 밀지 않는다. 정점색·원 경계·배치 검사는 실제 화면 명암과 실기기 가독성 검증을 대신하지 않는다.

## 식사와 운반

- 식탁마다 원본 의자 2개를 마주 배치하고 각 좌석의 음식·빈 포장지를 독립적으로 표시한다. 음식이 남은 자리와 정리할 자리를 구분한다.
- 머리 위 운반 기준점은 `cargo-layout.mjs`의 **y 1.4·z 0.14**다. 층 간격은 **장비 0.17·물약 0.31·음식 0.16**을 유지한다. 웹 품목 키 `gear`는 보라 버거, `potion`은 초록 컵, `food`는 따뜻한 색 버거의 원본 형상으로 표시한다.
- 원본 버거·컵을 모바일 적재 크기로 정규화한다. 운반 버거의 폭/높이는 **0.52/0.16**, 컵은 **0.28/0.30**, 음식 버거는 **0.46/0.143**이다. 이는 원본 메시의 모든 런타임 스케일을 복원한 값이 아니다.
- 물건이 새로 도착하면 **340ms 감쇠 반동**을 주며 상단 4층이 차례로 살짝 들렸다 내려앉고 눌린다. 걷는 동안 층별로 기울어지는 대신 좌우 흔들림을 적용한다. 합친 시각 변위는 **0.12 이내**로 제한하고 멈추면 원래 행렬로 돌아간다. 물건을 뺄 때는 새 물건이 착지하는 반동을 발생시키지 않는다.
- 물건은 출발한 층에서 포물선으로 날아와 다음 층에 도착하며, 비행 중 목적지 스택에 중복 표시하지 않는다. 손님은 받은 실제 수량을 앞손 **y 0.65·z 0.35**에 들고, 착석하면 해당 자리의 음식으로 전환한다.
- 반동·포물선·운반 시간은 웹 연출이다. 원작 영상의 전체 타이밍을 추출한 것처럼 기록하지 않는다.

## 실행 예산

- 일반 손님은 **1 draw·196 triangles**, 주인공 등 앞치마 인물은 **1 draw·1,840 triangles·8 bones**다. 직업 모자·전투 무기는 별도 메시다.
- 선택한 원본 메시 11종의 데이터 모듈은 약 **244KB**다. 초기 실행 때 텍스처·GLB·OBJ 파서·Unity 런타임을 읽지 않는다. 변환은 사전에 끝내고 형상·재질·운반 인스턴스 버퍼를 재사용한다.
- 매장 고정 시설은 **7 mesh·5,858 triangles**다. 둥근 요정 장식·새 조명·반사·고해상도 텍스처를 추가하지 않는다.
- 320px·390px 브라우저 확인과 실제 휴대폰 FPS·발열 검증은 구분한다. 정점·면 수, 스택 행렬·충돌·투영 테스트는 실기기 검증을 대신하지 않는다.
