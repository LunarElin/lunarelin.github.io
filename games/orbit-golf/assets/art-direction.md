# 오빗 골프 대형 조우 아트

## 화면과 기술 기준

- 엔진은 저장소의 Three.js 0.160.1 WebGLRenderer를 유지한다. 새로운 엔진·DCC 런타임·텍스처·폰트를 추가하지 않는다.
- 공 뒤의 원근 추적 카메라에서 보이는 실제 3D 모델이다. +Y가 위, +Z가 코스 전방이며 얼굴과 초콜릿 표면은 접근하는 공 쪽인 −Z를 향한다.
- 320×568·390×844 세로 화면과 PC를 대상으로 한다. 대형 조우는 반경 2.25~2.6, 높이 약 4.2~5.5월드이며 폭 20 트랙에 통로를 남긴다. 화면 크기는 거리와 카메라에 따라 변하므로 실제 게임에서 실루엣을 검사한다.
- 소스는 `../encounter-art.mjs`다. 생성 모델의 루트는 바닥 중앙이며, 내부 `encounter-local-rig`의 원점은 물리 충돌 중심 `event.height`다. 장면이 루트를 실제 `eventPose`에 배치하고 회전한다.
- `animateEncounterVisual(group,event,elapsed,hit,dt)`는 내부 부위만 변형한다. 모델 루트를 밀거나 별도 비행 경로를 계산하지 않는다. 절대 경과 시간으로 계산하므로 일시 정지 때 움직임이 누적되지 않는다.

## 공통 시각 체계

- 형태: 둥글고 부피가 큰 몸, 따로 읽히는 팔다리·귀·과자 조각. 작은 기계 장치를 단순 확대하지 않는다.
- 명도: 어두운 남색 코스에 밝은 몸통과 옅은 얼굴을 놓고, 접촉 부위는 중간 명도의 고무·구운 가장자리로 분리한다.
- 팔레트: 남색 `#21384d`, 크림 `#fff8e7`, 동물의 따뜻한 몸 `#d49b78`, 고무 민트 `#60cdbd`, 외계인 보라 `#9e77cf`, 손바닥 민트 `#67d8c0`, 과자 금갈색 `#dba95e`, 초콜릿 `#5c3b2f`.
- 재질: 피부·털은 거칠기 0.68~0.86, 외계인의 부드러운 피부는 0.45~0.48, 고무는 0.38, 과자는 0.82~0.92다. 금속은 작은 팔목 고리에만 제한한다. 색상 텍스처나 구운 조명을 사용하지 않는다.
- 광원: 기존 따뜻한 좌상단 방향광·차가운 가장자리 광·하늘 채움광을 그대로 사용한다. 추가 점광원·그림자 맵을 만들지 않고 정지 물체 아래에 얕은 접촉 그림자를 둔다. 물체가 실제로 날면 그 그림자는 숨긴다.
- 세부 밀도: 눈·주둥이·배 쿠션, 외계인 세 눈과 네 촉수, 과자의 큰 초콜릿 조각·깨질 틈에 집중한다. 읽을 수 없는 작은 문구와 장식은 넣지 않는다.
- 움직임: 동물은 배가 눌리고 발이 벌어지며, 외계인은 팔이 감겼다 풀리고, 과자는 실제 파괴 상태에서 사라져 물리 조각으로 이어진다. 물리 오브젝트가 날거나 뒤집히는 위치는 장면·규칙이 결정한다.

## 가족과 대표 대상

대표 대상은 넓은 주둥이·네 발·둥근 귀·민트색 배 고리를 가진 우주 하마다. 2026-10-28에 사용자에게 위임된 아트 선택에 따라 이 형태를 가족의 기준으로 정했다. 팬더 변형은 같은 부피와 재질 대비를 유지하되 검은 발·눈 패치와 크림 몸으로 구분한다.

| 대상 | 실루엣과 물리 의미 | 상태·변형 |
| --- | --- | --- |
| 우주 하마·팬더 | 폭이 넓은 배 쿠션이 탄성 반발·도약 지점을 보여 준다 | 평상시 작은 호흡, 충돌 시 배 압축·발 벌어짐, 실제 비행 시 발이 들림 |
| 거대 외계인 | 세 눈·네 굵은 촉수·금색 팔목 고리가 옆 던지기와 회전을 예고한다 | 평상시 팔 감기, 충돌 방향으로 팔 풀림, 실제 비행 중 과한 자력 동작 정지 |
| 초콜릿 과자 | 두꺼운 원판·구운 테두리·큰 초콜릿 조각·여섯 갈래 틈 | 파괴 전 약한 흔들림, `event.broken`이면 원판 숨김, 실제 `fragment` 물체를 별도 조각 모델로 표시 |

## 리소스 예산과 소유권

- 하마 25메시·약 9,462삼각형, 팬더 27메시·약 10,254삼각형, 외계인 26메시·약 8,766삼각형이다. 과자는 16메시·약 1,286삼각형, 실제 과자 조각은 3메시·58삼각형이다. 접촉 그림자를 포함한 수치다.
- 표면과 단순 구체·고리는 한 모델 안에서 공유한다. 서로 다른 오브젝트는 GPU 리소스를 공유하지 않으므로 장면의 기존 `disposeObject`로 독립 정리한다. 로컬 모듈에 전역 GPU 캐시는 없다.
- 텍스처는 0개, 스킨 메시와 리깅·애니메이션 믹서는 없다. 부모-자식 관절과 한 번 만든 기하 도형의 변형을 사용한다. 비행 중에도 매 프레임 모델·재질·기하를 새로 만들지 않는다.
- 충돌은 구형·아케이드 프록시를 사용한다. 귀·안테나·꼬리처럼 작은 장식은 프록시 밖으로 약간 나올 수 있다. 장면은 모델 중심과 물리 중심을 일치시켜야 한다.

## 제작·검증 기록

- 새 `create-game-assets`와 `threejs-materials-lighting` 스킬의 실루엣·피벗·재질·예산·출처 검증 절차를 적용했다.
- 기존 Kenney Space Kit를 실제 게임에 계속 사용한다. Kenney Food Kit와 Cube Pets도 우선 검토했지만, 이번의 변형되는 배·촉수·실제 파괴 조각에는 충돌 중심을 맞춘 코드 기반 원본 모델이 적합해 새 팩을 반입하지 않았다. 검토 링크: <https://kenney.nl/assets/food-kit>, <https://kenney.nl/assets/cube-pets>. 이 팩의 파일을 사용했다고 주장하지 않는다.
- 세 모델과 조각은 이 저장소를 위해 작성한 원본 기하 코드다. 외부 모델·이미지·음원·이미지 생성 결과를 복제하지 않았다. 별도 외부 에셋 라이선스나 표시 의무는 발생하지 않는다.
- Node에서 실제 Three.js 객체 생성, 모든 꼭짓점의 유한성, 전체 메시/삼각형 수, 정밀 경계 상자, 충돌 반응 전후 루트 위치 고정, 파괴된 원판 숨김을 검사한다.
- 실제 GPU 화면·모바일 원래 크기의 실루엣·장면 광원 아래 색상은 메인 작업의 브라우저 QA에서 확인한 뒤 manifest의 `native_scale_reviewed`·`in_engine_reviewed`를 갱신한다. 자동 기하 검사만으로 아트가 완성됐다고 처리하지 않는다.

### 공개 빌드 화면 확인 (2026-10-28)

데스크톱 브라우저의 390×844에서 하마의 배 반발과 뒤집힌 비행, 팬더 실루엣, 과자 원판과 파괴 후 실제 조각 비행을 확인했다. 320×568에서는 외계인 세 눈·촉수와 실제 횡투척을 확인했고, 1440×900에서는 팬더·코스·공의 배치를 확인했다. 새 모듈 로드/콘솔 오류는 없었다. 이를 근거로 manifest의 인엔진·원래 표시 크기 검토를 완료 처리했다. 실제 휴대폰 GPU 성능이나 장시간 재미를 승인한 의미는 아니다.

## 감속 위험물 아트 (2026-10-28)

속도를 잃는 위험을 추진 장치와 형태부터 구별한다. 기존 우주 장난감의 광원·거칠기·큰 면을 유지하되, 동물의 둥근 쿠션이나 전진 화살표 대신 **넓고 막힌 단단한 충격면**과 **바닥에 눌러 붙은 오목한 액면**을 각각 대표 형태로 선택했다. 사용자에게 위임된 아트 선택이며 별도 외부 팩·래스터 그림은 필요하지 않다.

| 대상 | 형태·재질·방향 | 충돌 반응·피벗 |
| --- | --- | --- |
| 금속 모루 `anvil` | 플레어 어깨·좁은 허리·무거운 발, 차콜 몸통, 접근 방향 −Z의 넓은 금속 충격면, 큰 호박색/검정 빗금과 눌린 자국 | 실제 `eventPose` 중심 높이 1.6, 반경 1.8. 내부 몸체가 약간 눌리고 충격면이 패이며, 실제 body가 밀릴 때만 모델 전체가 이동한다. 추진 화살표나 발광 포대를 달지 않는다. |
| 끈적 웅덩이 `tar` | 반경 2.35의 넓고 낮은 오목 액면, 밝은 호박색 둑, 검은 점성 가닥·가장자리 방울, 작은 반사광 | 중심 높이 0.16을 유지한다. 내부 가닥이 늘어나고 낮은 방울만 움직이며 웅덩이 루트는 고정이다. 접촉을 소비한 뒤에도 footprint는 남긴다. |

- 새 텍스처·광원·그림자 맵·외부 모델을 추가하지 않는다. 기존 PBR 표면과 키/채움광을 사용하며 차콜 면에 금속 0.3, 충격판에 0.56을 써 환경맵이 없어도 검게 묻히지 않게 한다. 타르는 불투명한 짙은 표면과 거칠기 0.2~0.3의 작은 하이라이트로 점성을 구분한다.
- 모루는 16메시·2,214삼각형, 타르는 13메시·3,366삼각형이다. 도형·재질은 객체 안에서만 공유하고 장면의 기존 정리 경로가 소유한다. 루프 중 기하·재질을 다시 생성하지 않는다.
- 실제 Three.js 기하의 꼭짓점/법선 유한성, 지면 앵커, 액면 법선 방향, 두 실루엣의 높이 차이, 같은 elapsed에서 애니메이션 정지, 루트 transform 보존, 소비된 타르 유지 검사를 통과했다. 새 두 manifest 항목은 실제 공개 브라우저 검토가 끝날 때까지 `native_scale_reviewed`·`in_engine_reviewed`를 false로 둔다. 앞선 다섯 에셋의 기존 검토 상태는 유지한다.

2026-10-29 공개 브라우저에서 모루의 충격면/빗금·실제 낮은 뒤집힘(390×844), 타르의 얕은 검은 액면/호박색 둑·접촉 후 바닥 유지(320×568)를 원래 표시 크기로 검토했다. 실제 속도 급감과 객체 반응이 함께 보였으며 이를 근거로 신규 두 항목의 인엔진/표시 크기 검토를 완료 처리했다. 실제 모바일 GPU 성능 검증은 포함하지 않는다.
