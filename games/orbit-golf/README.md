# 오빗 골프

세워진 햄스터 휠처럼 원통 안쪽을 한 타로 최대한 멀리 도는 싱글 플레이 3D 스페이스 골프다. 공은 수직 원을 따라 돌고, 좌우 조작은 원통 폭 방향의 3개 레인을 바꾼다. 고정된 3/4 시점에서 바닥·천장·내려오는 구간을 함께 본다. 거리에 따라 골드를 모으고 슈트와 공을 강화하면서 최고 기록에 도전한다. Roblox 게임의 이름이나 리소스를 사용하지 않는 독립 게임이다.

## 진입점과 실행

- 공개 경로: `/games/orbit-golf/`
- 로컬 경로: `http://127.0.0.1:8123/games/orbit-golf/`
- 진입 파일: `index.html` → `game.mjs`(입력·HUD·저장·오디오), `scene.mjs`(Three.js 3D 화면), `rules.mjs`(진행·경제·이벤트 규칙).
- 저장소 루트를 정적 서버로 제공한다. 기존 서버·포트를 먼저 확인하고 재사용한다. 새 서버가 필요하면 저장소 루트에서 `node games/orbit-golf/tests/serve.mjs`를 실행한다. 별도 의존성이 없는 이 도우미는 로컬 8123 포트에서 `.mjs`의 JavaScript MIME 타입을 포함해 제공한다. `file://` 직접 열기는 지원하지 않는다.
- WebGL을 지원하는 브라우저가 필요하다. Three.js 0.160.1, 글꼴, 사용 에셋을 게임 폴더에 보관하므로 런타임 패키지 설치와 외부 CDN은 필요 없다. 파일·출처·라이선스는 [assets/ASSETS.md](assets/ASSETS.md)를 참조한다.
- 홈페이지의 게임 링크로 들어가거나 게임 왼쪽 위 홈 버튼(`../../`)으로 돌아간다.

## 플레이와 반복 진행

1. 파일럿 이름을 입력하고 출발한다. 이름은 최대 12자로 정리한다.
2. 타격 버튼을 길게 눌렀다가 놓아 출발 세기를 결정한다. 터치 좌우 버튼 또는 화면 좌우 스와이프로 3개 레인을 오가며 방해물을 피하고 보상을 노린다. PC에서는 스페이스로 타격하고 `←`·`→` 또는 `A`·`D`로 조향하며 `Esc`로 일시 정지한다.
3. 거리는 계속 누적되며 360m마다 같은 휠을 한 바퀴 돈다. 한 바퀴를 돌아도 물리적인 휠은 바뀌지 않는다. UFO·홀인원만 남은 바퀴를 건너뛰어 공간에 떠 있는 다른 휠로 이동시킨다. 공은 마찰과 충돌로 느려지며 멈추면 결과와 획득 골드를 확인한다.
4. 8m당 1G를 얻는다. 동전 이벤트는 12G, 홀인원은 20G를 추가한다. UFO와 홀인원은 다음 트랙으로 즉시 워프하므로 이동한 거리도 보상에 포함된다.
5. 첫 플레이는 **최대 75초의 훈련 비행**이다. 더 일찍 멈출 수도 있으며 훈련에서는 이어 달리기를 제공하지 않는다. 실제로 출발한 첫 비행을 정산하면 훈련 보너스 80G를 주고, 이번 판 총 획득량이 90G보다 적으면 90G까지 더 채워 첫 강화를 할 수 있게 한다. 이 보너스는 한 번만 지급한다.
6. 훈련 이후 일반 비행은 **최대 120초**다. 두 시간 제한은 일시 정지·숨김 시간을 제외한 실제 플레이 시간 기준이다. 시간 제한 전에 멈췄다면 한 판에 **딱 한 번, 40G**를 내고 그 위치에서 이어 달릴 수 있다. 이번 판 골드도 비용에 사용할 수 있다. 거리·보상·남은 비행 시간은 유지하며 이미 받은 골드는 중복 지급하지 않는다. 시간이 끝난 판은 이어 달릴 수 없다.
7. 첫 결과에서 강화하고 다음 비행의 기록 목표를 확인한다. 슈트는 장애물 감속을 단계당 8% 줄이고, 골프공은 출발 속도를 단계당 7 높이며 마찰을 줄인다. 둘 다 5단계까지 강화한다. 첫 비용은 각각 70G·90G이고 이후 표시된 비용이 증가한다. 기본 타격 속도는 기존과 같으며, 타격 세기와 강화로 다음 비행의 도달 거리를 늘린다.

혜성·우주인·중력 함정은 같은 레인을 통과할 때 감속시킨다. 매 바퀴의 이벤트 6개 중 이 세 장애물이 각각 하나씩 나온다. 나머지는 동전, 가속 패드, 무작위 보상 하나다. 추가 무작위 보상은 25% 확률로 UFO 또는 홀인원, 그 외에는 동전이므로 워프가 매 바퀴 보장되지는 않는다. 첫 이벤트는 60~68m, 다음 이벤트는 약 55m 간격이며 종류의 순서와 레인은 무작위다. 보상도 같은 레인을 타야 얻는다. 워프는 속도를 최소 65로 보정하며 최고 출발 속도로 되돌리지는 않는다. 일시 정지 후 계속·재시작과 소리 전환은 화면 버튼으로 조작한다.

## 기록과 저장

- 키: `orbit-golf:v1`. 이름, 보유 골드, 강화 단계, 이 브라우저의 랭킹과 훈련 완료 여부(`tutorialComplete`)를 `localStorage`에 저장한다. 진행 중인 비행 자체는 저장하지 않는다.
- 랭킹은 같은 이름의 최고 거리만 남겨 최대 10명을 표시한다. 대소문자만 다른 영문 이름은 같은 이름으로 취급한다. 서버와 계정이 없는 **기기·브라우저별 로컬 랭킹**이며 온라인 통합 순위가 아니다.
- 이름의 제어 문자·태그 기호를 제거하고, 저장 데이터의 숫자·강화 범위·랭킹을 정리한다. 손상되거나 읽을 수 없는 저장은 기본 프로필로 처리한다. 저장 기능이 차단되거나 용량이 부족하면 경고하고 해당 방문의 메모리로 플레이를 유지한다. 사이트 데이터를 삭제하면 기록도 사라진다.
- 기존 v1 저장의 골드·강화·랭킹은 유지한다. 훈련 완료 필드가 없는 기존 저장은 훈련을 한 번 진행하고 새 필드를 저장한다. 이름을 바꿔도 훈련을 반복 지급하지 않는다. 이후 저장 형식을 바꿀 때는 별도 버전 키와 명시적 마이그레이션 또는 초기화 정책이 필요하다. 다른 게임의 저장 키를 읽거나 변경하지 않는다.
- 탭이 숨겨지면 진행을 멈추고, 돌아왔을 때 숨겨진 시간을 거리로 적립하지 않는다. 페이지 이탈 시 렌더링·이벤트·오디오 자원을 정리한다.

## 검증

저장소 루트에서 대상 파일만 검사한다.

```powershell
node --check games/orbit-golf/game.mjs
node --check games/orbit-golf/scene.mjs
node --check games/orbit-golf/rules.mjs
node --test games/orbit-golf/tests/rules.test.mjs
node --test games/orbit-golf/tests/scene.test.mjs
git diff --check -- games/orbit-golf index.html
```

규칙 테스트는 타격·레인·장애물 구성·거리 보상·강화·휠과 바퀴의 구분·훈련 및 일반 비행의 시간 제한·첫 강화 보너스·한 번 이어 달리기·정산·로컬 랭킹·저장 데이터 호환을 다룬다. `scene.test.mjs`는 실제 Three.js 좌표·카메라 계산으로 수직 휠과 레인 배치, 공의 화면 노출, 새 판 이벤트 교체와 다른 휠 이동을 검사하며 GPU 렌더링 검증은 아니다. 두 검사는 별도 설치 없이 실행한다.

화면 연결 통합 검사는 `tests/`의 개발 의존성 **jsdom 26.1.0**을 사용한다. `pnpm-lock.yaml`에 맞춰 이 폴더에만 설치한다. Node.js 20 이상과 pnpm을 사용한다.

```powershell
pnpm --dir games/orbit-golf/tests install --frozen-lockfile
node --experimental-vm-modules --test games/orbit-golf/tests/rules.test.mjs games/orbit-golf/tests/scene.test.mjs games/orbit-golf/tests/integration.test.mjs
```

통합 검사는 실제 `game.mjs`·`rules.mjs`를 실행하고 3D 화면만 대역으로 바꾼다. 이름·포인터 입력·첫 훈련 완료와 강화 후 다음 비행·낮은 프레임률에서의 실제 플레이 시간·정산·이어하기·랭킹·저장 실패·기존 저장 호환·탭 복귀·종료 정리를 검증하며 화면 배치·터치 실기기·WebGL 성능은 포함하지 않는다. jsdom과 테스트 의존성은 실제 게임에서 로드하지 않는다.

화면을 바꾸면 실제 브라우저의 PC 및 320~390px 세로 화면에서 직접 진입, 이름 입력, 터치 타격·조향·일시 정지·재시작, 결과 정산과 강화, 홈 왕복을 확인한다. 작은 화면의 글씨·잘림·44px 이상 터치 영역, 주소창에 따른 높이 변화, 안전 영역, 탭 복귀, 새로고침 후 저장 복원도 확인한다. 브라우저 에뮬레이션과 실제 iOS Safari·Android Chrome 기기 검증은 구분해 보고하며, 규칙 테스트 통과를 실기기 성능이나 재미 검증으로 간주하지 않는다.
