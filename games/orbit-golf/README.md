# 오빗 골프

매번 다른 높낮이의 일자 우주 트랙에 공을 날려 최대한 멀리 보내는 싱글 플레이 3D 물리 골프다. 폭 20월드 단위에서 공과 맞은 물체가 자유롭게 튀고 연쇄 충돌한다. 뒤에서 공을 따라가는 카메라는 수평을 유지한다. 360° 루프와 루프 카메라는 제거했다.

## 진입과 실행

- 공개 경로: `/games/orbit-golf/`, 홈 복귀: `../../`.
- 진입 파일: `index.html` → `game.mjs`(입력·HUD·저장·오디오), `scene.mjs`(Three.js), `rules.mjs`(물리·진행·경제), `course.mjs`(공유 지형), `encounter-art.mjs`(대형 조우 모델·반응).
- 저장소 루트를 정적 서버로 제공한다. 기존 서버를 확인해 재사용한다. 필요할 때 루트에서 `node games/orbit-golf/tests/serve.mjs`를 실행하면 `http://127.0.0.1:8123/games/orbit-golf/`에서 실행된다. `.mjs`의 JavaScript MIME 타입이 필요하며 `file://`는 지원하지 않는다.
- WebGL 및 로컬 Three.js 0.160.1을 사용한다. GLTF 로더·폰트·사용 에셋도 로컬이며 런타임 설치나 외부 CDN은 없다.
- HTML·스타일·런타임 모듈의 `?v=…`를 함께 갱신한다. `scene.mjs`의 새 아트 모듈까지 같은 배포 버전을 쓴다.
- 카메라 구도 참고: Super Golf! 영상 [best hole in1](https://medal.tv/ko/games/roblox/clips/nxPbWofUkDMzZ1ns3), [DUDE WHATTT](https://medal.tv/ko/games/roblox/clips/nvDTNnNMVLt-JlOFj). 영상·모델·음원을 복제하지 않은 독립 게임이다.

## 매 판 다른 길과 조우

- 새 판마다 생성한 32비트 시드가 지형·장치 위치·기믹 해금 순서를 함께 결정한다. 같은 판의 재타격·이어하기는 같은 코스를 사용하고, 결과에서 새 판을 시작하면 새 시드를 만든다.
- 일자 전방축은 계속 증가하며 좌우 굽이·뒤집힘·360° 회전은 없다. 360m 구간마다 긴 내리막·큰 언덕·깊은 골짜기·연속 언덕·계단 고원·넓은 고원·골짜기와 오르막·완만한 고개 중 하나를 섞는다. 인접한 같은 유형을 피하고, 높이·굴곡 위치·내부 오르내림 구간의 길이도 시드별로 바꾼다.
- 높이·경사·경사 변화율은 구간 경계에서 연결된다. 기울기는 −0.32~+0.26이며 처음 60m는 완만한 도입부다. 전체적으로 낮아지되 중간 오르막에서는 실제 전진 속도를 잃는다. 물리와 지형 메시가 같은 시드·높이·미분값을 사용한다.
- 충돌 묶음은 개수·간격·배열·장치 종류와 여백이 달라진다. 첫 구간은 반발/도약을 먼저 보여 준 뒤 126~168m에 큰 조우를 배치한다. 작은 장치를 같은 간격으로 반복하는 고정 격자를 쓰지 않는다.
- 2번째 구간부터 기믹 묶음을 하나씩, 매 5번째에는 3개씩 추가한다. 이동 범퍼·공중 연속 도약·교차 회전·반발 연쇄·횡단 혜성·가속 도약·제동/재추진·쌍 추진 포대·동물 볼링·촉수 투척·과자 도미노 11종의 순서를 시드로 섞는다. 최근 8묶음만 유지하고 이후에는 보조 장치를 더한 변형으로 교체한다.

## 타격·속도·연쇄 물리

1. 최대 12자의 이름을 입력하고 발사각을 정한다. 타격 버튼을 길게 눌렀다 초록 구간에서 놓으면 최대 세기다. 날아가는 동안 터치 슬라이더로 스핀을 줄 수 있다. 손을 놓거나 입력이 취소되면 중립이 된다. PC는 스페이스 타격, 좌우 방향키/A/D 스핀, Esc 일시 정지다.
2. 공은 앞뒤 위치/속도, 좌우 위치/속도, 높이/수직 속도를 가진다. 세 칸 레인이나 목표 위치로 자동 이동하지 않는다. 공 중심은 좌우 약 ±8.85까지 움직이고 옆벽에서 반사된다. 뒤로 튀면 실제로 후진하며 최고 도달 거리만 보상에 쓴다.
3. `run.speed`가 유일한 실제 부호 있는 전진 속도다. `rollSpeed`는 양의 전진 속도를 읽는 호환 값이며 공을 재가속하지 않는다. 경사·마찰·충돌·착지가 연속적으로 속도를 바꾸며 숨은 목표 속도로 복구하거나 자동 모터를 적용하지 않는다.
4. 수동 스핀은 남은 실제 전진 운동에 비례한 약한 횡방향 개입이다. 전진 속도 절댓값 1.4 미만이 0.55초 이어지면 좌우 운동·공중 높이·계속 누르는 스핀과 관계없이 자연 종료한다. 종료와 이어하기에서 이전 스핀 입력·회전력을 정리한다.
5. 물리 적분은 내부 1/120초 간격이다. 수동 물체의 반발 계수는 최대 0.98이며 수평 에너지를 중복 생성하지 않는다. 공/움직이는 물체는 유한 질량 충격량을 교환한다. 주황 추진기·초록 패드·표시된 대형 능동 효과만 제한된 추진을 더하며 빠를수록 추가량이 줄어든다.
6. 날아간 장치는 중력·트랙·옆벽·다른 장치·공과 실제 충돌한다. 출발/대상 ID, 실제 접촉 위치, 힘과 연쇄 깊이가 반응에 연결된다. 활성 물체·수명·접촉 빈도·연쇄 깊이·입자 수를 제한하고 워프 뒤의 물체는 정리한다. 과자 조각의 총 질량도 원본 예산을 나눠 쓴다. 범용 강체 엔진이 아닌 넓은 코스용 아케이드 모델이다.
7. 카메라는 공 뒤에서 따라가며 회전·강한 흔들림을 쓰지 않는다. 원점 이동으로 먼 거리의 좌표 정밀도를 보존한다. 모션 감소 설정에서는 잔상·시야각 변화도 줄인다.

## 수문장

10번째 구간 끝 3,570m에 전폭 20·높이 10인 관문이 나타나며 이후 10구간마다 다시 나타난다. 앞 100m는 일반 장치를 비워 예고한다. 필요 힘은 170에서 시작해 이후 24씩 증가하고 최대 300이다. 실제 양의 전진 속도 × `(1 + 공 단계 × 0.2)`가 충분하면 40G를 한 번 받고 갑옷을 부수며 통과한다. 부족하면 실제 반발과 속도 손실로 막힌다. 좌우 스핀·점프·워프로 우회할 수 없다. 파괴 상태는 캐시 재생성·후진·이어하기에도 유지된다.

## 성장과 반복

- 최고 도달 거리 8m당 1G와 물체 보상을 얻는다. 첫 훈련은 최대 75초다. 자연 정지/시간 종료 시 최초 80G 보너스를 주고 총 획득량을 최소 90G로 맞춰 첫 공 강화를 살 수 있게 한다. 훈련은 이어하기가 없으며 발사 전 취소나 임의 중단에는 훈련 보너스를 주지 않는다.
- 일반 판은 최대 120초다. 시간 전에 멈춘 판에서 딱 한 번 40G로 같은 위치에서 이어 칠 수 있다. 남은 시간·지형·거리·보상은 유지한다. 이번 판 골드도 비용에 쓸 수 있다. 시간 종료 후에는 이어 칠 수 없다.
- 공·슈트는 각각 5단계다. 첫 비용은 공 90G·슈트 70G다. 공은 단계마다 발사 속도 ×1.4·마찰 ×0.92, 충돌 질량 `1 + 공 단계 ×2.8 + 슈트 단계 ×0.08`이다. 기본 충돌 보존율은 Lv0 85%→Lv1 97%, 최대 99%이며 제동 패드 보존율도 강화한다. 추가 추진은 기본 발사 속도 ×1.25에 가까울수록 줄지만 이미 가진 속도를 이 수치로 복구/절삭하지 않는다.
- 강화 화면의 기준 비거리는 물체 없는 평지 풀샷 비교값이다. 실제 비거리는 경사·충돌·운에 따라 달라지며 모든 판에서 증가를 보장하지 않는다. 첫 결과는 강화→다음 타격으로 이어진다.

최종 2026-10-28 새 지형/조우의 600회 비교: 일반 판, 시드 1~100, 공 6단계, 풀샷·각도 8°·무조작·호출 0.2초/내부 1/120초. 첫 강화의 같은 시드 거리 비율 중앙값은 **2.95배**, **96/100쌍**이 더 멀리, 82쌍은 1.45배 이상 갔다. 이후 단계의 거리 중앙값도 각각 25% 이상 증가했다. 연쇄는 기본 공 95/100판, 강화 공 각 100/100판에서 발생했다. 이 측정은 재미·브라우저 FPS·실기기 검증이 아니다.

## 기록·저장·QA

- 키 `orbit-golf:v1`: 이름·골드·공/슈트 단계·이 기기 TOP 10·훈련 완료 여부. 진행 중인 물리 상태는 저장하지 않는다. 같은 이름의 최고 기록만 보관하고 영문 대소문자를 구분하지 않는다. 서버 공용 랭킹은 없다.
- 기존 v1의 지갑·장비·기록은 보존한다. 훈련 필드가 없으면 한 번 훈련한다. 이전 물리의 기록도 보존하므로 난이도가 완전히 같지는 않다. 손상/차단/용량 초과 시 경고하며 메모리 플레이를 유지한다. 이름 변경으로 훈련 보너스를 반복 지급하지 않는다.
- 숨긴 탭은 진행·입력을 멈추고 복귀 후 계속 버튼으로 재개한다. 숨김 시간은 적립하지 않는다. 이탈 시 렌더링·리스너·오디오를 정리한다. 다른 게임 저장은 건드리지 않는다.
- `?preview=1`: 기존 저장을 읽거나 쓰지 않는 메모리 QA. 새로고침 시 초기화된다. `&seed=42`로 0~4294967295의 고정 시드를 지정할 수 있다. 일반 판의 `seed`/`encounter` 파라미터는 무시한다.
- `?preview=1&seed=42&encounter=beast` / `giant-alien` / `cookie`: 실제 생성된 해당 대상을 첫 12구간에서 찾아 36m 전·공 Lv1·각도 0°로 준비한다. 실제 물리·주변 장치를 그대로 쓰며 타격 세기는 사용자가 정한다. 자연 도달한 플레이와 구분하는 통제된 충돌 검사다.
- `?preview=1&encounter=guardian-weak` / `guardian-strong`: 3,510m에서 각각 공 Lv0/Lv2로 실제 수문장을 검사한다. 별도 약화 물체를 만들지 않는다.

## 검증

```powershell
node --check games/orbit-golf/game.mjs
node --check games/orbit-golf/scene.mjs
node --check games/orbit-golf/rules.mjs
node --check games/orbit-golf/course.mjs
node --check games/orbit-golf/encounter-art.mjs
node --test games/orbit-golf/tests/rules.test.mjs
node --test games/orbit-golf/tests/course.test.mjs games/orbit-golf/tests/scene.test.mjs games/orbit-golf/tests/encounter-art.test.mjs
node --experimental-vm-modules --test --test-concurrency=1 games/orbit-golf/tests/integration.test.mjs
git diff --check -- games/orbit-golf
```

규칙 검사는 새 배치의 재현성/변화·대형 효과 차이·실제 과자 조각/질량/보상·연쇄·수문장·스핀 종료·에너지와 숨은 재가속 방지·시간 제한·성장·저장 호환을 다룬다. 600회 성장은 테스트 전용 `worker_threads`/`balance-worker.mjs`로 25시드씩 최대 6worker에 나눠 실행한다. 측정 조건·첫 강화/후속 성장 판정 기준은 고정한다.

지형 검사는 다양한 시드·먼 좌표의 연속 높이/미분·전방축/바닥의 비반전·패턴 변화를 확인한다. 장면 검사는 실제 Three.js 좌표/투영·카메라 가림·실제 물체/대형 아트 피벗·정지/정리·지형 메시 재사용을 확인하며 GPU 검증과 구분한다. 아트 검사는 메시/삼각형 예산·유한성·로컬 반응·깨진 원판/조각 표시를 확인한다.

통합 검사는 실제 컨트롤러/규칙을 쓰고 3D 화면만 대역으로 바꾼다. 새 판 시드·지형 HUD·3종 실제 대형 충돌 QA·수문장·타격/스핀·훈련/강화·한 번 이어하기·저장 실패·탭 복귀·이탈 정리를 확인한다. jsdom 26.1.0만 테스트 폴더의 개발 의존성이다. 필요할 때 Node20+와 `pnpm --dir games/orbit-golf/tests install --frozen-lockfile`로 설치한다. 게임에서는 로드하지 않는다.

실제 브라우저에서 PC·320/390px 세로 화면의 직접 진입·홈 왕복·터치 타격/스핀/일시 정지/재시작·모듈/폰트·줄바꿈·44px 영역과 동적 높이를 별도로 확인한다. 데스크톱 모바일 에뮬레이션과 실제 iOS Safari/Android Chrome 하드웨어를 구분해 보고하며, 자동 검사로 장시간 재미나 실기기 FPS를 단정하지 않는다.
