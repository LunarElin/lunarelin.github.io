# 오빗 골프

수직으로 세워진 우주 쳇바퀴 안쪽에 공을 날려 최대한 멀리 보내는 싱글 플레이 3D 물리 골프다. 폭 20월드 단위의 넓은 트랙에서 공이 자유롭게 움직이고, 맞은 장애물도 날아가 다른 장애물과 부딪힌다. 공·장애물의 반사와 점프가 이어지는 코믹한 연쇄를 보고, 필요할 때 스핀으로 조금 개입한다. 카메라는 실제 공의 위치와 높이를 뒤에서 따라간다. 천장을 지날 때도 휠 표면을 기준으로 화면의 위쪽 방향을 회전시킨다. 휠 전체를 보는 시점은 대기실에서 사용한다.

카메라 구도 참고: Super Golf! 플레이 영상 [「best hole in1」, eanee33](https://medal.tv/ko/games/roblox/clips/nxPbWofUkDMzZ1ns3), [「DUDE WHATTT」, ughpav](https://medal.tv/ko/games/roblox/clips/nvDTNnNMVLt-JlOFj). 독립 게임이며 영상·모델·음원을 복사해 사용하지 않는다. 실제 사용 에셋과 라이선스는 [assets/ASSETS.md](assets/ASSETS.md)에 기록한다.

## 진입점과 실행

- 공개 경로: `/games/orbit-golf/`
- 로컬 경로: `http://127.0.0.1:8123/games/orbit-golf/`
- 저장 없는 QA 경로: `/games/orbit-golf/?preview=1`. 기존 저장을 읽거나 쓰지 않고 새 프로필을 메모리에서 시작한다. 새로고침하면 QA 진행은 초기화된다.
- 진입 파일: `index.html` → `game.mjs`(입력·HUD·저장·오디오), `scene.mjs`(Three.js 3D 화면), `rules.mjs`(연속 물리·충돌·진행·경제).
- 배포 캐시: HTML의 `game.mjs?v=…`와 게임·장면에서 가져오는 런타임 모듈의 `?v=…`를 같은 버전으로 갱신한다. 이전 방문자가 새 컨트롤러와 예전 물리·카메라 모듈을 섞어 받지 않게 한다.
- 저장소 루트를 정적 서버로 제공한다. 기존 서버와 포트를 먼저 확인하고 재사용한다. 새 서버가 필요하면 저장소 루트에서 `node games/orbit-golf/tests/serve.mjs`를 실행한다. 이 도우미는 별도 설치 없이 8123 포트에서 `.mjs`의 JavaScript MIME 타입을 포함해 제공한다. `file://` 직접 열기는 지원하지 않는다.
- WebGL이 필요하다. Three.js 0.160.1, GLTF 로더, 글꼴과 사용 에셋은 게임 폴더에 있어 런타임 패키지 설치나 외부 CDN을 사용하지 않는다.
- 홈페이지에서 게임으로 진입하고 게임 왼쪽 위 홈 버튼(`../../`)으로 복귀한다.

## 타격과 물리

1. 최대 12자의 파일럿 이름을 입력한다. 발사 방향 슬라이더로 각도를 정하고 타격 버튼을 길게 눌렀다가 놓는다. 초록 구간에서 놓으면 최대 세기로 타격한다.
2. 공은 앞뒤 속도·좌우 속도·높이·수직 속도를 가지고 움직인다. 트랙 폭은 20월드 단위이고, 공 중심은 좌우 약 8.85까지 움직인다. 옆벽에서는 반사되고, 범퍼와 물체의 충격은 진행 방향과 좌우 속도를 바꾸며, 스프링 등은 공을 공중으로 발사한다. 착지에는 반발과 감쇠가 적용된다. 이동을 세 칸으로 나누거나 목표 레인으로 옮기지 않는다.
3. 날아가는 동안 스핀 슬라이더를 좌우로 움직이면 약한 횡방향 힘을 가한다. 손을 놓거나 입력이 취소되면 스핀이 중립으로 돌아온다. 조작하지 않아도 공은 발사각과 충돌에 따라 진행한다. PC는 스페이스로 타격하고 `←`·`→` 또는 `A`·`D`를 누르고 있는 동안 스핀을 준다. `Esc`로 일시 정지한다.
4. 물리는 휠 표면의 연속 좌표에서 작은 시간 간격으로 적분하는 아케이드 모델이다. 앞뒤 위치 `s`와 폭 방향 `x`, 높이 `height` 및 각각의 속도를 사용한다. 실제 진행 좌표와 최고 도달 거리(`distance`)를 구분해 뒤로 튀어도 골드를 다시 받지 않는다. 360m는 같은 물리 휠의 한 바퀴이며, UFO·홀인원이 다른 휠로 옮긴다.
5. 장애물의 실제 위치와 회전은 `eventPose(event, elapsed)`를 물리와 장면에서 함께 계산한다. 공에 맞은 물체에는 이동·수직 속도와 회전이 생기며, 다른 장애물에도 충격을 전달한다. 움직이는 물체가 공을 다시 밀 수도 있다. 충돌마다 출발 물체·맞은 물체의 ID와 실제 충돌 위치·힘·연쇄 단계를 화면 반응에 사용한다. 공과 물체의 공중 이동, 뒤집힘, 충돌음·잔상·시점 반응이 물리 결과를 보여 준다. 모션 감소 설정에서는 강한 카메라 반응을 줄인다.

범퍼는 공을 다른 방향으로 튕기고, 스프링은 높이 띄우며, 권투 장갑은 옆에서 공을 밀어낸다. 우주인·혜성·범퍼·장치는 충돌하면 실제 물리 위치를 따라 굴러가거나 날아가며 뒤집힌다. 물체는 넓은 폭에 흩어진 작은 무리로 배치해 공→장애물→다른 장애물의 연쇄가 생기게 한다. 동전과 가속 장치, UFO와 홀인원은 운 좋게 진행을 이어 갈 기회다. 화면에는 최근 연쇄 단계가, 결과에는 장애물 간 충돌 횟수와 최대 연쇄 단계가 표시된다. 물체 간 충돌 자체로 골드나 수집 보상을 중복 지급하지 않는다.

날아간 물체도 트랙의 바닥·옆벽과 충돌하며 중력과 감쇠를 받는다. 한 쌍의 물체가 겹친 채 매 순간 재충돌하지 않도록 접촉 간격을 두고, 활성 물체 수·수명·연쇄 깊이에 상한을 둔다. 시간 제한과 물체가 다른 휠로 따라오지 않는 워프 처리도 물리에서 관리한다. 이 모델은 곡면 트랙에 맞춘 아케이드 물리이며 범용 강체 시뮬레이터는 아니다.

## 성장과 반복 진행

- 최고 도달 거리 8m당 1G를 얻고 보상 물체에서 추가 골드를 모은다. 멈추면 이번 판 골드를 정산하고 장비를 강화한다. 충돌과 워프의 운에 따라 판별 결과는 달라질 수 있다.
- 첫 플레이는 최대 75초의 훈련이다. 자연 정지나 시간 종료로 끝나면 훈련 보너스 80G를 주며, 이번 판 총 획득량이 90G보다 적으면 90G까지 채워 첫 공 강화를 바로 살 수 있게 한다. 이 보너스는 한 번만 지급하고, 타격 전 취소나 진행 중 임의 종료에는 지급하지 않는다. 훈련은 이어하기를 제공하지 않는다.
- 일반 비행은 최대 120초다. 일시 정지·숨김 시간은 제외한다. 제한 시간 전에 멈췄다면 한 판에 딱 한 번 40G를 내고 멈춘 위치에서 이어 칠 수 있다. 이번 판 골드도 비용으로 쓸 수 있으며 거리·남은 시간·받은 보상은 유지한다. 시간이 끝난 판은 이어 칠 수 없다.
- 공 강화는 발사 속도와 추진 유지력을 함께 높인다. 단계별 기준 비거리와 다음 강화의 차이는 강화 화면에 표시한다. 기준 비거리는 물체가 없는 직선 풀샷의 비교값으로, 실제 판의 보장 거리와 구분한다. 슈트는 충돌에서 잃는 추진력을 줄인다. 둘 다 5단계까지 강화한다. 첫 비용은 슈트 70G·공 90G이며 다음 비용은 화면에 표시한다.
- 첫 결과의 주 행동은 강화이고, 구매 뒤 다음 타격으로 이어진다. 강화는 공의 색과 실제 다음 판의 물리 계수에 함께 적용된다. 다음 목표는 지난 기록과 장비의 기준 비거리를 함께 반영한다.

성장 계수는 공 단계마다 풀샷 발사 속도 ×1.35, 마찰 ×0.92이며 높은 단계의 공은 물체 충돌로 빼앗기는 진행 운동량도 줄어든다. 물체 없는 직선 풀샷 기준 비거리는 단계마다 약 98% 늘어난다. 이 비교값을 실제 충돌 판의 보장 거리로 표시하지 않는다.

일반 비행 프로필, 시드 1~100, 풀샷·발사각 8°·무조작을 같은 조건으로 비교한 넓은 트랙·장애물 연쇄 물리의 측정값은 아래와 같다. 호출 간격은 0.2초, 내부 물리 간격은 1/120초다. 기본 공의 100판 중 99판에서 장애물 간 충돌이 발생했다. Lv.0→1의 시드별 거리 비율 중앙값은 약 2.69배였고 100쌍 중 98쌍이 더 멀리 갔다. 이 수치는 밸런스 회귀 기준이며 브라우저 성능이나 사람이 느끼는 재미의 검증은 아니다. 충돌과 워프의 경로가 바뀌므로 모든 개별 판이 강화 전보다 멀리 가는 것을 보장하지 않는다.

| 공 단계 | 최고 도달 거리 중앙값 | 플레이 시간 중앙값 | 장애물 간 충돌 중앙값 | 최대 연쇄 단계 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 484m | 20.2초 | 6회 | 3단계 |
| 1 | 1,289m | 34.6초 | 10회 | 4단계 |
| 2 | 3,008m | 59.0초 | 28회 | 5단계 |
| 3 | 4,758m | 75.7초 | 42회 | 5단계 |
| 4 | 7,259m | 98.9초 | 66회 | 5단계 |
| 5 | 9,613m | 119.4초 | 98회 | 6단계 |

4단계에서는 표본의 16%, 5단계에서는 50%가 일반 비행의 120초 제한으로 끝났다. 트랙 폭이나 충돌 규칙을 바꿀 때는 이 분포도 다시 측정한다.

## 기록과 저장

- 키: `orbit-golf:v1`. 이름·보유 골드·공/슈트 강화 단계·로컬 TOP 10·훈련 완료 여부를 `localStorage`에 저장한다. 진행 중인 공의 물리 상태 자체는 저장하지 않는다.
- 같은 이름의 최고 거리만 남겨 최대 10명을 표시한다. 영문 대소문자만 다른 이름은 같은 이름으로 취급한다. 서버·계정이 없는 기기·브라우저별 로컬 랭킹이다.
- 이름의 제어 문자·태그 기호를 제거하고, 숫자·강화 범위·랭킹을 정리한다. 손상되거나 읽을 수 없는 저장은 기본 프로필로 처리한다. 저장이 차단되거나 용량이 부족하면 경고하고 해당 방문의 메모리로 플레이를 유지한다.
- 기존 v1의 골드·강화·랭킹은 유지한다. 훈련 완료 필드가 없는 저장은 훈련을 한 번 진행하고 새 필드를 저장한다. 물리 규칙이 바뀌기 전의 기록도 보존하므로 기존 기록과 새 기록의 난이도가 완전히 같지는 않다. 이름을 바꿔도 훈련 보너스를 반복 지급하지 않는다. 이후 저장 형식 변경에는 별도 버전과 명시적 마이그레이션 또는 초기화 정책이 필요하다.
- 탭이 숨겨지면 진행과 입력을 멈춘다. 돌아왔을 때 숨겨진 시간을 거리로 적립하지 않고, 계속 버튼으로 재개한다. 페이지 이탈 시 렌더링·이벤트·오디오를 정리한다. 다른 게임의 저장 키는 읽거나 변경하지 않는다.

## 검증

저장소 루트에서 대상 파일만 검사한다.

```powershell
node --check games/orbit-golf/game.mjs
node --check games/orbit-golf/scene.mjs
node --check games/orbit-golf/rules.mjs
node --test games/orbit-golf/tests/rules.test.mjs
node --test games/orbit-golf/tests/scene.test.mjs
git diff --check -- games/orbit-golf
```

규칙 테스트는 넓은 트랙의 연속 이동·반사·공중 비행, 공→물체→물체 충격 전달, 움직이는 물체의 공 재충돌, 연쇄 상한·워프 정리, 큰 프레임 간격·시간 제한·여러 시드의 강화 비교와 경제·정산·랭킹·저장 호환을 다룬다. 장면 테스트는 실제 Three.js 좌표와 투영으로 넓은 폭/높이, 물체의 실제 물리 위치·회전 일치, 수직 휠의 회전, 추적 카메라와 공의 화면 노출을 검사한다. 두 검사는 별도 설치가 필요 없으며 GPU 렌더링 검증은 아니다.

화면 연결 통합 검사는 `tests/`의 개발 의존성 jsdom 26.1.0을 사용한다. Node.js 20 이상과 pnpm으로 이 폴더에만 잠금 파일에 맞춰 설치한다.

```powershell
pnpm --dir games/orbit-golf/tests install --frozen-lockfile
node --experimental-vm-modules --test --test-concurrency=1 games/orbit-golf/tests/rules.test.mjs games/orbit-golf/tests/scene.test.mjs games/orbit-golf/tests/integration.test.mjs
```

통합 검사는 실제 컨트롤러·물리를 실행하고 3D 화면만 대역으로 바꾼다. 임의 발사각·스핀과 해제, 이전 좁은 트랙 경계 너머의 연속 이동, 무조작 충돌·공중 이동·장애물 연쇄의 HUD/화면 반응/결과 연결, 훈련과 강화 후 비거리·한 번 이어하기·정산·저장 실패와 호환·탭 복귀·종료 정리를 검사한다. 모듈의 배포 버전 일치도 확인한다. jsdom과 테스트 의존성은 실제 게임에서 로드하지 않는다.

화면 변경 후 실제 브라우저의 PC 및 320~390px 세로 화면에서 직접 진입, 타격·스핀·일시 정지·재시작, 강화·결과와 홈 왕복을 확인한다. 모듈·글꼴·에셋 로딩과 작은 화면의 글씨·잘림·44px 이상 터치 영역, 동적 높이·안전 영역·탭 복귀를 확인한다. 브라우저 에뮬레이션과 실제 iOS Safari·Android Chrome 기기 검증을 구분한다. 규칙·DOM 검사 통과를 실기기 성능, 충돌 장면의 웃김이나 장시간 재미 검증으로 대신하지 않는다.
