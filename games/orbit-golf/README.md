# 오빗 골프

공을 한 번 쳐서 물체를 날리고 연쇄 충돌을 만드는 싱글 플레이 3D 물리 골프다. 일반 비거리 모드에서 골드·장비·이 기기 TOP 10을 쌓고, 별도의 짧은 연쇄 조준 과제 3개로 공 특성을 해금한다.

움직임 참고 영상: [골프를 로블록스에서 치는 아저씨들](https://www.youtube.com/watch?v=gf_R5FoiopY). 10:37의 넓은 코스와 충돌, 12:15의 새 타격, 15:55의 고공 비행에서 공의 관성·그림자·뒤 추적 구도를 참고했다. 원본 게임의 코드·모델·영상·음원은 복제하지 않았다. 실제 사용 리소스와 라이선스는 [assets/ASSETS.md](assets/ASSETS.md), 아트 기준·예산은 [art-direction.md](assets/art-direction.md) 및 [asset-manifest.json](assets/asset-manifest.json)에 기록한다.

## 실행과 파일

- 공개 경로: `/games/orbit-golf/`, 홈 복귀: `../../`.
- 저장소 루트를 정적 서버로 제공한다. 기존 서버를 먼저 확인해 재사용한다. 필요할 때 루트에서 `node games/orbit-golf/tests/serve.mjs`를 실행하면 `http://127.0.0.1:8123/games/orbit-golf/`에서 실행된다. `.mjs`의 JavaScript MIME 타입이 필요하며 `file://` 직접 실행은 지원하지 않는다.
- WebGL과 로컬 Three.js 0.160.1, GLTF 로더·폰트·사용 모델을 사용한다. 런타임 설치·외부 CDN·다른 게임 의존성은 없다.
- `index.html` → `game.mjs`는 입력·HUD·저장·오디오, `rules.mjs`는 물리·진행·경제, `scene.mjs`는 3D 화면·카메라, `course.mjs`는 공유 지형, `challenges.mjs`는 도전 배치·실제 연쇄 판정, `encounter-art.mjs`는 대형 조우 모델·반응을 담당한다.
- HTML·스타일·런타임 모듈의 `?v=…`를 함께 갱신한다. 게임·장면·물리가 서로 다른 배포 버전을 섞어 받지 않게 한다.

## 플레이와 진행

- 최대 12자의 이름을 입력하고 발사각을 정한다. 타격 버튼을 길게 눌렀다 초록 구간에서 놓으면 최대 세기다. 터치 슬라이더로 남은 전진 운동 안에서 스핀을 줄 수 있고 손을 놓으면 중립으로 돌아온다. PC는 스페이스 타격, 좌우 방향키/A/D 스핀, Esc 일시 정지다. 이동을 세 칸 레인으로 나누지 않는다.
- 폭 20월드의 일자 코스다. 결과의 `새 코스`는 새 시드로 높이·굴곡·조우 위치·기믹 순서를 만들고, `같은 코스`는 시드·배치·발사각을 유지한 새 타격을 준비한다. 물체의 사용·파괴 상태는 새 판으로 초기화되어 각도·세기·장비를 비교할 수 있다. 360도 루프나 뒤집힌 바닥은 없다.
- 진행·장치 추가 단위는 360m다. 지형은 3구간을 묶은 **1080m의 긴 호흡**으로 오름·정점·내림이 이어진다. 8가지 지형을 섞고 큰 산등성이·골짜기의 고저차는 약 25~34월드다. 경사 −0.36~+0.34와 곡률 예산을 두어 짧은 벽처럼 꺾이지 않게 한다. 첫 60m는 완만하고 150~400m부터 눈에 보이는 기복이 나타난다.
- 2번째 구간부터 기믹 묶음을 하나씩, 매 5번째에는 3개씩 추가하며 최근 8묶음만 유지한다. 이동 범퍼·도약·회전·반발·혜성·추진·중량 제동·동물/촉수/과자 조합을 시드로 섞는다.
- 10번째 구간 끝 3,570m에는 수문장이 나타나고 이후 10구간마다 반복한다. 실제 전진 속도 × `(1 + 공 단계 × 0.2)`가 필요 힘 이상이면 40G를 한 번 받고 관문을 부순다. 필요 힘은 170에서 시작해 최대 300까지 증가한다. 파괴 상태는 후진·이벤트 재생성·이어하기에도 유지된다.

## 연쇄 도전과 공 특성

일반 코스와 분리된 180m 공간에서 발사각·세기로 연쇄의 시작점을 고르는 짧은 과제다. 코랄 조준 링은 먼저 맞힐 물체, 금색 링·표적은 목표, 민트 체크는 실제로 완료한 표적을 뜻한다.

| 과제 | 성공 조건 | 공 Lv.5에서 해금 |
| --- | --- | --- |
| 도미노 | 날아간 링의 같은 연쇄로 서로 다른 표적 2개 충돌 | 탄성 공 |
| 과자 파쇄 | 해당 과자에서 생긴 실제 조각으로 부유 표적 1개 충돌 | 회전 공 |
| 우주 볼링 | 날아간 동물의 같은 연쇄로 서로 다른 표적 2개 충돌 | 중량 공 |

- `sourceId`·`chainId`와 실제 몸체의 계보가 맞는 연쇄만 인정한다. 공으로 표적을 직접 맞히거나 다른 물체의 독립 연쇄·같은 표적 반복 접촉은 성공 수에 더하지 않는다.
- 정밀 타격은 장비 단계와 무관한 공통 발사 위력 84·질량 6·기본 마찰을 사용하고 슈트 보정은 적용하지 않는다. 선택한 공 특성의 배율은 적용한다. 일반 비거리 모드의 성장 수치는 유지한다.
- 최대 35초이며 목표 달성 후에도 1.1초 동안 실제 물리 결과를 보여 준 뒤 현재 위치에서 종료한다. 공이 먼저 멈추거나 180m를 지나도 이미 날아간 물체의 남은 수명 동안 연쇄를 판정한다.
- 거리 골드·물체 골드·일반 랭킹·첫 훈련·40G 이어하기와 분리한다. 과제별 최초 정상 성공에만 60G와 완료 기록을 저장한다. 목표 달성 후 관찰 시간 중 이탈해도 성공을 보관하며, 반복 성공·실패·목표 달성 전 중단에는 골드를 지급하지 않는다.
- 공 Lv.5 이전의 완료 기록도 보관하여 Lv.5에 도달하면 대응 특성이 열린다. 해금 후에는 무료 교체하며 자동 장착하지 않는다. 한 번 발사한 공은 도중에 특성을 바꾸지 않는다.
- 중량 공은 물체를 강하게 밀지만 출발·회전이 느리고, 탄성 공은 크게 반발하지만 가볍고 직진이 짧다. 회전 공은 스핀이 강하지만 출발이 느리다. 기본 공은 기존의 균형을 유지한다. 공 표면의 금속 띠·분절 링·나선과 색·재질로 구별한다.
- 조준 링·표적·완료 체크·공 무늬는 Three.js 절차 메시다. 새 외부 이미지·모델·음원은 추가하지 않았다.

## 움직임 계약

- 내부 물리는 1/120초 고정 간격이다. `s`/`speed`는 게임 전방 좌표·부호 있는 속도, `x`/`vx`는 화면 오른쪽을 양으로 하는 좌우 좌표·속도이며 Three.js X는 `-x`다. **`worldY`/`worldVy`가 공 중심의 실제 월드 높이·수직 속도**다. `height`와 `vy`는 바닥과의 상대 높이·속도를 읽는 호환 값이며, 별도의 숨은 추진 속도는 없다.
- 바닥에 닿아 구를 때는 같은 지형의 접선·법선·곡률로 중력·마찰·접촉을 계산한다. 정점에서 필요한 접촉 힘이 사라지면 자연스럽게 이륙한다. 공중에서는 월드 중력으로 포물선을 그리며 아래 지형에 붙어서 오르내리거나, 공중에 지형 경사 힘을 추가하지 않는다. 7.5월드 높이에서 멈추던 상한은 없다.
- 착지는 실제 경로와 바닥의 교차 지점에서 법선 속도를 반사·감쇠한다. 낮은 접촉은 구름으로 전환하고, 큰 낙하는 반발한다. 일반 범퍼·옆벽에 닿았다는 이유로 수직 점프를 강제로 더하지 않는다. 도약·추진 능력은 해당 장치에서만 발동한다.
- 공과 날아간 물체는 월드 중심과 유한 질량 충격량을 공유한다. 접촉 겹침을 분리하고 이동 구간 충돌 검사로 빠른 물체의 관통을 막는다. 연쇄 깊이·활성 몸체·수명·입자 수를 제한하고 워프 시 이전 물체를 정리한다.
- 공의 회전은 고정 물리 간격에서 quaternion으로 적분한다. 지상에서는 실제 표면 이동량과 반지름에 맞춰 구르고, 공중에서는 각운동을 유지·감쇠한다. 렌더링은 이전/현재 월드 중심·회전을 보간하며 수직 속도만으로 공을 계속 늘이지 않는다.
- 카메라는 공의 월드 중심을 기준으로 따라가고 뒤 거리·올려다보는 위치만 시간 기반으로 부드럽게 바꾼다. 큰 비행·빠른 타격에서 공이 카메라를 앞질러 가지 않는다. 그림자는 같은 전방/좌우 좌표의 바닥에 남고, 고도에 따라 옅어진다. 잔상은 1/60초 간격, 속도선은 실제 이동 거리 위상으로 생성해 렌더 FPS나 감속에 따라 순간이동하지 않게 한다. 모션 감소 설정은 잔상·시야각 변화를 줄인다.
- 카메라와 공 사이를 실제로 가리는 장애물 메시만 일시적으로 옅게 표시한다. 옆이나 공 앞의 물체는 유지하고 시야를 벗어나면 원재질을 복원한다. 충돌은 계속 계산하며 이벤트별 복제 재질은 제거 시 정리한다.
- 전진 속도가 소진되면 스핀 입력·횡운동·능동 충돌을 종료하고 남은 수직 낙하가 착지한 뒤 자연 종료한다. 도전은 이미 날아간 물체의 판정을 끝까지 기다린다. 스핀만으로 판을 무한히 연장할 수 없다. QA·외부 강제 배치에는 `placeRun(run, {s, x, height, vy})`를 사용해 월드 중심·이전 포즈를 함께 맞춘다.

## 보상·성장·저장

- 일반 모드는 최고 도달 거리 8m당 1G와 물체 보상을 얻는다. 첫 훈련은 최대 75초다. 자연/시간 종료 시 최초 80G 보너스를 주고 총 획득량을 최소 90G로 맞춰 첫 공 강화를 살 수 있게 한다. 훈련은 이어하기가 없고 발사 전 취소·임의 중단에는 훈련 보너스를 주지 않는다.
- 일반 판은 최대 120초다. 시간 전에 멈춘 판에서 딱 한 번 40G로 같은 위치·거리·보상·남은 시간에서 이어 칠 수 있다. 이번 판 골드도 비용으로 쓸 수 있다. 시간 종료 후에는 이어 칠 수 없다.
- 공·슈트는 각각 5단계이고 첫 비용은 공 90G·슈트 70G다. 공은 타격 위력·구름 마찰·충돌 보존을, 슈트는 충격 보존을 강화한다. 현재 물리 계수와 평지 기준 비거리는 `ballStats`와 강화 화면이 함께 계산한다. 실제 경사·충돌·운을 포함한 각 판의 비거리를 보장하는 수치는 아니다.
- 저장 키는 `orbit-golf:v1`이다. 기존 이름·골드·공/슈트 단계·이 기기 TOP 10·훈련 완료를 보존하고, `challengeWins`와 `ballTrait`를 추가한다. 완료 목록은 알려진 과제만 중복 없이 유지하고, 알 수 없거나 아직 잠긴 특성은 `standard`로 복원한다. 이전 저장에는 빈 완료 목록과 기본 공을 적용한다.
- 진행 중인 물리 상태·재도전 시드는 저장하지 않는다. 같은 이름의 최고 기록만 남기고 영문 대소문자를 구분하지 않는다. 이전 물리의 기록도 보존하므로 난이도가 완전히 같지는 않다. 서버 공용 랭킹은 없다. 저장 손상·읽기 차단·용량 초과 시 경고하고 메모리 플레이를 유지한다. 이름 변경으로 훈련 보너스를 반복 지급하지 않는다.
- 숨긴 탭은 진행·입력을 멈추고 복귀 후 계속 버튼으로 재개한다. 숨김 시간을 적립하지 않는다. 페이지 이탈 시 렌더링·리스너·오디오를 정리하고 다른 게임 저장은 건드리지 않는다.

## 저장 없는 QA

`?preview=1`은 기존 저장을 읽거나 쓰지 않는 메모리 프로필이다. 새로고침하면 초기화되며 `&seed=42`로 고정 시드를 지정할 수 있다. 일반 플레이에서는 `seed`·`encounter`·`profile`·`challenge` QA 파라미터를 무시한다. 아래 경로는 실제 생성된 장치·지형과 정상 물리를 사용하며 자연 도달한 플레이와 구분한다.

- `?preview=1&seed=42&encounter=beast` / `giant-alien` / `cookie`: 첫 12구간의 실제 대형 대상 18m 전·공 Lv1·각도 0°에서 준비한다.
- `encounter=spring` / `anvil` / `tar`: 실제 대상 36m 전·공 Lv1로 도약·급감속을 검사한다. 별도의 약화 장치를 만들지 않는다.
- `encounter=climb` / `drop`: 같은 시드의 첫 8진행 구간에서 큰 상승/하강 경사 36m 전에 배치한다.
- `?preview=1&encounter=guardian-weak` / `guardian-strong`: 3,510m에서 공 Lv0/Lv3으로 검사한다. 수문장의 힘 170 문턱은 동일하다.
- `?preview=1&profile=max&challenge=domino&seed=42`: 이름 입력 후 정밀 도전 준비. 풀샷 +14°에서 실제 도미노 성공과 탄성 공 해금을 검사한다. `challenge=cookie`는 −12°, `challenge=bowling`은 +2°다. `profile=max`는 공·슈트 Lv.5인 메모리 프로필이며 `profile=max` 없이도 같은 정답을 사용할 수 있다. 세 과제 모두 시드 42의 0° 풀샷은 실패한다.

## 검증

저장소 루트에서 대상 파일만 실행한다. Node20+를 사용하며 게임 런타임 의존성 설치는 없다. 화면 연결 검사의 jsdom 26.1.0만 테스트 폴더 개발 의존성으로, 필요할 때 `pnpm --dir games/orbit-golf/tests install --frozen-lockfile`을 실행한다.

규칙 검사는 평지 구름·월드 포물선·정점 이륙·착지 법선·충돌/연쇄·위험·전진 소진·시간 제한·경제·저장 호환을 다룬다. `challenges.test.mjs`는 시드 재현·직접 접촉 제외·같은 연쇄와 조각 계보·중복 제외·실제 기본/최대 장비 성공·잘못된 각도 실패를 확인한다. `progression.test.mjs`는 실제 성공에서 60G 1회 정산·Lv.5 해금·특성 차이·훈련/랭킹 분리·v1 보존을 검사한다.

일반 모드 성장 비교는 기본 특성 `standard`·공 6단계×시드1~100·풀샷·각도8°·무조작·호출0.2초/내부1/120초로 실행한다. 테스트 전용 `balance-worker.mjs`가 25시드씩 최대6worker로 나누고 결과를 시드 순으로 모은다. 도전 정밀 장비나 새 특성의 통계가 아니다. 물리 계수가 바뀌면 다시 수행하며 이전 빌드의 수치를 그대로 전용하지 않는다.

`motion.test.mjs`는 실제 규칙과 Three.js 객체를 함께 사용해 월드 중심 보간·그림자의 수평 일치·물리 quaternion·실제 둘레와 구름 회전량·10/30/60/144FPS의 카메라/잔상 일치·감속 중 속도선 위치·먼 좌표 원점 이동을 검사한다. 지형은 C2 연결·곡률·시드 재현성·높이 폭을, 장면은 투영/공 가림·위치·정리와 자산 피벗을 확인한다. 통합 검사는 실제 컨트롤러·규칙을 실행하고 GPU 장면만 대역으로 바꾼다.

자동 좌표·DOM 검사는 실제 GPU 화면·휴대폰 성능·사람이 느끼는 자연스러움/재미의 검증이 아니다. 공개 빌드에서 PC와320/390px 세로 화면의 타격·스핀·착지·일시 정지·이어하기·재시작·홈 왕복·글꼴·44px 터치 영역·높이 변화·탭 복귀를 별도로 확인한다. 데스크톱 모바일 에뮬레이션과 실제 iOS Safari/Android Chrome 실기기를 구분해 보고한다.

### 과거 공개 빌드 관찰과 미검증 범위

이전 `motion1` 공개 빌드에서 PC·320/390px 모바일 크기의 실제 WebGL 타격·스프링 비행/착지·40G 이어하기·정지/재시작·홈 왕복을 확인했다. 시드17의 직접 플레이 한 쌍은 기본 공 165m→Lv.1 1,219m였다. `motion2`는 당시 발견한 공 가림에 메시 교차 기반 투명화·복원을 추가한 빌드다. 이 기록은 이번 도전·특성 UI의 공개 검증을 대신하지 않는다.

`chain1` 공개 WebGL에서 저장 없는 최대 장비 프로필로 390×844·320×568·1440×900을 직접 플레이했다. 시드42의 0° 도미노 실패 후 같은 항로에서 +14°로 성공했고, 탄성 공 무료 장착 후 반복 성공은 추가 골드 없이 완료 기록만 유지됐다. 이어서 과자 -12°·볼링 +2°로 실제 연쇄를 완료해 회전·중량 공도 해금·장착했다. 성공 결과에 실제 원인 물체가 표시되고 특성 메뉴를 닫으면 결과로 돌아왔다. 320px에서 문서가 뷰포트를 넘지 않고 Jua 로딩, 설명16px·선택 버튼48px를 확인했다.

이 관찰에서 볼링의 표적이 하마 뒤에 숨는 문제를 발견해 `chain2`의 볼링 표적 핀만 높이고 실제 범퍼까지 가는 줄기로 연결했다. 물리 배치·카메라는 유지했고, 세 화면 크기의 실제 하마 메시 가림 회귀를 포함해 자동 검사 총204개가 통과했다. 자동 물리·장면·DOM 검증과 데스크톱의 모바일 크기 에뮬레이션은 실제 iOS Safari/Android Chrome 실기기 확인과 구분한다. 과제3개는 짧은 조준 퍼즐이며 장기 재미·재방문·어지러움 개선을 검증한 결과가 아니다. 다음 확인 우선순위는 실제 휴대폰의 조작성·프레임/발열과, 여러 이용자의 자발적인 재도전 여부다.

`chain2` 공개 화면에서 볼링의 두 표식이 하마 위로 보이는 것과 실제 320×568에서 성공·중량 공 해금을 확인했다. 일반 비행의 같은 코스는 항로 번호를 유지하고 새 코스는 다른 번호로 바뀌었다. 이 재도전에서 1m 미만 차이를 `0m 경신`으로 알리는 표시를 발견해 `chain3`에서 정수 기록 비교로 바로잡았고, 실제 컨트롤러 재현 검사로 실패→수정 후 통과를 확인했다. 세 도전 최초 보상 합계180G·무료 특성 교체·반복 보상0G·일반 랭킹 분리와 콘솔 오류/경고 없음을 공개 QA에서 확인했다.
