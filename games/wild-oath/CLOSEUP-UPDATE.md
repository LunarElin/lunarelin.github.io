# 2026-10-30 · 남아 있던 광선 제거와 전투 확대

공개 v6의 연결선은 사라졌지만 scratch·flare·spark·burst PNG의 가늘고 긴 빛 모양과 이동 파편이 레이저처럼 보였다. 캐릭터와 사용 카드도 작았다. 이번 `closeup-7`은 이 두 문제를 교정한다.

## 변경

- 긴 발톱·별빛·전격 텍스처 4종을 런타임과 파일에서 제거했다. Kenney Particle Pack CC0 원본 중 둥근 fire·ring·smoke·splash 4종만 사용한다. 합계 60,217 B이며 라이선스와 원본 경로는 [리소스 기록](assets/kenney-effects/README.md)에 보존한다.
- 대상의 초상화 중심에 짧은 충격·연기·고리와 효과 기호를 표시한다. 대상까지 이동하는 카드, 파편, 광선, 구체를 만들지 않는다. 일반 공격·반격은 splash, 감전·변신은 smoke를 사용하며 정적인 기호로 효과를 구분한다.
- 캐릭터 그림을 크게 하고 상태 수치를 옆의 고정 칸으로 옮겼다. 사용 카드의 기본 크기와 그림 영역도 늘렸다. 카드 제시 중에는 수직으로 살짝 들어올리고, 추가 확대·회전으로 생명바를 덮지 않는다.
- PC에서는 자기 덱을 카드 옆에 둔다. 좁은 화면에서는 덱 그림과 장수를 진영 머리줄에 놓아 캐릭터와 사용 카드 공간을 확보한다. 낮은 가로 화면은 두 진영을 좌우로 나눈다.
- 배포 파일 쿼리를 `closeup-7`로 갱신했다. 전투 규칙과 저장 형식은 바꾸지 않았다.

## 내부 브라우저에서 직접 확인

Codex 내부 브라우저의 실제 DOM·스크린샷과 일반 클릭으로 검증했다. 아래 수치는 CSS 픽셀이며 실기기 테스트가 아니다. `clientWidth/offsetWidth`로 연출 변형 전 크기를 기록했다.

기존 PC 초상화 약 76px·사용 카드 폭 184px에서 각각 130px·280px로 확대했다. 390px 세로 화면의 초상화는 약 61px에서 96px로 확대했다. 작은 세로 화면에서도 카드 그림 높이 76px를 확인했다. 390×580에서 생명 30px, 기력 28px, 카드 이름 18px를 측정했고 속도·정지 버튼은 75×46, 50×48px였다.

저장된 로컬 시련 4 전투를 이어서 플레이했다. 내 기력 사냥 공격은 상대 초상화에 splash로 발생했고 생명 65→58로 감소했다. 다음 행동 뒤 상대 생명 53, 내 생명 70을 확인했다. 상대 와이번 변신은 상대 초상화의 둥근 연기, 독 부여는 내 초상화의 효과로 구분됐다. 실제 등장한 이펙트 DOM에 이동 파편·구체·광선·날아가는 카드가 없었다. 행동하지 않는 진영의 사용 카드는 비어 있었고, 320px에서 보이는 사용 카드는 한 장이었다.

일시 정지 후 이펙트·피해 숫자·효과 칩은 0개로 정리됐다. 새로고침 뒤 생명 53/70과 일시 정지 상태가 유지됐다. 홈 복귀와 홈→게임 재진입도 확인했다. 콘솔 경고·오류는 없었다. 개발용 상태 주입이나 규칙 변경은 사용하지 않았다. 원시 관찰 요약은 [브라우저 검증 기록](tests/closeup-browser-review.json)에 있다.
