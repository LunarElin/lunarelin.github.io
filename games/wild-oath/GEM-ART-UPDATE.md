## 실제 교체 범위

- 초상화 6칸의 아틀라스, 일반 카드 25종, 변신 카드 전용 가로 구도 3종을 제작했다. 변신 카드는 정사각 초상화의 이마 부분만 보이는 문제를 실제 화면에서 발견해 추가 제작했다. 캐릭터 초상화와 카드 삽화는 각 역할에 맞는 구도를 사용한다.
- 짙은 라일락 보드, 사파이어/로즈 진영, 크림 에나멜 카드, 진주·금색 프레임, 입체 캔디 버튼을 시작 선택·탐험·야영지·전투·도감·팝업에 적용했다. 글자와 버튼은 코드로 유지한다.
- 캐릭터 크기·카드 제시·공격 돌진·대상 위치 충격·아이콘과 큰 수치·별도 덱 위치는 유지한다. 규칙·밸런스·저장 형식은 바꾸지 않았다.
- 새 WebP는 **29개, 548,904 B**다. 초상화 187,732 B, 일반 카드 317,852 B, 변신 가로 그림 43,320 B이며 기존 550,000 B 한도를 유지한다. 새 반복 보드는 자체 SVG 1,591 B다. 이전 아트는 제작 이력으로 보존하고 현재 아트 CSS는 gem-v5를 참조한다.
- OpenAI 내장 `image_gen`으로 생성했다. 모델·생성 ID는 도구가 공개하지 않았다. 원본 PNG·SHA256·전체 프롬프트·크기·분할 경계·인코딩 과정은 [아트 기록](assets/gem-v5/ART.md), [manifest](assets/gem-v5/manifest.json), [정규화 스크립트](assets/gem-v5/normalize.py)에 보관한다. Python/Pillow는 제작 전용이다. 게임에는 패키지·런타임 의존성을 추가하지 않았다.
