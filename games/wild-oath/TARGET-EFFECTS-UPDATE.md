# 대상 위치 이펙트 · 2026-10-30

사용자 요청에 따라 카드와 상대를 잇던 레이저·이동 구체를 제거했다. `create-game-assets`, `game-feel` 스킬로 Kenney의 실제 무료 파티클을 고르고 대상 위치에 적용했다. 카드가 덱에서 나와 제시·착지하는 동작 뒤 짧은 준비 시간을 두고, 규칙에서 확정된 대상에만 효과를 표시한다. 카드 아래의 별도 접촉 파티클도 제거했다.

## 실제 무료 리소스

공식 [Kenney Particle Pack](https://kenney.nl/assets/particle-pack)의 CC0 표시와 다운로드 ZIP의 라이선스를 함께 확인했다. 필요한 투명 PNG 8개만 `assets/kenney-effects/`에 보관했다. 전체 팩·로고·미사용 이미지·발사체 이미지를 배포하지 않는다. 파일은 각각 256×256 RGBA이며 합계 **120,851B**, 예산은 150,000B다.

원본 투명 영역을 잘라 비율을 유지해 축소하고 중앙 기준점을 맞췄다. RGB를 흰색으로 통일한 뒤 런타임 CSS 마스크로 색을 입힌다. 형태·파일별 원본 경로·가공·SHA256·실제 알파는 [리소스 기록](assets/kenney-effects/README.md)·[manifest](assets/kenney-effects/manifest.json)에 남겼고 [원본 CC0 라이선스](assets/kenney-effects/LICENSE.txt)를 동봉했다. 다운로드는 10월 29일, 통합 검토 마무리는 30일이다. 기존 아트·글꼴·음원은 유지한다.

## 대상과 타이밍

- 직접 공격은 맞는 쪽, 반격은 공격자, 버림 화상·재섞기 맹독·피로는 그 피해를 받는 본인에게 표시한다. 이미 다음 차례로 넘어간 `battle.actor`를 대상 계산에 사용하지 않는다.
- 실제 생명 피해와 보호막 손실이 모두 0인 초과 타격은 타격 이펙트를 만들지 않는다. 전부 막힌 타격은 파란 방패와 고리로 표시한다.
- 회복·보호막·기력은 실제 수혜자에게 표시한다. 최대 생명에서 실제 회복이 0이거나 기력 한도에서 실제 증가가 0이면 해당 증가 효과를 만들지 않는다.
- 상태 부여는 성공한 카드의 실제 부여량에 따라 대상에 표시한다. 첫 타격에 같은 종류의 효과가 이미 있는 경우 파티클을 이중 생성하지 않고 상태 수치 칩은 유지한다. 상태 부여만으로 생명 피해 숫자를 만들지 않는다.
- 숫자 뒤의 불투명한 판을 없애고 숫자·상태 칩 위치를 옮겨 대상 파티클을 읽을 공간을 확보했다. 손상·회복 숫자와 생명바는 기존 실제 타격 순서를 유지한다.
- 일반·연계·강타를 크기로 구분하고, 개별 타격은 기존 160ms 간격으로 표시한다. 이펙트는 360ms에 사라지고 370ms에 정리하여 최소 다음 행동 대기 380ms 안에 끝난다. `presentationTiming.travel`은 호환되는 내부 필드명이며 이제 이동 이펙트가 아닌 발동 준비 시간이다.
- 모션 감소에서는 파편·이동·반동을 끄고 대상의 정적인 모양과 짧은 페이드를 사용한다. 모든 새 이펙트는 기존 타이머·56개 상위 노드 한도·정지/이탈 정리를 따른다. 그림과 파편은 터치를 가로채지 않는다.

규칙과 저장 스키마는 변경하지 않았다. `wild-oath:v5`와 기존 v4 이전 정책을 유지하며 효과를 위해 규칙을 다시 실행하지 않는다. 파티클 8개는 전투를 표시할 때 한 번 비동기로 준비하며 전투 진행이 이미지 로딩을 기다리게 하지 않는다. 런타임 라이브러리·프레임별 DOM 루프는 추가하지 않았다.

## 검증

대상 게임의 **88/88 테스트 통과**. 기존 81개에 실제 피해/방어·초과 타격·반격/폭발·버림 화상/재섞기 독·감전/피로·불변성·리소스 검증 7개를 추가했다. 리소스 검증은 PNG를 실제로 풀어 RGBA·알파·흰 마스크·크기·SHA256·용량·CC0 원문을 확인한다. 변경 모듈의 `node --check`, 문서 링크·JSON·`git diff --check`도 확인했다. 새 밸런스 시뮬레이션은 실행하지 않았다.

Codex 내부 브라우저에서 localhost 테스트 저장을 이어 실제 UI로 플레이했다. 기존 늑대 여정의 2시련 14턴 생명 60/53에서 시작해 **25턴 생명 70으로 승리**했다. 늑대 보상과 정령의 선물의 불씨 수액을 고르고, 늑대 한 쌍을 정상 일괄 합성해 선두 표식이 붙은 2등급을 남겼다. 3시련도 **생명 69로 승리**하여 보상 창까지 진행했다. HP·카드·RNG·승패를 강제로 바꾸지 않았다. 새 버전 전체 다섯 시련 완주를 뜻하지 않는다.

3시련 보상과 다음 상인 이벤트에서 폭풍의 씨앗을 얻고 2등급을 정상 정렬 기능으로 맨 앞에 두었다. 4시련 첫 카드에서 상대 생명 70→65·감전 5를 확인했다. 피해와 상태 부여가 같은 전격 모양을 중복 생성하지 않아 밝은 4개 프레임 각각 전격 효과가 1개였다. 이펙트는 상대 초상화 위치에만 생겼으며 빛줄기는 없었다. 확인 후 정지했다.

준비 단계의 4개 표본은 대상 이펙트가 0개였다. 효과 단계는 실제 수혜자 중심에 배치됐고, 반동 중에는 캐릭터가 접촉점으로부터 이동하므로 정리 단계의 스프라이트와 얼굴 중심은 최대 약 22px 떨어진 표본이 있었다. 이는 접촉 지점에 남아 사라지는 파티클과 캐릭터 반동의 분리이며 레이저로 따라 연결하지 않는다.

전체 8종은 어두운 바탕의 130px 정지 미리보기로 검토했다. 전투 중 직접 프레임을 확인한 대표 종류는 발톱·방패·회복·기력·변신·전격이다. 불꽃·독을 포함한 모든 카드/모습 조합의 동작을 실제 기기에서 확인했다고 주장하지 않는다. 원본 UI 표본: [tests/target-effects-browser-review.json](tests/target-effects-browser-review.json).
