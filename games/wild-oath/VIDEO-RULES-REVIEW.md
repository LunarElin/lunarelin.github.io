# 영상 참고 규칙 검토 · 2026-10-29

사용자가 제공한 [플레이 영상 0:53부터](https://youtu.be/gyqe3jZ0cYE?t=53)를 Codex 내부 브라우저에서 열고, 전투 화면과 한국어 자동 생성 자막을 검토했다. 화상과 기력 설명은 기존 설치본의 단일 번역 TSV에서 관련 키를 읽어 교차 확인했다. 자동 자막이나 순간적으로 보이는 충전 표시만으로 규칙을 단정하지 않는다.

이번에 확실하게 확인한 불일치는 **화상을 충전 실패에만 적용하던 동작**이다. 성공적으로 사용한 카드도 버려지므로 화상을 받아야 한다. 사용자가 앞서 지정한 무작위 첫 덱, 공용 카드 풀, 기력 기반 자동 연속 사용과 드루이드 변신은 이 게임의 우선 설계로 유지한다.

읽기 전용 자료는 `D:/SteamLibrary/steamapps/common/card-battler/localization_1.2.1.tsv` 한 파일이다. `Term`, `english`, `korean` 열의 관련 키만 확인했으며 실행 파일·게임 코드·원본 문장·전체 자막을 배포물에 포함하지 않는다.

따라서 **부분 충전은 같은 전투의 다음 덱 순환까지 보존**, **성공 후 충전은 0**, **새 전투는 모두 0**으로 시작하는 기존 정책을 유지한다. 이는 이 게임에서 명시하고 테스트하는 정책이며, 성공 후 초기화가 원작 영상으로 확정됐다는 의미는 아니다.

## 교정한 버림 처리

성공한 카드는 직접 공격, 보호막·회복, 상태 부여·집중·자원 효과, 독성 폭발·회복, 곰 반격을 처리한 뒤 버려지고 **현재 남은 화상만큼 한 번** 피해를 받는다. 이 세부 해결 순서는 이 게임의 고정 정책이다. 회복으로 줄어든 화상과 그 카드가 새로 얻은 보호막도 버림 피해에 반영한다.

충전 실패 카드도 버림과 화상을 한 번만 처리한다. 다중 타격·늑대 추격이 여러 번 발생해도 버리는 카드는 한 장이므로 화상은 한 번이다. 카드가 없는 재섞기 차례에는 버림 화상이 없다. 화상 수치는 발동 후 1 줄고, 생명 피해는 남은 생명을 초과하지 않는다. 화상으로 쓰러지면 턴 종료 기력 회복을 받지 않는다. 양쪽이 동시에 쓰러진 경우 기존 플레이어 패배 정책을 유지한다.

기력 0·충전 실패·덱 소진에 따른 연쇄 종료는 변경하지 않는다. 성공 카드의 화상 처리로 기력이 추가 소비되거나 다음 무료 카드가 자원 고갈을 건너뛰지는 않는다.

저장 스키마는 v5를 유지한다. 유효한 기존 v5 진행은 계속 읽고, 이미 저장된 카드의 효과와 화상은 다시 실행하지 않는다. 저장된 다음 행동부터 공통 버림 화상 규칙을 적용한다. v4→v5 이전도 기존 정책을 따른다.

## 검증

수정한 규칙 테스트는 45개, 표현 테스트는 20개다. 덱 분석5·인스턴스/저장무결성4·최종 아트2를 합한 **전체 76개가 통과**했다. 실제 내부 브라우저에서도 0비용 와이번 변신의 정상 사용 후 `버림 화상 −2`와 자기 진영의 피해 표시를 확인했다. 정지·재로드 전후 생명47/38과 효과 정리를 확인했다. 전체 UI 검증과 제한은 [카툰 통합 기록](CARTOON-ART-UPDATE.md)에 구분한다.

신규 회귀는 성공·실패·무료 카드의 양쪽 대칭, 회복의 화상 감소 순서, 새 보호막 흡수, 독성 폭발·곰 반격 이후 버림, 다중 타격 한 번 처리, 자원 고갈, 재섞기 제외, 치명 피해 상한·동시 사망, 저장 복원 후 중복 피해 방지와 정확한 HP 표시를 포함한다.

다음 명령은 고정 선택 정책으로 형태별 seed 1~100의 자연 탐험을 실행한다. `--compare-baseline` 옵션은 기존 와이번 회복 유무 비교용이므로 이번 화상 교정의 전후 비교로 사용하지 않았다.

```powershell
node games/wild-oath/tests/balance-campaigns.mjs --seeds 100
```
