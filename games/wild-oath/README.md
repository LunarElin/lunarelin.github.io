# 야생의 서약 · WILD OATH

드루이드 변신을 중심으로 한 **로그라이크 덱 빌딩 오토배틀**이다. 무작위 카드 제시 이벤트에서 시작 덱을 직접 고르고, 탐험과 전투 보상으로 카드를 늘려 다섯 시련에 도전한다. 패배하면 새 덱으로 다시 시작한다. 전투에서는 뽑힌 카드가 자원이 허락하는 만큼 순서대로 자동 충전·사용된다. 늑대·곰·와이번 변신도 덱에 넣은 카드가 사용될 때 발동한다.

## 전투 화면·그래픽

상대 진영은 위쪽 코랄색, 내 진영은 아래쪽 민트색으로 고정한다. 각 진영에 캐릭터·생명·기력, 자기 덱과 사용 카드 자리가 따로 있다. 카드는 자기 덱에서 자기 사용 영역으로 이동하고, 공격은 그 자리에서 상대 캐릭터를 향한다. 상대가 행동해도 다른 쪽의 마지막 카드는 남는다. 낮은 가로 화면에서는 두 진영을 좌우로 나누며 같은 색과 역할 표시를 유지한다.

사용할 카드는 자기 자리에서 확대·강조한 뒤 효과를 발사한다. 4배속에서도 뽑기 140ms·카드 제시 260ms·발사 180ms를 확보한다. 공격·화상·감전·독·방어·회복·기력·변신을 다른 형태와 색으로 표시하며, 연타·반격·독성 폭발은 실제 규칙 순서대로 160ms 간격으로 나온다. 큰 피해 숫자와 생명바가 타격마다 함께 바뀌고, 막은 피해는 별도로 표시한다. 효과음은 로컬 Kenney 타격음과 직접 합성한 준비·속성음을 조합한다. 음원 로딩이나 실패는 전투 진행을 기다리게 하지 않는다.

모션 감소 설정에서는 이동·반동·흔들림을 끄고 대상별 피해를 합산하여 정적인 강조와 숫자를 유지한다. 연출은 저장된 결과를 표시할 뿐 규칙을 다시 실행하지 않는다. 카드 처리 도중 정지하면 표시를 이미 확정된 생명으로 맞추고, 재개 시 다음 행동으로 이어간다. 사용 전 제시 단계에서 정지하면 아직 해당 카드를 소비하지 않는다.

둥근 형태·밝은 색·두꺼운 테두리·입체 그림자를 사용하고 캐릭터·카드·시작 선택·탐험·야영지·도감·팝업에 같은 스타일을 적용한다. Kenney UI Pack 2.0의 CC0 별·화살표·재생·재섞기 SVG를 실제 화면에 사용한다. 캐릭터 아틀라스의 생성 프롬프트, 리소스 원본 경로와 라이선스는 [assets/ART.md](assets/ART.md)에 기록한다.

## 플레이 구조

1. 빈 덱으로 시작한다. 무작위 카드 세 장 중 한 장씩 8번 골라 첫 덱을 만든다.
2. 두 탐험 갈림길 중 하나를 선택한다. 카드 획득 또는 회복 이벤트를 처리한 뒤 야영지에 도착한다.
3. 야영지에서 덱을 편집하고 카드를 구매·판매·합성한다.
4. 전투를 시작하면 현재 차례인 쪽이 덱 맨 위부터 기력이 허용하는 만큼 카드를 연속 사용한다. 플레이어가 카드를 고르거나 변신을 지시하지 않는다.
5. 승리하면 카드 세 장 중 하나를 받고 다음 탐험 갈림길로 간다. 다섯 시련을 통과하면 성공하며, 패배하면 이번 여정이 끝난다.

카드의 충전 비용, 덱 두께, 변신 카드의 비중과 상태 이상 조합이 준비 단계의 판단 요소다. 야영지의 **연계** 버튼에서 내 덱의 변신 고유 능력·연계 조건·함께 쓰는 카드의 보유 여부를 확인한다. 카드 표면에는 짧은 연계 요약을, 상세 창에는 정확한 조건을 표시한다. 전투에서는 집중과 연타 진행, 추격·반격·독성 폭발의 발동을 표시한다.

## 덱 구성·상점

- 시작 생명 70, 골드 10. 고정 시작 카드나 무료 보관 카드는 없다. 첫 선택은 변신 → 저비용 공격 → 방어 → 기력 공급 → 저비용 공격 → 회복 → 자유 → 자유 순서다. 각 회차에 무작위 세 장 중 하나를 골라 8장으로 시작한다. 공격 필수 제시는 비용 2 이하, 기력 필수 제시는 실제 기력을 공급하는 생명의 수액·숲의 양분·불씨 수액으로 구성한다. 카드 종류는 28종이며 플레이어·상점·보상·적이 같은 풀을 사용한다.
- 출전 덱은 6~18장이다. 보관함의 카드를 출전시키거나 덱에서 뺄 수 있다. 전체 소유 카드는 최대 36장이다.
- 시련마다 상점에 카드 3장이 새로 나온다. 구매 비용은 카드별 3~6금화이며 구매한 카드는 보관함에 들어간다. 같은 야영지 안에서 상품을 새로고침하지는 않는다.
- 판매하면 카드 등급만큼 금화 1~3을 얻는다. 같은 카드·같은 등급 두 장은 무료로 합성해 한 단계 올린다. 최대 3등급이며, 판매·합성 후에도 출전 덱 6장을 유지해야 한다.
- 덱·보관함 위의 **일괄 합성**은 가능한 합성 횟수를 표시한다. 한 번 누르면 전체 소유 카드를 같은 카드·등급끼리 최대 3등급까지 연속 합성한다. 출전+보관 → 보관+보관 → 출전+출전 순서로 재료를 고르고 출전 최소 6장을 유지한다. 정렬 표식이 있는 카드의 UID·표식을 남기며, 앞장·뒷장이 각각 붙은 두 장은 함께 합성하지 않는다. 이 경우 개별 카드 관리에서 표식을 조정할 수 있다. 합성 결과는 즉시 자동 저장된다.
- 출전 카드에 선두·후미 정렬 표식을 각각 한 장씩 붙일 수 있다. 전투 시작과 덱 섞기에서 그 카드는 맨 앞·맨 뒤에 배치하고 나머지는 무작위로 섞는다. 같은 표식을 다른 카드에 붙이면 기존 표식은 해제된다.
- 첫 네 승리 뒤 카드 3개 중 하나를 얻고 골드 6·생명 18을 회복한 뒤 다음 탐험으로 간다. 생명은 최대 70까지 회복한다. 보상·탐험 카드는 출전 덱 18장까지 즉시 편입하고 이후에는 보관함에 들어간다. 전체 소유 카드가 36장이면 획득 카드는 골드 3으로 바뀐다. 마지막 시련 승리로 탐험이 끝난다.

### 탐험 이벤트

매 시련 전에 아래 네 종류 중 현재 생명·골드로 선택 가능한 서로 다른 두 곳이 무작위로 나온다. 적어도 한 곳은 카드 획득 경로다. 제시된 길과 카드 후보는 저장되므로 새로고침으로 바뀌지 않는다. 이벤트 비용은 길을 선택할 때 한 번만 지불한다.

| 탐험 | 비용 | 효과 |
| --- | --- | --- |
| 정령의 선물 | 무료 | 무작위 1등급 세 장 중 한 장 선택 |
| 가시덤불 | 생명 6, 현재 생명 7 이상 | 무작위 1등급 세 장 중 한 장 선택을 두 번 |
| 숲의 샘 | 무료 | 생명 12 회복·골드 3 |
| 떠돌이 상인 | 골드 4 | 무작위 2등급 세 장 중 한 장 선택 |

시작 카드 선택과 탐험을 마치기 전에는 야영지 편집·상점·전투를 실행할 수 없다. 이벤트 완료 후 상대 덱과 상점이 한 번 생성된다.

### 상대 덱

상대 덱은 야영지에 도착할 때 생성되어 저장되며, 전투 전에 목록을 확인할 수 있다. 늑대·곰·와이번 중 하나를 중심으로 같은 28종 카드 풀에서 구성한다. 기본 여섯 장은 해당 변신 카드와 야생의 발톱·나무껍질·생명의 수액·숲의 숨결·대지 강타다. 나머지는 전체 풀에 해당 형태의 일반 카드 가중치를 더해 뽑는다.

시련별 상대 덱 크기는 8·10·11·12·14장으로 공통 제한인 6~18장 안에 있다. 형태 카드는 선두 표식을 가진다. 세 번째 시련부터 후미 표식이 추가되고, 네 번째는 일반 카드 한 장·다섯 번째는 두 장이 2등급이다. 등급·표식은 플레이어가 사용하는 것과 같은 규칙을 따른다. 상대만의 추가 피해·무료 보호막·전용 카드는 없다.

## 자동 전투 규칙

- 양쪽 모두 최대 생명 70·드루이드·기력 4·보호막 0으로 시작한다. 플레이어의 현재 생명은 탐험에서 이어지고 상대의 현재 생명은 70이다. 변신 카드가 실제로 사용된 뒤부터 해당 모습의 규칙이 적용된다.
- 자기 차례에는 덱 맨 위 카드부터 한 장씩 뽑고 기력으로 빈 충전 칸을 채운다. 충전이 완료되면 사용한 뒤, 기력이 남아 있고 덱에 카드가 있으면 같은 차례에 다음 카드를 계속 처리한다. 카드 효과로 얻은 기력도 이 연속 사용에 쓸 수 있다.
- 기력이 0이 되면 그 차례는 즉시 끝난다. 다음 카드가 비용 0이어도 다음 자기 차례까지 기다린다. 차례 시작에 뽑힌 비용 0 카드는 충전 없이 발동한다.
- 기력이 모자라 충전을 완료하지 못하면 충전한 상태로 버림 더미에 보내고 차례를 끝낸다. 그 카드는 다음 덱 순환에서 충전을 이어간다.
- 차례 종료마다 기력 1을 얻고 상대에게 차례를 넘긴다. 카드 한 장마다 회복하지 않으며, 덱을 섞는 차례 뒤에도 1을 얻는다. 기력은 최대 30까지 모인다.
- 이미 사용한 카드의 충전은 0으로 돌아간다. 충전은 해당 전투 안에서만 유지되고 새 전투에서는 모두 0으로 시작한다.
- 덱의 마지막 카드를 처리하면 차례를 끝내고, 다음 자기 차례에 버림 더미를 섞는 데 차례 전체를 사용한다. 재정렬한 차례에는 카드를 사용하지 않는다. 덱이 두꺼운 쪽이 선공하며, 동률이면 플레이어가 먼저 행동한다.
- 공격 카드와 방어·회복·충전 카드, 변신 카드가 모두 같은 자동 드로 흐름을 따른다. 전투는 일시 정지·재개와 속도 조절을 제외하면 끝까지 자동 진행된다.

| 늑대 | 앞선 연속 공격당 피해 +2, 최대 +4. 기력 카드는 연타를 유지하며, 세 번째 공격 카드마다 피해 타격을 한 번 추가하는 **추격**이 발동한다. 방어·회복·변신·충전 실패·재섞기는 연타를 끊는다. |
| 곰 | 방어 카드의 보호막 +3, 공격 시 남은 보호막 4마다 피해 +1. 상대 공격을 막으면 막은 양의 절반을 올림하여 최대 6 피해로 한 번 **반격**한다. 반격 피해도 상대 보호막이 흡수한다. 관통 공격에는 반격하지 않고 반격끼리 연쇄 발동하지 않는다. |
| 와이번 | 공격이 보호막을 관통하고 공격 카드마다 맹독 2를 더한다. 이미 중독된 적에게 화상·감전을 거는 카드는 기존 맹독 최대 4를 소모하고 두 배의 관통 피해를 주는 **독성 폭발**을 카드당 한 번 발동한다. 소모한 맹독만큼 생명을 최대 4 회복한다. 방어·기력 카드도 조건을 만족하면 폭발한다. |

변신 카드가 발동하면 이후 카드에 적용되는 형태 규칙이 바뀐다. 전투 중 변신을 직접 고르는 버튼은 없다.

### 카드 연계와 집중

나무껍질·야생의 신호는 **집중**을 최대 12까지 모은다. 다음 성공한 공격이 집중을 모두 사용해 첫 타격에 추가 피해를 주며, 고대의 격노는 그 피해를 두 배로 쓴다. 집중은 충전 실패·방어·회복·변신·재섞기에도 남고 새 전투에서 0으로 초기화된다. 다중 타격·늑대 추격에도 집중 피해는 한 번만 더한다.

전용 연계가 있는 카드는 나무껍질·야생의 신호·쌍발톱·대지 강타·맹독 송곳니·폭풍의 씨앗·숲의 양분·고대의 격노의 8종이다. 중독·화상·감전·보호막 조건은 해당 카드가 발동하기 **전**의 상태로 판정한다. 등급별 수치와 8종 전체 표는 [카드 연계 목록](CARD-REFERENCE.md#카드-연계)에 기록한다. 적도 같은 집중·조건·변신 규칙을 사용한다.

- **늑대:** 공격 → 생명의 수액 또는 야생의 신호 → 공격 → 공격으로 연타를 유지하고 세 번째 공격의 추가 타격을 노린다.
- **곰:** 나무껍질로 보호막·집중을 준비한 뒤 대지 강타의 보호막 조건이나 고대의 격노의 집중 두 배를 발동한다. 상대 공격을 막으면 반격도 이어진다.
- **와이번:** 독쐐기풀·맹독 송곳니로 중독을 준비하고 잿불 가시·폭풍의 씨앗으로 폭발시키며 소모한 맹독만큼 회복한다. 화상 → 폭풍의 씨앗은 추가 감전, 감전 → 숲의 양분은 추가 기력으로 연결된다.

예시는 카드가 해당 순서로 발동하고 필요한 기력·상태가 남았을 때의 조합이다. 실제 드로는 덱 섞기와 앞장·뒷장 표식에 따른다. 추가 타격은 상태 이상·기력 등 카드 전체 효과를 반복하지 않는다.

### 상태 이상

| 상태 | 발동 시점 |
| --- | --- |
| 화상 | 충전에 실패한 카드가 버려질 때 누적 수치만큼 피해를 주고 1 감소한다. |
| 맹독 | 덱을 섞을 때 누적 수치만큼 피해를 주고 절반으로 감소한다. 보호막에는 두 배로 작용한다. |
| 감전 | 감전에 걸린 대상의 상대가 기력을 얻을 때 누적 수치만큼 피해를 주고 1 감소한다. |

화상·감전 피해는 일반 공격과 같이 보호막이 먼저 흡수한다. 회복 카드는 실제로 회복한 생명의 10%를 내림한 수치만큼 화상을 제거한다. 이 상태 이상·치유 처리는 이 게임을 위해 정한 간소화 규칙이며, 참고 자료와 설치된 원작의 모든 세부 조건을 재현한 것은 아니다.

기력 충전 카드는 다음 카드의 빈 충전 칸을 미리 채운다. 기력 감소 카드는 상대가 보유한 기력 풀을 줄인다. 둘은 현재 구현에서 서로 다른 효과이며, 상대 카드의 이미 충전된 칸을 지우지는 않는다.

보호막은 전투 안에서 유지되며 새 전투에서 초기화된다. 양쪽을 합친 41번째 차례부터 그 차례를 끝낸 쪽이 보호막을 무시하는 피로 피해를 받는다. 피해는 두 차례마다 1씩 증가해 무한 방어를 막는다. 연속으로 사용한 카드 수는 피로 차례 수를 늘리지 않는다. 정확한 카드 수치와 전투 상태는 [rules.mjs](rules.mjs)가 기준이다.

## 저장·정지·리소스

- 탐험 저장 키: `wild-oath:v5`. 설정 저장 키: `wild-oath:settings:v1`.
- 자동 저장은 시작 카드의 매 선택, 탐험 갈림길과 비용 결제, 이벤트 카드 선택 중간, 야영지 편집·구매·판매·합성, 자동 전투 행동과 보상 선택을 보존한다. 전투 중 저장도 이미 처리한 카드 효과를 반복하지 않고 다음 행동부터 이어간다.
- v5 키가 **없을 때만** 유효한 `wild-oath:v4` 저장을 읽어 v5로 이전한다. 덱·등급·골드·생명·탐험 후보·전투 차례와 카드 충전은 보존하며, 진행 중 전투 양쪽의 집중은 0으로 시작한다. 이미 처리한 카드를 다시 발동하지 않고 다음 행동부터 새 연계 규칙을 적용한다. 이전 v4 키는 삭제하거나 덮어쓰지 않는다.
- v5 저장이 존재하지만 검증에 실패하면 예전 v4 진행으로 되돌리지 않고 새 탐험을 시작한다. 고정 덱으로 시작하던 v3까지의 탐험도 이어받지 않는다. 설정 키는 유지한다. 버전·단계·후보·덱 구성 검증에 실패한 저장은 무시하며, 저장 실패 시 안내를 표시하고 현재 탭의 플레이는 유지한다.

일시 정지·도움말·숨겨진 탭에서는 전투 타이머와 연출·효과음을 멈춘다. 복귀 시 재개를 기다리며, 페이지 이탈·종료 때 타이머·효과·오디오를 정리한다. 효과음은 사용자가 켠 뒤 로드하고, OGG 디코딩이 불가능하면 합성음으로 대체한다. 시스템 모션 감소 설정을 반영한다.

## 검증

저장소 루트에서 대상 게임과 변경한 홈 연결만 확인한다.

```powershell
node --check games/wild-oath/rules.mjs
node --check games/wild-oath/game.mjs
node --check games/wild-oath/combat-presentation.mjs
node --check games/wild-oath/catalog.mjs
node --check games/wild-oath/tests/serve.mjs
node --test games/wild-oath/tests/rules.test.mjs games/wild-oath/tests/combat-presentation.test.mjs
node games/wild-oath/tests/balance-campaigns.mjs --seeds 100 --compare-baseline
git diff --check -- games/wild-oath index.html portfolio/style.css
```

밸런스 명령은 형태별 동일한 1~100 시드와 고정 선택 정책으로 자연 탐험을 실행한다. 생산 규칙 파일을 변경하지 않고 격리한 모듈에서 와이번 회복만 0으로 바꾼 기준과 비교한다. 결과는 [tests/balance-results.json](tests/balance-results.json), 실제 UI로 세 형태를 다섯 시련까지 플레이한 기록은 [tests/browser-playthroughs.json](tests/browser-playthroughs.json)에 보관한다. 시뮬레이션과 브라우저 플레이는 별도 검증이다.

화면·입력 검증은 직접 진입·홈 왕복, 시작 카드 선택·탐험·덱 성장·자동 전투·일시 정지·재시작, 320~390px 세로와 PC의 글꼴·잘림·터치 영역을 따로 확인한다. 데스크톱의 모바일 뷰포트 검증은 실제 iOS Safari·Android Chrome의 터치·주소창·안전 영역·오디오 검증을 대신하지 않는다. 완료 시 실제 확인한 범위는 [VERIFICATION.md](VERIFICATION.md)에 기록한다.
