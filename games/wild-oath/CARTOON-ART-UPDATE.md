# 카툰 아트와 영상 규칙 검토

2026-10-29. 사용자가 v3의 실사적인 재질과 비직관적인 효과 그림을 지적한 뒤 적용한 후속 변경이다. 현재 아트는 `assets/cartoon-v4/`, UI 보드는 `assets/cartoon-board.svg`다. v1~v3는 제작 이력으로 보존하며 현재 화면에서는 사용하지 않는다.

## 아트 문제와 변경

이전 그림은 털·비늘·나뭇결·숲 배경·역광이 작은 그림 창에 함께 들어갔다. 25개 일반 카드에 12개 그림을 공유하면서 관통 공격에 독니, 선충전에 수액병을 쓰는 등 효과가 혼동되는 문제도 있었다.

`create-game-assets`의 실루엣·색 역할·실제 크기 검토, `game-ui-ux`의 화면·정보 위계, `imagegen`의 내장 생성·출처 기록 절차를 적용했다. 다음 기준으로 새로 제작했다.

- 굵고 짙은 외곽선, 큰 형태, 셀 명암과 선명한 중간색을 사용한다. 실사 재질·세밀한 붓질·파스텔 면을 줄인다.
- 세 변신과 드루이드·수호자·숲 초상화를 같은 카툰 스타일로 통일한다.
- 일반 카드 25종에 서로 다른 그림을 배정한다. 파일명과 카드 ID를 직접 연결해 다른 효과의 그림을 빌리지 않는다. 등급 1~3은 같은 정체성을 유지한다.
- 관통=방패를 뚫는 흰 송곳, 독=초록 독 방울, 선충전=포효와 두 푸른 광점, 방어=방패/가죽, 회복=하트/잎처럼 색과 형태를 함께 사용한다.
- 카드 아틀라스는 가로 패널로 생성하고 전체 패널을 정규화한다. 예전처럼 정사각형 가운데 절반을 잘라 쓰지 않는다. 불균등 행 경계와 1px 이음선은 원본 좌표를 확인해 보정했다.
- 목재의 잔무늬와 황동의 광택을 큰 셀 색면으로 정리했다. 기존 입체적인 두께·접촉 그림자·가독성·터치 크기는 유지했다.

기본 선택·덱·상점·상세·보상·도감·전투·발동 기록·날아가는 카드가 같은 그림을 사용한다. 카드 25개는 실제 이미지 내용의 SHA256도 모두 다르다. 원본 및 80px 초상화·80×40/60×30 카드 접촉 시트를 검토한 후 적용했다. 실제 기기에서 모든 카드의 전투 프레임을 관찰했다는 의미는 아니다.

| 자산 | 규격 | 용량 |
| --- | --- | ---: |
| 초상화 1장 | 1152×768, 3×2 | 183,092B |
| 개별 액션 25장 | 각각 320×160 | 315,792B |
| WebP 합계 | 26개, 550KB 예산 | **498,884B** |
| 원본 카툰 보드 | 512×512 SVG | 1,276B |

v3의 519,088B보다 WebP를 20,204B 줄였다. 상세 프롬프트·원본·권리·정규화·체크섬은 [아트 기록](assets/cartoon-v4/ART.md)과 [manifest](assets/cartoon-v4/manifest.json)에 남긴다. 상용 게임 이미지나 사용자 영상의 그림·음원을 배포하지 않는다.

## 영상에서 확인한 규칙

사용자가 지정한 [영상 53초 이후](https://youtu.be/gyqe3jZ0cYE?t=53)를 Codex 내부 브라우저로 열고, 2:34~2:38의 충전 설명, 3:12~3:14의 충전 유지 설명, 5:50~5:56의 버림·화상 구간을 살펴봤다. 자동 생성 자막도 참고했으며 원문이나 전체 자막을 배포하지 않는다. 로컬 설치본의 알려진 번역 TSV 한 파일에서 관련 키를 읽기 전용으로 대조했다.

확실한 불일치는 **성공 사용 후 버림에도 화상이 발생한다**는 점이었다. 이전 실패 전용 처리를 교정해 성공·실패·무료 카드 모두 카드당 한 번 적용한다. 성공 카드는 회복·새 보호막·폭발·반격을 마친 뒤 화상을 받는다. 셔플 자체에는 화상이 발생하지 않는다. 전투에는 `버림 화상` 칩과 실제 생명 피해 또는 방어 수치를 표시한다.

자원으로 허용되는 만큼 자동 사용, 부분 충전 보존, 턴 종료 회복, 재섞기 휴식, 공용 카드 풀은 유지한다. 성공 후 충전 초기화는 영상에서 명시적으로 확인되지 않아 현재의 독립 정책을 유지했다. 원작의 6승·4패 구조도 이 게임의 5시련 여정과 차이로 기록했다. 영상 전체를 재현했다고 주장하지 않는다. 자세한 근거와 적용 범위는 [영상 규칙 검토](VIDEO-RULES-REVIEW.md)에 있다.

v5 저장 구조는 바꾸지 않았다. 기존 진행을 이어 읽고 다음 카드부터 새 버림 규칙을 적용한다. 이미 저장된 카드의 효과와 화상을 다시 실행하지 않는다.

- 화상은 양쪽 대칭·무료/실패/성공·회복/보호막 순서·폭발/반격 뒤 처리·연타 한 번·치명 상한·동시 사망·저장 후 중복 방지·HP 표현을 검증했다.
- 아트는 28종×3등급 연결, 개별 25그림, 실제 WebP 치수·포맷·체크섬·용량 예산을 검증했다.
- seed1~100의 세 형태 자연 탐험 **300런·1,268전투·39,982행동**, 저장 검증47,956회와 다음 행동 재생3,077회가 일치했다. 완주는 늑대68·곰61·와이번73/100이다. 고정 선택 정책의 시뮬레이션이며 사용자 승률이나 실제 재미와 구분한다. [원본 결과](tests/video-rules-balance.json).

우선 실제 iOS/Android에서 효과 크기·터치·음량·프레임을 확인해야 한다. 곰은 큰 보호막을 쌓아도 관통·맹독 상대에게 약하다는 선택상의 의미가 있었으나, 상태이상 대응 선택지가 충분한지는 여러 새 덱으로 추가 점검할 필요가 있다. 한 번의 패배나 고정 정책의 완주율만으로 일반 승률·장기 재미를 단정하지 않는다.

DOM 수치·실제 선택·승패·정지 복원은 [cartoon-browser-review.json](tests/cartoon-browser-review.json)에 남겼다. 캡처는 Codex 작업 증거 폴더의 `wild-oath-cartoon-*`로 보관하고 게임에는 불러오지 않는다. 실제 휴대폰·청취·FPS 검증과 데스크톱 뷰포트/규칙 시뮬레이션을 구분한다.
