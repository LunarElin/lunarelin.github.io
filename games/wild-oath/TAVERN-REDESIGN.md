# 야생의 서약 · 목재 보드와 영웅 판타지 아트 개편

작업일: 2026-10-29. 상태: **UI·아트·연출 통합, 71개 회귀 테스트와 Codex 내부 브라우저 검증 완료**. 실기기·실제 청취·프레임 계측은 미검증이다.

## 문제와 목표

기존 파스텔 배경, 매끈한 클레이 캐릭터와 옅은 효과색은 카드·인물·보드 사이의 명암 차이가 작았다. 사용자가 요청한 상용 카드 게임의 재질과 타격감을 위해 참고작을 하스스톤으로 정하고, 짙은 목재 보드와 황동, 양피지 카드, 선명한 보석색으로 방향을 바꿨다. 게임의 오리지널 숲 드루이드·늑대·곰·와이번 정체성은 새 삽화에 이어간다.

이 작업은 화면·아트·카드 연출 개선이다. 자원을 기준으로 양쪽이 같은 카드 풀과 규칙에 따라 자동으로 사용하는 로그라이크 덱 빌딩 구조는 유지한다.

목재·황동·양피지·보석색 조합과 아래의 구현 결정은 이 프로젝트를 위한 해석이다. 참고 자료가 최신 버전의 디자인 명세라는 뜻은 아니다. 공식 이미지·카드 프레임·로고·특정 캐릭터·음원은 배포물에 반입하지 않았다. 새 삽화는 이 프로젝트의 기존 생성 캐릭터를 정체성 참고로 사용해 다시 생성했다.

## 소스에 반영한 내용

### 아트 연결

`card-art.css`의 초상화는 `assets/tavern-v3/portraits.webp`를 사용한다. 3열×2행의 대상 순서는 늑대·곰·와이번 / 드루이드·수호자·빈 숲이며 기존 CSS 좌표와 호환된다. `index.html`의 초상화 preload도 새 경로다.

일반 카드의 12개 액션 계열은 `assets/tavern-v3/cards/`의 개별 WebP로 연결했다. 파일은 `claw`, `bite`, `bark`, `mend`, `sap`, `venom`, `ember`, `storm`, `pounce`, `ancient`, `frost`, `moonwell`이다. 2:1 그림은 `cover center`로 표시하며 초상화 아틀라스 배율을 적용하지 않는다. 여러 카드가 같은 액션 계열 그림을 공유한다.

### 카드 제시와 접촉

`combat-presentation.mjs`와 `game.mjs`에서 드로우 → 제시 → 보드 접촉 → 발사 → 타격 → 정착을 나눈다. 사용할 수 있는 카드만 보드 접촉과 접촉음을 낸 후 효과를 발사한다. 기력이 부족한 카드는 충전·버림 안내를 유지한다.

일반 모션의 최소 시간은 드로우 140ms, 제시 260ms, 접촉 80ms, 효과 이동 180ms, 타격 간격 160ms다. 배속이 올라가도 이 최소 구간을 확보한다. `combat-fx.css`에는 카드의 들어 올리기·내리치기·착지 파문과 속성별 궤적·충격 모양을 반영했다.

### 타격 강약과 정보

`impactFeedback()`은 실제 피해가 있는 강타, 일반 타격, 연계 타격, 전부 방어한 타격을 구분한다. 강타 조건은 원시 피해 14 이상 또는 독성 폭발 반응 피해 6 이상이며, 실제 생명 피해가 있어야 한다. 강타에는 60ms의 시각적 정지감과 큰 충격·반동을 사용한다. 이 정지감은 전투 규칙의 시간이나 피해를 변경하지 않는다.

피해 숫자와 생명바는 각 타격 결과에 맞춰 바뀐다. 전부 막았을 때는 방어 피드백을 사용하고, 피해와 흡수가 함께 있으면 보호막 감소를 별도로 표시한다. 모션 감소에서는 카드 이동·내리치기·흔들림을 줄이고 대상별 합계 숫자와 정적인 강조를 유지한다. 효과 노드 상한과 정리 로직을 유지한다.

UI 전체의 재질·진영색은 `ui-polish.css`, 도감은 `catalog-theme.css`에 적용한다. 원본 `assets/tavern-board.svg`는 필터나 외부 이미지 없이 반복 목재 무늬를 만든다. 실제 화면 점검에서 배경 shorthand 충돌, 320px 진행 표식 잘림, 양피지 위 즉시 발동 문구와 재섞기 아이콘의 대비를 발견해 수정했다.

## 생성 자산과 예산

| 묶음 | 최종 규격 | 파일 수 | 용량 |
| --- | --- | ---: | ---: |
| 초상화·전장 | 1152×768, 3×2, 셀 384×384 | 1 | 283,048 bytes |
| 카드 액션 | 각각 320×160 | 12 | 236,040 bytes |
| 전체 | 불투명 sRGB WebP, 품질 82 | 13 | **519,088 bytes** |

전체 이미지 예산은 **550KB**다. 초기 캐릭터와 v2 카드 family의 449,182 bytes보다 69,906 bytes 늘었으며 붓질과 작은 효과 형태의 명확성을 위해 품질 82를 유지했다. 큰 생성 원본 PNG와 접촉 시트는 배포하지 않는다. 초상화는 미리 읽고 카드 그림은 필요한 표시에서 사용한다.

`characters-pop.webp`와 `cards-v2/`는 제작 이력·정체성 참고용으로 보존하며 현행 런타임에서 사용하지 않는다. 신규 생성·정규화·프롬프트·출처는 [assets/tavern-v3/ART.md](assets/tavern-v3/ART.md), 파일별 치수·용량·SHA256은 [assets/tavern-v3/manifest.json](assets/tavern-v3/manifest.json)에 기록한다. 생성 이미지와 Kenney CC0 리소스의 출처·권리를 구분한다.

## 완료한 자산 검토

- 초상화 원본과 90px 셀 접촉 시트의 성숙한 비율·명암·얼굴 식별 확인.
- 카드 원본과 160×80 접촉 시트의 12계열·큰 효과 모양·중앙 가로 crop 확인.
- 새 초상화를 스타일 기준으로 선택한 후 같은 원본을 참조해 카드 family 생성.
- 13개 최종 WebP의 형식·실제 치수·파일 용량·SHA256을 manifest와 대조해 통과.

이 검토는 이미지 자산 검토다. 게임 안에서 읽히는 크기·효과의 타이밍·모바일 조작·사람이 느끼는 타격감을 증명하지 않는다.
