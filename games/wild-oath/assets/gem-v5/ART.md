# 보석 마법 마스코트 아트 · v5

2026-10-30 사용자의 “캐치티니핑 스타일로 아트풍 변경” 요청에 따라 만든 **야생의 서약 전용 원본 아트**다. 부모 작업자가 생성 원본 초상화·일반 카드 세 묶음·가로 변신 카드 묶음을 직접 보고 새 방향으로 선택했다. 기존 `cartoon-v4/` 원본과 가공 파일은 이력으로 보존한다.

## 시각 기준

- 큰 보석 같은 눈, 둥근 치비 얼굴과 짧은 주둥이, 작은 코, 부드러운 볼을 가진 마법 마스코트 비율.
- 사진 같은 털·피부·비늘이나 굵은 검은 만화선 대신, 매끈한 장난감 같은 표면·부드러운 3D 명암·금속과 투명 보석의 밝은 면을 사용한다.
- 색은 사파이어·청록·자수정·에메랄드·호박색 중심의 선명한 보석색이다. 얼굴의 크림색과 어두운 보석색 배경을 분리한다.
- 늑대는 은백색·삼각 귀·청색 보석과 초록 잎 목도리, 곰은 꿀색·둥근 귀·호박색 암석 갑옷, 와이번은 비취색·뿔·접힌 날개·보라색 보석으로 구분한다. 드루이드는 초록 후드·금빛 뿔 티아라·잎 지팡이, 나무 수호자는 나무 얼굴과 잎 왕관을 유지한다.
- 카드마다 큰 중심 모양 하나를 우선한다. 회복은 초록 하트, 맹독은 연두 액체 방울, 기력은 금빛 별, 선충전은 푸른 구체 두 개를 유지한다. 강화 등급이 달라도 같은 카드의 삽화는 바뀌지 않는다.

공식 스타일 참고는 내부 브라우저에서 확인한 [더티니핑 공식 상품 이미지](https://theteenieping.com/products/137419126)다. 큰 눈·둥근 비율·매끈한 부피·보석 장식의 시각 특성을 참고했으며, 그 이미지를 생성 입력이나 배포 파일로 복사하지 않았다. 생성 입력은 아래의 프로젝트 자체 초상화 원본뿐이다. 상용 시리즈의 캐릭터·이름·로고를 게임에 반입하지 않았다.

## 실행 자산과 규격

| 자산 | 규격 | 실제 용량 | 용도 |
| --- | --- | ---: | --- |
| `portraits.webp` | 1152×768, 3열×2행, 칸 384×384 | 187,732 B | 늑대·곰·와이번·드루이드·수호자·빈 숲 |
| `cards/*.webp` | 25개, 각 320×160 | 317,852 B 합계 | 일반 카드별 독립 삽화 |
| `forms/*.webp` | 3개, 각 320×160 | 43,320 B 합계 | 늑대·곰·와이번의 전용 가로 변신 카드 |
| `board.svg` | 512×512 반복, 코드로 제작 | 1,591 B | 낮은 대비의 보석·덩굴 바탕 |

**WebP 29개 합계는 548,904 B**다. 전체 550,000 B·일반 카드 350,000 B 이내다. `card_bytes`는 일반 카드 25개만, `form_bytes`는 변신 카드 3개, `total_bytes`는 초상화·일반 카드·변신 카드 29개 전체를 뜻한다. 이미지에 글자·버튼·판정 영역을 그려 넣지 않는다. 한글·수치·입력은 기존 HTML/CSS로 유지한다. 초상화는 기존 3×2 좌표, 일반·변신 카드는 각각 전용 2:1 슬롯과 부드러운 필터링을 사용한다. 모든 이미지는 sRGB의 불투명 RGB WebP다. 별도 충돌·물리 역할은 없다.

## 생성 출처와 전체 프롬프트

OpenAI 내장 **`image_gen` 도구**로 새로 생성했다. CLI/API 대체 경로는 사용하지 않았다. 모델 이름과 생성 ID는 도구 결과가 공개하지 않아 `not exposed by tool`로 기록한다. 파일명·원본 해상도·SHA256·생성/참고 관계는 [manifest.json](manifest.json)에 보관한다. 생성 이미지를 CC0 파일이라고 표시하지 않는다. WebP 변환이 생성 원본의 내장 provenance 메타데이터를 보존한다고 보장하지 않으므로, 원본 PNG는 생성 보관 폴더에 그대로 남기고 전체 프롬프트도 함께 기록했다.

## 결정적 정규화

[normalize.py](normalize.py)는 생성·수정 도구가 아니라 선택된 PNG를 자르고 크기를 맞춰 인코딩하는 자산 파이프라인이다. 원본에 덧그리기·재색칠·새 이미지 생성·원본 덮어쓰기를 하지 않는다. Python과 Pillow는 제작/검증 전용이며 게임 런타임 의존성이 아니다.

1. 초상화 1536×1024 원본을 Lanczos로 1152×768로 축소하고 WebP 품질 80·method 6으로 저장했다.
2. 1774×887 카드 원본은 가로 경계 `0/592/1183/1774`를 사용한다. 세로 경계는 A `0/296/574/887`, B `0/296/583/887`, C `0/295/590/887`이다. 원본의 행은 완전히 같은 높이가 아니므로 시각 확인과 행/열 인접 픽셀 차이를 함께 확인했다.
3. 이웃 셀의 색이 섞이지 않도록 내부 경계의 원본 2px를 제외했다. 각 패널 전체를 320×160으로 Lanczos 축소했다. 중앙 일부만 잘라 재구성하지 않았으며, 행 높이 차이는 약한 전체 패널 종횡비 정규화로 처리했다.
4. 카드는 WebP 품질 78·method 6으로 저장했다. B/C의 마지막 빈 칸은 출력하지 않았다. 파일마다 원본 칸·정확한 crop box·실제 출력 크기·바이트·SHA256을 기록했다.
5. 변신 카드는 정사각 초상화를 긴 슬롯에 확대해 얼굴이 잘리는 문제를 피하기 위해 전용 가로 구도로 추가 생성했다. 1024×1536 원본의 1열×3행을 세로 경계 `0/510/985/1536`에서 나누고 내부 경계의 2px만 제외한 전체 패널을 320×160으로 축소했다. WebP 품질은 76·method 6이며 늑대 14,488 B·곰 14,364 B·와이번 14,468 B다. 이 추가 때문에 기존 초상화·일반 카드 품질이나 해시를 바꾸지 않았다.
6. `board.svg`는 프로젝트에서 직접 작성한 낮은 대비의 원본 벡터 패턴이다. 외부 원본이나 생성 PNG에서 추출하지 않았다.

```powershell
& '<bundled-python>/python.exe' games/wild-oath/assets/gem-v5/normalize.py `
  --source-dir '<CODEX_HOME>/generated_images/01a15e8e-97b4-7fb0-b8bd-d7e699a3c9c7' `
  --preview '<evidence-directory>/gem-v5-preview.png'
```

## 실제 확인 범위

최종 WebP를 실제 디코드한 접촉 시트에서 초상화 130×130, 일반·변신 카드 160×80 및 80×40을 원래 배율로 확인했다. 초상화 6종의 실루엣·큰 눈, 25개 일반 카드의 서로 다른 중심 모양, 전용 변신 카드 3개의 넓은 구도, 경계 혼입·글자·프레임의 부재를 확인했다. 작은 카드에서는 반짝임·장식의 세부가 줄어들지만 방패·하트·방울·별·씨앗·두 발톱·파고드는 가시의 큰 모양은 남는다.

이 검토는 정지 자산의 선택·기술 검증이다. 이후 내부 브라우저에서 수행한 실제 전투·카드 돌진·도감·모바일 크기 배치 검토는 [통합 검증 기록](../../GEM-ART-UPDATE.md)에 따로 기록한다. 실물 휴대폰·전 배속/효과 조합·FPS와 청취는 미검증이다.
