# 야생의 서약 · UI와 카드 아트 기준

## 현행 방향 · 2026-10-29

밝은 파스텔·토이/클레이 방향을 **목재 게임판, 황동 테두리, 양피지 카드와 선명한 보석색**으로 바꾼다. 친숙한 상용 카드 게임 참고작은 하스스톤으로 정했다. 둥근 조작부와 큰 한글 정보는 유지하면서 재질의 두께·접촉 그림자·명암 대비를 강화한다. 캐릭터는 성숙한 숲의 드루이드와 야수로 다시 그렸다.

공식 시각 참고는 [Hearthstone: Battlegrounds Press Kit](https://blizzard.gamespress.com/en/Hearthstone-Battlegrounds-Press-Kit), 연출 원칙 참고는 [Developer Insights: The Art Behind THE SCIENCE](https://hearthstone.blizzard.com/en-us/news/22552047)다. 후자의 정보 전달, 정체성을 드러내는 색·형태, 중요한 순간에 강약을 주는 원칙을 이 게임의 자동 전투에 적용한다. 두 자료의 공개일은 각각 2019-11-05와 2018-10-26이며, 최신 업데이트의 화면이라고 주장하지 않는다. 참고작의 로고·캐릭터·카드·텍스처·UI 이미지나 음원을 배포물에 사용하지 않는다.

| 조건 | 현행 기준 |
| --- | --- |
| 렌더러·화면 | 기존 2D DOM/CSS, 휴대폰 320~390px 세로 우선. 양쪽 덱과 사용 카드 영역을 분리한다. |
| UI 재질 | 짙은 월넛 목재와 절삭 면, 황동의 밝은 모서리와 어두운 바닥 면, 따뜻한 양피지와 짙은 글자. 상단 왼쪽 광원과 접촉 그림자를 맞춘다. |
| 팔레트 | 넓은 면은 짙은 갈색·남청색·숲색으로 억제한다. 사파이어·루비는 양쪽 진영, 비취·호박색·보라는 효과와 변신의 강조색으로 사용한다. 금색은 주요 행동과 힘의 강조에 집중한다. |
| 캐릭터 | 은빛 늑대, 호박색 돌 갑옷 곰, 비취 와이번, 뿔 후드 드루이드, 이끼 수호자, 어스름 숲. 유아·장난감 비율 대신 성숙한 실루엣과 붓질을 사용한다. |
| 삽화 광원 | 왼쪽 위의 따뜻한 테두리 빛과 짙은 청록 그림자. 얼굴·발톱·마법 등 초점만 선명하게 밝혀 작은 창에서도 동작을 구분한다. |
| 카드 그림 | 불투명 sRGB WebP 320×160, 중심 pivot, 충돌 없음. 핵심 동작은 중앙 가로 띠 안에 두고 `cover center`로 사용한다. 그림 안 글자·UI 테두리는 넣지 않는다. |
| 초상화 | `tavern-v3/portraits.webp`, 1152×768, 3열×2행, 각 셀 384×384. 기존 여섯 대상의 셀 좌표를 유지한다. 액션 close-up을 초상화에 재사용하지 않는다. |
| 연출 | 덱에서 이동 → 카드 제시 → 보드 접촉 → 효과 발사 → 타격 → 정착을 구분한다. 강한 피해·연계·방어의 크기와 색을 다르게 하고 모션 감소에서는 이동·흔들림을 줄인다. |
| 가독성 | 주요 수치 28~40px, 행동·상태 18~22px, 설명 16px 이상을 목표로 한다. 터치 영역 44px 이상과 로컬 Do Hyeon을 유지하며 장식이 글자와 숫자를 가리지 않게 한다. |
| 자산 예산 | v3 런타임 이미지 13개 합계 **519,088 bytes**, 전체 상한 **550KB**. 초상화 283,048 bytes와 카드 12종 236,040 bytes다. 생성 원본 PNG와 접촉 시트는 배포하지 않는다. |

현재 `card-art.css`는 초상화와 12개 액션 계열을 모두 `tavern-v3/`에 연결한다. 기존 `characters-pop.webp`와 `cards-v2/`는 제작 이력·정체성 참고용으로 보존하며 현행 런타임에서 사용하지 않는다. 원본은 삭제하거나 새 파일로 덮어쓰지 않는다.

새 초상화와 카드 접촉 시트의 스타일·실루엣·중앙 crop 확인 및 13개 WebP의 치수·용량·SHA256 검증을 마쳤다. **게임에 통합한 실제 브라우저 화면, 320~390px 배치, 터치·색감·동작 평가는 아직 대기 중**이다. 생성·프롬프트·정규화는 [tavern-v3/ART.md](tavern-v3/ART.md), 파일별 기록은 [tavern-v3/manifest.json](tavern-v3/manifest.json), 구현·검증 진행은 [TAVERN-REDESIGN.md](../TAVERN-REDESIGN.md)를 기준으로 한다.

## 이전 방향 · 2026-10-28 · 이력 보존

아래는 v2 당시의 제작·검증 기록이다. 당시 색감과 자산 수치는 현행 방향에 적용하지 않는다.

2026-10-28. `game-ui-ux`·`create-game-assets`를 기존 DOM/CSS 게임에 적용한다. 게임의 둥글고 팝한 방향은 유지한다. 대표 스타일은 이미 사용 중인 [캐릭터 아틀라스](characters-pop.webp)로 선택했다.

| 조건 | 구현 기준 |
| --- | --- |
| 렌더러·카메라 | 2D DOM/CSS, 고정 HUD·분리된 양쪽 진영. 새 엔진·외부 런타임 없음. |
| 화면 | 휴대폰 320~390px 세로 우선, 낮은 가로 화면은 기존 좌우 진영. |
| 삽화 | 불투명 sRGB WebP 320×160, 중심 pivot, 충돌 없음, 부드러운 필터·cover crop. 텍스트는 모두 코드와 로컬 Do Hyeon. |
| 실 표시 | 카드 선택의 약65×75px 장식 창, 도감 상세225×112.5px, 낮은 전투의 일반 카드 그림 높이30px. 읽을 정보와 효과 실루엣을 우선한다. |
| 부피·재질 | 둥근 실루엣, 두꺼운 모서리, 크림 하이라이트·중간 면·짙은 접촉 그림자. 토이/클레이와 매끈한 나무·돌·유리. |
| 광원 | 왼쪽 위의 부드러운 빛, 오른쪽 아래 접촉 그림자. |
| 팔레트 | 민트=내 진영, 코랄=상대, 금색=주요 행동/기력, 푸른색=비용/얼음, 녹색=치유/독, 보라+노랑=번개. 색에 이름·숫자·서로 다른 모양을 함께 쓴다. |
| 밀도 | 얼굴 그림을 일반 카드마다 반복하지 않고 효과의 큰 물체·동작으로 구분. 작은 입자·사진 같은 잡음·이미지 내 글자는 제외. |
| UI | 밝은 배경 장식을 낮추고 크림·이끼색 테두리와 그림자를 통일. 주요 수치28px, 설명16px, 버튼18px 이상·터치44px 이상. |
| 자산 예산 | 새 카드 family 12개, 총153,470 bytes. 필요한 카드가 표시될 때 CSS에서 로드하며 대형 생성 원본은 배포하지 않는다. |

### 당시 선택과 승인 근거

기존 캐릭터 아틀라스를 스타일 기준으로 고르고 내장 ImageGen으로 액션 삽화를 생성했다. 12칸 배열·크기·색·실루엣·중앙 crop을 접촉 시트에서 검사했다. 통합 뒤 Codex 내부 브라우저에서 대표 삽화들을 선택·덱·상점·보상·도감·전투의 실제 크기로 확인했다. 원작이나 특정 작가의 자산은 사용하지 않았다.

변신 카드는 형태 식별을 위해 기존 캐릭터를 사용한다. 일반 카드 25종은 12개 효과 계열을 공유한다. 같은 효과 계열의 카드까지 모두 고유한 그림을 가진 것은 아니다. 액션 close-up을 초상화에 재사용하지 않는다.

생성 프롬프트·참조·가공 좌표·출처·제한은 [cards-v2/ART.md](cards-v2/ART.md), 파일별 체크섬·상태는 [cards-v2/manifest.json](cards-v2/manifest.json)에 기록한다. 실제 기기의 색·프레임 성능·터치 검증은 남아 있다.
