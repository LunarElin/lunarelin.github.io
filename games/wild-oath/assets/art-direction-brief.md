# 야생의 서약 · UI와 카드 아트 기준

## 현행 방향 · 카툰 v4 · 2026-10-29

**큰 동작과 명확한 실루엣이 먼저 읽히는 2D 잉크 카툰**을 기준으로 한다. v3의 세밀한 사실적 털·비늘·재질·역광은 축소하면 배경과 섞였고, 여러 카드가 같은 그림을 공유해 다른 효과를 같은 기능처럼 보이게 했다. 초상화와 액션 그림을 굵은 외곽선·2~3단 셀 명암으로 다시 만들고, 일반 카드 25종에 각각 다른 모티프를 부여한다. 작은 화면을 위해 글씨를 줄이거나 파스텔·장난감 재질로 되돌리지 않는다.

`create-game-assets`의 대표 시안 선택·계열 제작·실제 크기 검토, `imagegen`의 내장 생성·참조·결정적 정규화, `game-ui-ux`의 모바일 가독성 기준을 함께 적용한다.

| 조건 | v4 현행 기준 |
| --- | --- |
| 렌더러·화면 | 기존 2D DOM/CSS, 휴대폰 320~390px 세로 우선. 분리된 양쪽 덱·사용 카드 영역과 낮은 가로 화면의 좌우 진영을 유지한다. |

| 카드 그림 | 불투명 sRGB WebP 320×160, 중심 pivot, 충돌 없음. 패널 전체의 주제 한 개와 핵심 동작을 크게 배치한다. 텍스트·숫자·카드 프레임은 그림에 굽지 않는다. |
| 개별 정체성 | 변신 3종은 각 형태의 초상화, 일반 25종은 카드 ID별 개별 그림. 강화해도 같은 카드의 정체성을 유지한다. 관통과 독, 기력 공급과 선충전, 공격 가시와 방어 가시를 공유 그림으로 묶지 않는다. |
| 가공·표시 | 원본 가로 패널의 실측 경계를 분리하고 내부 이음선 1px을 제외해 전체 패널을 정규화한다. v3의 정사각형 중앙 절반 crop은 쓰지 않는다. 의미적 재합성·다시 그리기 없이 결정적인 크기·포맷 가공만 한다. `cover center`로 표시하고 초상화 3×2 배율을 일반 카드에 적용하지 않는다. |
| UI·재질 | `cartoon-board.svg`의 넓은 판자 2개와 적은 목선·리벳 4개로 바탕 소음을 줄인다. 종이·황동·기력 보석도 큰 셀 색면과 짙은 모서리, 접촉 그림자로 부피를 남긴다. |
| 가독성 | 로컬 Do Hyeon과 주요 수치 28~40px, 행동·상태 18~22px, 설명 16px 이상, 터치 영역 44px 이상을 유지한다. 필수 입력을 hover에 의존하지 않는다. |
| 연출 | 카드 이동·제시·접촉·발사·타격·정착을 구분한다. 실제 피해·보호·연계와 다른 강도로 꾸미지 않으며, 모션 감소에서는 이동·흔들림 대신 읽히는 정적 강조를 남긴다. |
| 자산 예산 | WebP 26개 합계 **498,884 bytes**: 초상화 183,092 bytes, 개별 액션 25개 315,792 bytes. 이미지 상한은 **550,000 bytes**. 원본 SVG 보드는 별도 1,276 bytes. 생성 원본 PNG와 접촉 시트는 배포하지 않는다. |

`card-art.mjs`는 변신 여부를 먼저 확인하고 일반 카드의 ID를 직접 `illustration-<id>`에 연결한다. 현재 CSS와 preload는 `cartoon-v4/`를 사용한다. 초기 캐릭터·v2·v3 이미지와 이전 목재 SVG는 삭제하거나 덮어쓰지 않고 이력으로 보존하며 현행 화면에서 사용하지 않는다.

대표 초상화 원본과 80px 접촉 시트를 확인해 스타일을 선택한 뒤 그 시안을 참고해 카드 계열을 생성했다. 제작 담당자가 25개 카드의 전체 패널·실측 격자 경계와 160×80·80×40·60×30 접촉 시트, 26개 WebP의 치수·포맷·용량·SHA256을 검토했다. **새 그림과 UI를 통합한 실제 브라우저·320~390px 화면·정지/재개·직관성 평가는 통합 담당자의 별도 검증 대상**이다. 접촉 시트나 자동 검증만으로 실기기 품질을 확정하지 않는다.

생성 프롬프트·참조·정규화·권리 기록은 [cartoon-v4/ART.md](cartoon-v4/ART.md), 최종 파일별 수치는 [cartoon-v4/manifest.json](cartoon-v4/manifest.json), 폰트·Kenney 자산·이전 제작 이력은 [ART.md](ART.md)를 따른다.

## 이전 방향 · 영웅 판타지 v3 · 2026-10-29 · 이력 보존

아래는 v3 당시의 방향이다. 붓질·세밀한 재질과 12개 공용 액션 계열은 현행 기준이 아니다.

당시 밝은 파스텔·토이/클레이 방향을 **목재 게임판, 황동 테두리, 양피지 카드와 선명한 보석색**으로 바꿨다. 친숙한 상용 카드 게임 참고작은 하스스톤으로 정했다. 둥근 조작부와 큰 한글 정보는 유지하면서 재질의 두께·접촉 그림자·명암 대비를 강화했다. 캐릭터는 성숙한 숲의 드루이드와 야수로 다시 그렸다.

공식 시각 참고는 [Hearthstone: Battlegrounds Press Kit](https://blizzard.gamespress.com/en/Hearthstone-Battlegrounds-Press-Kit), 연출 원칙 참고는 [Developer Insights: The Art Behind THE SCIENCE](https://hearthstone.blizzard.com/en-us/news/22552047)다. 후자의 정보 전달, 정체성을 드러내는 색·형태, 중요한 순간에 강약을 주는 원칙을 이 게임의 자동 전투에 적용한다. 두 자료의 공개일은 각각 2019-11-05와 2018-10-26이며, 최신 업데이트의 화면이라고 주장하지 않는다. 참고작의 로고·캐릭터·카드·텍스처·UI 이미지나 음원을 배포물에 사용하지 않는다.

v3 당시 `card-art.css`는 초상화와 12개 액션 계열을 모두 `tavern-v3/`에 연결했다. 기존 `characters-pop.webp`와 `cards-v2/`는 제작 이력·정체성 참고용으로 보존했다. 이후 v3도 현행 런타임에서 제외했으며 원본은 삭제하거나 새 파일로 덮어쓰지 않는다.

당시 초상화와 카드 접촉 시트의 스타일·실루엣·중앙 crop, 13개 WebP의 치수·용량·SHA256을 검증했다. v3 생성·프롬프트·정규화는 [tavern-v3/ART.md](tavern-v3/ART.md), 파일별 기록은 [tavern-v3/manifest.json](tavern-v3/manifest.json), 당시 실제 내부 브라우저 검증과 제한은 [TAVERN-REDESIGN.md](../TAVERN-REDESIGN.md)를 기준으로 한다. 이 기록은 v4나 실제 휴대폰 검증을 대신하지 않는다.

## 이전 방향 · 2026-10-28 · 이력 보존

아래는 v2 당시의 제작·검증 기록이다. 당시 색감과 자산 수치는 현행 방향에 적용하지 않는다.

2026-10-28. `game-ui-ux`·`create-game-assets`를 기존 DOM/CSS 게임에 적용한다. 게임의 둥글고 팝한 방향은 유지한다. 대표 스타일은 이미 사용 중인 [캐릭터 아틀라스](characters-pop.webp)로 선택했다.

### 당시 선택과 승인 근거

기존 캐릭터 아틀라스를 스타일 기준으로 고르고 내장 ImageGen으로 액션 삽화를 생성했다. 12칸 배열·크기·색·실루엣·중앙 crop을 접촉 시트에서 검사했다. 통합 뒤 Codex 내부 브라우저에서 대표 삽화들을 선택·덱·상점·보상·도감·전투의 실제 크기로 확인했다. 원작이나 특정 작가의 자산은 사용하지 않았다.

변신 카드는 형태 식별을 위해 기존 캐릭터를 사용한다. 일반 카드 25종은 12개 효과 계열을 공유한다. 같은 효과 계열의 카드까지 모두 고유한 그림을 가진 것은 아니다. 액션 close-up을 초상화에 재사용하지 않는다.

생성 프롬프트·참조·가공 좌표·출처·제한은 [cards-v2/ART.md](cards-v2/ART.md), 파일별 체크섬·상태는 [cards-v2/manifest.json](cards-v2/manifest.json)에 기록한다. 실제 기기의 색·프레임 성능·터치 검증은 남아 있다.
