# 잉크 카툰 아트 v4

2026-10-29. `create-game-assets`와 `imagegen` 스킬을 적용했다. 사용자가 거절한 실사풍·붓질의 v3를 바탕으로 필터 처리하지 않고, 굵은 외곽선·셀 채색·큰 액션 모티프로 새로 생성했다. 게임 코드·색 팔레트·카드 규칙은 이 폴더에서 변경하지 않았다.

## 시각 기준과 선택

초상화 원본과 80px 셀 접촉 시트를 root가 확인하고 이 시안을 공통 스타일로 선택했다. 은빛 늑대·호박 돌갑옷 곰·비취 와이번 / 뿔 후드 드루이드·이끼 수호자·빈 숲의 3×2 순서를 유지한다. 단순한 색면, 검은 외곽선과 큰 얼굴/도구 실루엣을 우선하며 개별 털·비늘·사진식 림라이트를 배제했다. 통합 후 실제 게임 크기에서 대표 초상화·액션 계열의 crop과 가독성도 검토했다. 배경의 나뭇잎과 수호자는 다른 초상화보다 세부가 많다는 특성은 남는다.

일반 카드 25종은 각 카드 ID에 대응하는 독립 그림을 사용한다. 관통은 흰 바람 송곳과 파란 방패, 독은 흰 독니와 녹색 방울, 선충전은 늑대 포효와 두 푸른 광점, 기력 감소는 기력 별을 깨무는 늑대 턱으로 구별한다. 방어형 불가시와 공격형 불가시, 나무 방패와 곰가죽도 다른 실루엣을 쓴다. 치유의 하트·회복 이슬과 독 방울은 물체/주변 모티프를 다르게 했다.

## 배포 파일·정규화

| 파일 | 최종 규격 | 파일 수 | 용량 |
| --- | --- | ---: | ---: |
| `portraits.webp` | 1152×768, 3×2, 셀384×384 | 1 | 183,092B |
| `cards/<card-id>.webp` | 각각320×160, 카드별 고유 그림 | 25 | 315,792B |
| 합계 | 불투명 RGB/sRGB WebP, 품질82·method6 | 26 | **498,884B** |

전체 이미지 550,000B 예산을 지켰다. v3의 519,088B보다 전송량은20,204B 작지만, 고유 그림이 늘어 모든 이미지를 디코딩한 픽셀 메모리는 약8.26MiB다. 이 값은 실제 기기의 GPU/메모리 계측을 대체하지 않는다. 카드 그림은 필요한 요소에서 사용하고 원본 아틀라스와 접촉 시트는 배포하지 않는다.

초상화 원본1536×1024는 1152×768로 Lanczos 축소했다. 카드 아틀라스 A/B/C는 각각1774×887로 전체2:1이며, 가로패널을3×3으로 배치했다. 실제 경계는 원본의 색 변화와 화면을 확인해 분할했다. A의 행 높이는 모델 출력에서296/274/317px로 고르지 않아, 단순3등분하면 옆 그림이 섞였다. 이 원본 경계를 보정하고 내부 이음의1픽셀만 제외한 전체 패널을320×160으로 정규화했다. 중앙 절반 crop이나 의미적 재합성은 하지 않았다. B/C의 마지막 빈 셀은 저장하지 않았다. 모든 파일의 실제 원본 좌표·크기·SHA256은 [manifest.json](manifest.json)에 있다.

## 검증 범위

- 원본 네 장의 셀 순서, 텍스트/프레임 혼입 여부와 초상화3×2·액션3×3 구성 확인.
- 160×80, 80×40, 60×30 접촉 시트에서 25개 카드의 주요 물체와 효과 방향을 확인.
- 발톱1회/두 발2회, 방어/찌르기, 독니/관통 송곳, 기력 방울/선충전, 나무/가죽의 차이 확인.
- 총26개 최종 WebP의 실제 규격·포맷·용량·고유 SHA256을 manifest와 대조.
- 통합 담당자가 Codex 내부 브라우저의 PC1280×720, 세로390×640·320×640, 가로844×390에서 탐험·선택·덱·상점 아트·분석 상세·도감·보상·전투·결과의 대표 아트 계열을 확인했다.
- 도감 DOM에서 카드28종 중 일반 액션25종과 고유 이미지 URL25개를 확인했다. 실제 화면에서 독니와 관통 송곳, 충전 포효와 기력 수액, 얼음과 나무 방어의 구분을 검토했다.
- 기존 v5 진행으로3·4·5시련 승리를 확인했고 새 곰8장 초안도 플레이했다. 이는 모든 카드·모든 등급의 전투 프레임을 각각 관찰했다는 뜻이 아니다.
- 전체26개 이미지의 헤더·치수·SHA·고유성·예산 검사가 통과했고, 통합 후 대상 게임 회귀 테스트76개도 통과했다. 세부 결과는 [통합 검증 기록](../../CARTOON-ART-UPDATE.md)에 있다.
- 실제 iOS/Android 기기, 스피커·헤드폰 청취와 FPS/GPU/발열 계측은 미검증이다. 데스크톱의 모바일 뷰포트와 접촉 시트 검토를 실기기 성능·타격감 검증으로 간주하지 않는다.

## 출처와 권리

도구는 OpenAI 내장 `image_gen`이며 모델 이름/버전은 도구가 공개하지 않았다. 생성 ID는 `01a18344-562a-75f0-98cc-e996fbbf4014`다. 네 원본은 기본 생성 보관 경로에 보존한다.

| 묶음 | 원본 파일 |
| --- | --- |
| 초상화 | `exec-739808cb-d43c-4d1c-8346-6837547bc2e2.png` |
| 액션A | `exec-dce97a96-1e21-4209-b19f-cfaaebb09bed.png` |
| 액션B | `exec-d45fc088-9dc9-46b7-aaf0-7b5eda49b3b0.png` |
| 액션C | `exec-20b3aa15-aa69-4240-a636-d813ee04f988.png` |

초상화는 텍스트 브리프만으로 새로 생성했고, 카드 세 묶음은 선택한 초상화 원본만 스타일·대상 정체성 참고로 사용했다. 상용 게임 이미지·캐릭터·로고를 추출하지 않았고 CC0 자산이라고 표시하지 않는다. WebP 변환이 원본의 내장 provenance 메타데이터를 보존한다고 보장하지 않아 생성 ID·원본·전체 프롬프트를 함께 기록한다.
