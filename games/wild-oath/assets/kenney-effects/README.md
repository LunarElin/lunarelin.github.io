# 대상 위치 이펙트 리소스

- 제작자·팩: **Kenney Vleugels, Particle Pack**.
- 공식 상세: <https://kenney.nl/assets/particle-pack>.
- 라이선스: **CC0 1.0**. 공식 상세 페이지의 CC0 표시와 실제 내려받은 ZIP의 `License.txt`를 모두 확인했다. 내용을 [LICENSE.txt](LICENSE.txt)에 보관하며 저장소 공백 검사를 위해 맨 앞의 탭만 있는 빈 줄 한 개를 제거했다. 상업적 사용·가공·재배포가 가능하고 크레딧은 의무가 아니다. 팩의 로고·미사용 파일은 포함하지 않는다.
- 확인·반입: 2026-10-29. 상세 페이지에는 2018년 1.0, 내려받은 ZIP 라이선스에는 **Particle Pack (1.1)**이라고 쓰여 있어 두 출처의 표기를 구분해 기록한다.
- 외부 리소스를 런타임에 호출하지 않는다. 필요한 PNG **8개만 로컬 제공**하며 전체 ZIP·미사용 파티클·원본 미리보기 시트는 배포하지 않는다.

## 실제 파일과 가공

아래 원본 경로는 ZIP 안의 `PNG (Transparent)/`를 기준으로 한다.

| 프로젝트 파일 | 원본 | 용도 |
| --- | --- | --- |
| `scratch.png` | `scratch_01.png` | 대상 위치의 세 갈래 발톱 자국 |
| `burst.png` | `magic_03.png` | 중심 충격·반격·연계 폭발의 별/고리 |
| `fire.png` | `flame_05.png` | 대상 위치의 불꽃 |
| `splash.png` | `smoke_03.png` | 독이 퍼지는 작은 덩어리 군집 |
| `ring.png` | `circle_02.png` | 보호·회복·상태 변화의 대상 고리 |
| `spark.png` | `spark_01.png` | 대상 위치의 갈라진 감전 |
| `smoke.png` | `smoke_06.png` | 변신의 연기 덩어리 |
| `flare.png` | `star_07.png` | 기력·회복의 빛나는 별 |

원본은 512×512다. 알파 값이 0이 아닌 범위를 잘라 비율을 유지하며 Lanczos로 232×232 안에 축소하고, 투명한 256×256 RGBA 캔버스 중앙에 배치했다. 알파 마스크 용도이므로 RGB를 흰색으로 통일했다. **RGB 통일 단계는 리사이즈된 알파 값을 바꾸지 않는다.** PNG는 무손실 압축했다. 실제 게임의 색은 CSS 마스크로 입히고, 필요한 의미 기호는 코드의 방패·회복·상태 기호와 조합한다. 이동하는 레이저·빛줄기·발사체용 `trace`·`muzzle` 이미지는 반입하지 않았다.

PNG 합계는 **120,851 bytes**, 예산은 150,000 bytes다. 중심 기준점은 모든 이미지 `(0.5, 0.5)`로 통일했다. 원본 경로·원본/가공 파일 SHA256·알파 범위·파일 크기는 [manifest.json](manifest.json)에 기록한다. 실제 표시 크기는 대략 80~130 CSS px이며 작은 파편·보조 고리는 이보다 작게 사용한다.

## 검토 범위

제작 담당자가 원본 80종 미리보기 시트와 선택한 8개의 130px 미리보기를 확인하고, 실사 캐릭터 묘사가 아닌 추상적인 발톱·불꽃·고리·별·연기 실루엣을 골랐다. 모든 이미지가 실제 투명 알파를 가지며 크기·용량·해시를 확인했다. 이 검토는 정지 리소스의 선택·가공 검증이며, 전투 중 대상 위치·수치 가림·모바일 모션·성능 검증은 통합 화면에서 따로 수행한다.

후속 통합 검토: [대상 이펙트 업데이트](../../TARGET-EFFECTS-UPDATE.md). 내부 브라우저의 PC·320/390px 세로·가로 화면에서 대표 타격·방어·회복·기력·변신을 확인했다. 8종 모두의 모든 조합·실물 휴대폰·FPS를 검증한 것은 아니다.
