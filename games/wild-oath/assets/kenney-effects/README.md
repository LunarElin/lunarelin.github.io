- 제작자·팩: **Kenney Vleugels, Particle Pack**.
- 공식 상세: <https://kenney.nl/assets/particle-pack>.
- 라이선스: **CC0 1.0**. 공식 상세 페이지의 CC0 표시와 실제 내려받은 ZIP의 `License.txt`를 모두 확인했다. 내용을 [LICENSE.txt](LICENSE.txt)에 보관하며 저장소 공백 검사를 위해 맨 앞의 탭만 있는 빈 줄 한 개를 제거했다. 상업적 사용·가공·재배포가 가능하고 크레딧은 의무가 아니다. 팩의 로고·미사용 파일은 포함하지 않는다.
- 확인·반입: 2026-10-29. 상세 페이지에는 2018년 1.0, 내려받은 ZIP 라이선스에는 **Particle Pack (1.1)**이라고 쓰여 있어 두 출처의 표기를 구분해 기록한다.
- 현행 버전은 **`closeup-7`**이다. 외부 리소스를 런타임에 호출하지 않는다. 필요한 PNG **4종 `fire`·`ring`·`smoke`·`splash`만 로컬 제공**하며 전체 ZIP·미사용 파티클·원본 미리보기 시트는 배포하지 않는다.

## 실제 파일과 가공

아래 원본 경로는 ZIP 안의 `PNG (Transparent)/`를 기준으로 한다.

| 프로젝트 파일 | 원본 | 용도 |
| --- | --- | --- |
| `fire.png` | `flame_05.png` | 대상 위치의 불꽃 |
| `ring.png` | `circle_02.png` | 보호·회복·기력·선충전과 보조 충격 고리 |
| `smoke.png` | `smoke_06.png` | 감전·변신의 둥근 연기 덩어리 |
| `splash.png` | `smoke_03.png` | 일반 공격·반격·독의 둥근 군집 |

원본은 512×512다. 알파 값이 0이 아닌 범위를 잘라 비율을 유지하며 Lanczos로 232×232 안에 축소하고, 투명한 256×256 RGBA 캔버스 중앙에 배치했다. 알파 마스크 용도이므로 RGB를 흰색으로 통일했다. **RGB 통일 단계는 리사이즈된 알파 값을 바꾸지 않는다.** PNG는 무손실 압축했다. 실제 게임의 색은 CSS 마스크로 입히고, 공격·반격·방패·회복·독·감전·기력·선충전·변신 기호와 조합한다. 마스크와 기호의 대응은 `../../combat-presentation.mjs`의 불변 레지스트리에서 관리한다.

PNG 합계는 **60,217 B**, 예산은 **75,000 B**다. 중심 기준점은 모든 이미지 `(0.5, 0.5)`로 통일했다. 원본 경로·원본/가공 파일 SHA256·알파 범위·파일 크기는 [manifest.json](manifest.json)에 기록한다. 런타임의 대상 효과 컨테이너는 초상화 크기와 타격 강도에 따라 84~160 CSS px로 제한한다. 보조 고리는 같은 중심에서 퍼지며 이동 파편은 만들지 않는다.

`target-6`에서 가는 빛줄기처럼 보일 수 있었던 `scratch.png`·`burst.png`·`spark.png`·`flare.png`는 제거했다. 카드 비행·덱 화살표도 현행 전투에서 표시하지 않는다.

## 검토 범위

초기 원본 시트·정지 미리보기 검토 이후, 사용자 피드백을 반영해 둥근 불꽃·고리·연기·군집 4종만 남겼다. 유지한 파일은 원본 알파 가공을 바꾸지 않았고, 실제 투명 알파·크기·용량·SHA256·CC0 라이선스는 리소스 회귀 테스트에서 확인한다. 이 검증은 파일의 무결성 검증이며 전투 중 대상 위치·수치 가림·모바일 모션·성능 검증과 구분한다.

현행 `closeup-7`의 통합 검토·평가·미검증 항목은 [확대·이펙트 업데이트](../../CLOSEUP-UPDATE.md)에 기록한다. [이전 대상 이펙트 업데이트](../../TARGET-EFFECTS-UPDATE.md)는 `target-6` 당시 기록으로 보존하며 현행 버전의 검증으로 재사용하지 않는다.
