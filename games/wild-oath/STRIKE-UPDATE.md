# 2026-10-30 · 공격 카드 돌진

사용자가 제안한 “공격 카드가 날아가 상대 캐릭터를 때리는” 동작을 `strike-8`에 적용했다. 커진 캐릭터·카드 크기와 대상 위치의 Kenney 효과는 유지한다. 이전 `closeup-7`의 정지 카드 정책은 [당시 기록](CLOSEUP-UPDATE.md)으로 보존한다.

## 동작

사용 카드 제시 → 짧은 기울임 → 상대 초상화로 가속 이동 → 접촉 시 카드 눌림·피해 숫자·충격 효과 → 짧은 반동과 사라짐 순서다. 카드가 260ms 이상 이동하며 도착 크기는 초상화 폭에 맞춘다. 비행 중 원래 카드 그림을 숨기되 배치는 그대로 유지한다. 카드 뒤의 광선·구체·이동 파편은 추가하지 않는다. 새 이미지나 외부 의존성도 없다.

실제로 사용된 공격 카드의 유효한 첫 strike를 확인해 한 번만 날린다. 플레이어와 적에 동일하게 적용한다. 보호막에 전부 막힌 공격도 충돌하고, 연타·추격·반격·독성 폭발의 추가 피해는 기존 160ms 박자에 따라 해당 대상에서 표시한다. 반격 카드가 새로 날아오거나 이미 죽은 대상에게 가짜 추가 비행을 만들지는 않는다. 방어·회복·변신·기력 카드는 자기 자리에서 발동하고, 충전 실패·독·화상·감전·피로 같은 상태 피해만으로 카드를 날리지 않는다.

공격 비용과 규칙 결과는 비행 시작 때 한 번 확정·저장한다. 생명과 보호막·독·화상·감전 표시는 도착 때 갱신한다. 비행 중 정지하면 저장된 최종 결과를 표시하고 다음 미처리 카드부터 재개한다. 승리·패배 화면도 마지막 충돌과 후속 피해를 표시한 뒤 연다. 비행 중 화면 크기가 바뀌면 잘못된 좌표로 계속 날리지 않고 일시 정지한다. 정지·상세 창·탭 숨김·페이지 종료는 기존 정리 경로에서 비행 노드와 원본 숨김 클래스를 함께 제거한다. 모션 감소 설정에서는 비행을 생략한다.

## 검증

Codex 내부 브라우저에서 저장된 로컬 시련 4를 이어서 플레이했다. 적 와이번의 야생의 발톱이 내 캐릭터로 이동하고, 내 폭풍의 씨앗·쌍발톱이 적에게 이동하는 것을 관찰했다. 개발용 상태 주입이나 브라우저 외부 자동화는 사용하지 않았다.

- 390×640에서 내 공격 비행 중 적 생명 26·내 생명 50, 대상 효과 0개를 기록했다. 충돌 때 적 생명 18·내 생명 50으로 바뀌며 상대 초상화에 claw 효과와 피해 숫자가 나왔다.
- 비행 원본은 hidden, 복제본은 inert·aria-hidden이며 버튼·링크·tabindex가 0개였다. 두 위치에서 같은 카드가 동시에 남지 않았다. 긴 선·구체·파편 노드도 없었다.
- 1280×720에서 적→플레이어의 비행 방향을 확인했다. 320×640에서도 돌진 카드·생명·조작을 표시하고 하단은 y632 이내였다. 844×390에서는 좌우 진영에 맞춰 다른 도착 좌표로 이동했고 하단은 y383이었다. 390×580에서는 생명의 고리(회복 카드)가 제자리에서 발동하고 비행 노드가 0개, 하단은 y575였다. 검사한 화면에서 가로 넘침은 없었다.
- 마지막 시련 첫 폭풍의 씨앗 비행 중 화면을 320×640에서 844×390으로 바꿨다. 일시 정지 창이 열리고 비행/숨김 클래스는 0개, 저장된 적 생명 65·내 생명 70을 표시했다. 재개 후 다음 카드로 넘어갔다.
- 비행 중 수동 정지와 새로고침도 확인했다. 중복 피해·카드 재소비·숨겨진 원본 카드가 남는 현상은 관찰되지 않았다. 실제 iOS/Android 기기의 탭 복귀는 별도 검증하지 않았다.
- 시련 4 승리 후 보상 선택 → 탐험 → 야영지 → 시련 5 출전으로 진행했다. 마지막 시련에서는 패배했고 결과 화면에 4/5·자동 변신 4·총 피해 359가 표시됐다. 종료 뒤 새 탐험을 눌러 0/8 첫 카드 선택으로 돌아왔고 남은 비행/숨김 클래스는 0개였다. 홈 복귀와 게임 재진입도 확인했으며 콘솔 경고·오류는 없었다. 이번 변경으로 새 여정을 처음부터 시작한 검증은 아니다.

기존 대상 이펙트 4종은 그대로 사용한다. [CC0·가공·실제 사용 파일](assets/kenney-effects/README.md)과 PNG 무결성 검증을 유지한다. 자동 검증은 README의 대상 테스트 7개 파일 **93/93**, MJS 9개 문법 검사와 대상 diff 공백 검사 통과다. 추가 3개 테스트는 실제 규칙 이벤트로 공격/지원/상태 피해·양쪽 소유자·보호막·연타·치명타·무효 대상·상태 불변성을 확인한다.
