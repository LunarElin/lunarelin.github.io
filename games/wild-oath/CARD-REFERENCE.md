# 카드 구성과 참고 범위

야생의 서약은 독립적인 드루이드 로그라이크 덱 빌딩 오토배틀이다. 사용자가 요청한 **한 차례에 남은 기력이 허용하는 만큼 덱 위에서 연속 사용**하는 구조를 채택했다. 플레이어와 적은 같은 28종 카드 풀, 비용·충전·변신·상태 이상·집중·카드 연계 규칙을 사용한다. 카드 목록은 [카드 도감](cards.html)에서 검색하고 등급별로 비교할 수 있다. 실제 데이터의 기준은 [rules.mjs](rules.mjs)의 `CARDS`와 `describeCard`다.

- [Grail 공식 Steam 패치 목록](https://steamcommunity.com/app/3597200/allnews/): 카드명과 조합을 확인한 1차 웹 자료다. 2026년 10월 21일 조사 당시 1.2.1까지의 패치가 공개되어 있었다. 할인하여 다른 카드 사용, 다른 카드 충전, 보호막·회복 복합, 화상·맹독·감전 등 일반 효과 구성을 참고했다.
- 로컬 설치본 `D:\SteamLibrary\steamapps\common\card-battler\localization_1.2.1.tsv`: 튜토리얼과 카드 효과를 읽기 전용으로 확인했다. 시작 에너지 4, 턴 종료 에너지 1, 충전이 부족한 카드의 버림 처리를 확인하는 데 사용했다. 원본 파일과 문장을 배포물에 복제하지 않는다.

웹에서 확인한 자료만으로 원작 전체 카드의 비용·수치·조건을 갖춘 완전한 목록을 확보하지는 못했다. 이 게임의 28종은 확인한 보편적 효과를 자체 이름·수치·그림으로 구성한 카드 풀이다. 원작의 전체 카드 도감을 재현했다는 의미가 아니다.

## 카드 연계

조건은 해당 카드가 발동하기 **전**의 내 보호막·상대 상태로 판정한다. 그 카드가 새로 건 맹독·화상·감전으로 자기 조건을 충족시키지는 않는다. 아래 수치는 1/2/3등급 순서다.

| 카드 | 연계 조건·추가 효과 | 함께 쓰는 카드 |
| --- | --- | --- |
| 나무껍질 | 집중 +2/3/4, 최대 12 | 대지 강타·고대의 격노 |
| 야생의 신호 | 집중 +4/5/6, 최대 12. 다음 카드 충전도 기존대로 적용 | 고대의 격노·쌍발톱 |
| 쌍발톱 | 적에게 맹독이 있으면 **각 타격** 피해 +2/3/4 | 독쐐기풀·맹독 송곳니 |
| 대지 강타 | 내 보호막이 8 이상이면 **첫 타격** 피해 +5/7/9 | 나무껍질·굳은 가죽 |
| 맹독 송곳니 | 적에게 맹독이 있으면 맹독 +3/4/5 추가 | 독쐐기풀·비취 와이번 |
| 폭풍의 씨앗 | 적에게 화상이 있으면 감전 +3/4/5 추가 | 잿불 가시·불씨 수액 |
| 숲의 양분 | 적에게 감전이 있으면 기력 +1/2/3 추가, 기력 상한 30 | 폭풍의 씨앗·번개 가지 |
| 고대의 격노 | 사용한 집중의 피해를 **두 배**로 적용. 배율은 모든 등급에서 2 | 야생의 신호·나무껍질 |

집중은 다음으로 성공한 공격에 전부 소모되어 첫 타격에만 추가된다. 보호막에 막혀 생명 피해가 0이어도 사용된다. 방어·회복·기력·변신·충전 실패·재섞기는 집중을 소모하지 않으며 새 전투에서 0이 된다. 추격이나 다중 타격으로 집중 피해가 복제되지는 않는다.

## 변신 고유 능력

| 변신 | 발동 규칙 |
| --- | --- |
| 늑대 · 추격 | 자기 카드 사용 흐름에서 앞선 연속 공격당 피해 +2, 최대 +4. 기력 카드는 연타를 유지한다. 세 번째 공격 카드마다 피해 타격을 한 번 추가한다. 방어·회복·변신·충전 실패·재섞기는 연타를 끊는다. |
| 곰 · 반격 | 방어 카드 보호막 +3, 공격 시 남은 보호막 4당 피해 +1. 살아 있는 곰이 공격을 막으면 총 흡수량의 절반을 올림한 피해를 최대 6까지 한 번 반격한다. 반격 피해는 상대 보호막이 흡수하며 재반격은 없다. 관통 공격에는 반격하지 않는다. |
| 와이번 · 독성 폭발 | 공격 관통·공격 카드당 맹독 +2. 이미 중독된 적에게 화상이나 감전을 거는 카드가 발동하면, 기존 맹독 최대 4를 소모하고 소모량×2의 관통 피해를 주고 자기 생명을 소모량만큼 최대 4 회복한다. 카드당 한 번이며 불타는 가시·불씨 수액 같은 비공격 카드로도 발동한다. |

추격은 피해 타격만 추가하며 카드의 기력 획득·상태 이상·회복 등 전체 효과를 다시 처리하지 않는다. 곰 반격과 독성 폭발도 다른 반격을 재귀적으로 발생시키지 않는다. 플레이어와 상대에게 같은 규칙이 적용된다.

### 덱 구성 예시

- **집중 준비:** 나무껍질 → 대지 강타는 보호막 조건과 집중을 함께 쓴다. 두 카드가 1등급이고 추가 형태 효과가 없다면 보호막 흡수 전 공격량은 11+5+2=18이다. 야생의 신호 → 고대의 격노는 집중 4를 두 배로 써 기본 공격량 24에 8을 더하고, 신호의 다음 카드 충전으로 격노의 필요한 기력도 줄인다.
- **늑대 추격:** 공격 → 생명의 수액 → 공격 → 쌍발톱이면 기력 카드가 연타를 유지해 쌍발톱이 세 번째 공격이 된다. 기본 2타에 추격 1타가 붙고, 적이 이미 중독되어 있으면 타격마다 쌍발톱의 연계 보너스도 적용한다.
- **상태 이상 연쇄:** 잿불 가시로 화상 → 폭풍의 씨앗으로 추가 감전 → 숲의 양분으로 추가 기력을 얻는다. 와이번이라면 화상·감전 카드 앞에 중독을 준비해 독성 폭발을 함께 노린다. 기존 맹독 4가 있으면 폭발 자체가 관통 피해 8을 주고 생명을 최대 4 회복한다.

실제 발동은 드로 순서·남은 기력·충전·상대의 상태와 보호막에 달려 있다. 야영지 **연계** 창에서 내 덱의 변신·연계 카드와 추천 카드의 보유 여부를 확인한다. 카드 상세에는 정확한 조건, 도감에는 조건·추천 카드 검색과 추천 카드 상세 이동을 제공한다.

## 차례와 충전의 적용

충전이 끝난 카드를 사용하고 기력이 남아 있으면 같은 차례를 계속한다. 기력 0·충전 실패·남은 덱 없음 중 하나에 도달하면 차례를 끝내고 기력 1을 회복한다. 기력이 0이 된 직후에는 다음 무료 카드도 다음 자기 차례까지 기다린다. 덱이 비어 끝난 차례 다음의 자기 차례는 재정렬만 하며, 카드 사용은 그다음 자기 차례부터 재개한다.

이는 사용자 요청에 맞춰 채택한 연속 사용 규칙이다. 원작 튜토리얼의 한 장 드로 설명과 모든 추가 사용 트리거를 그대로 복제한 모델은 아니다. 이 게임의 차례 수는 사용 카드 수와 별개이므로 피로와 턴 종료 기력 회복도 차례 경계에서만 처리한다.
