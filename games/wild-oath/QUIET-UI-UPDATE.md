# 전투 정보와 메뉴 정리 · 2026-10-29

사용자 지적은 전투 중 글자로 인한 덜그럭거림, 과한 설명, 양쪽 마지막 카드가 남아 차례를 혼동하는 문제, 동작을 알기 어려운 문자 메뉴였다. `game-ui-ux`, `card-game`, `game-feel` 스킬을 적용했다. [참고 영상](https://www.youtube.com/watch?v=gyqe3jZ0cYE&t=53s)을 Codex 내부 브라우저에서 다시 열고 5:36 정지 화면의 카드 위치·숫자와 아이콘·명암을 대조했다. 영상의 이미지를 게임에 복제하지 않았다.

## 변경

- 캐릭터 이름, 상태, 기력·집중, 카드, 하단 조작에 고정된 칸을 사용한다. 상태가 없을 때도 공간을 예약하며 글자·상태의 변화로 높이가 늘어나지 않는다.
- 반복되는 변신 규칙·전체 효과 문장·최근 발동 목록을 전투에서 덜었다. 카드 이름, 큰 생명·기력, 상태 기호와 수치, 실제 타격 숫자를 우선한다. 긴 문장은 카드나 초상화를 눌러 확인한다.
- 현재 행동하는 진영만 밝은 외곽선·짧은 차례 표시·카드를 보여준다. 타격 중에는 규칙 엔진이 이미 다음 차례로 넘어가도 `event.actor`를 유지한다. 마지막 타격 후 정리 단계에서 양쪽 카드 자리를 비운다. 대기 칸은 빈 자리이며 가짜 버튼이 없다.
- 카드·초상화 상세를 열면 연출과 전투를 정지한다. 읽기 전용 카드 스냅샷을 표시하고 구매·판매·합성 버튼은 만들지 않는다. 닫으면 다음 미처리 행동부터 진행한다. 정지·페이지 이탈 때도 표시 카드를 비운다.
- 덱·보관함·상점·합성·분석·도감·정지·음량·홈을 일관된 원본 SVG 아이콘으로 표시한다. 주요 행동은 `출전`, `계속`, `시작` 같은 짧은 이름을 남긴다. 접근성 이름과 포커스 표시는 유지한다.
- 덱·보상·상대 덱·도감의 일반 카드 설명은 효과 기호와 수치로 요약한다. 기력 별, 감전 번개, 다음 카드 충전, 상대 기력 감소는 서로 다른 모양이다. 기본 수치에 조건부 연계 보너스를 합쳐 표시하지 않는다. 정확한 연계·변신 조건은 상세 창과 도움말에 남는다.
- 기존 앞/뒤 표식은 카드 앞뒷면 전환이 아닌 실제 덱 정렬이었다. 맨 앞·무작위·맨 뒤를 화살표와 재섞기 기호로 구분하고, 현재 정렬은 버튼이 아닌 선택 표시로 보여준다. 가능한 합성이 없으면 합성 동작을 숨긴다. 최소 출전 6장 때문에 제외·판매할 수 없는 경우는 비활성화한다.

규칙·밸런스·저장 형식은 변경하지 않았다. 유효한 `wild-oath:v5`를 그대로 이어가며 v4 이전 정책도 유지한다. 아트 v4의 26개 WebP는 그대로 사용한다. 새 아이콘은 `menu-icons.mjs`에 직접 작성한 SVG 경로이며 외부 리소스를 추가하지 않았다. 런타임 의존성과 프레임 루프도 추가하지 않았다.

## 검증

`node --check`로 변경한 모듈을 검사했고, README의 대상 테스트 **81/81**을 통과했다. 기존 규칙 45·연출 20·덱 분석 5·인스턴스/저장 4·아트 2에 UI 모델 5개를 더했다. 새 검증은 28종×3등급의 실제 수치·접근성 이름, 연타·기력·선충전·기력 감소·관통 구분, 조건부 효과의 과장 방지, 실제 차례 전환 후에도 타격 중 카드 사용자를 유지하는지 확인한다. 이번 변경에는 새 밸런스 시뮬레이션을 실행하지 않았다.

실제 UI 검증은 **Codex 내부 브라우저**만 사용했다. 사용자 127.0.0.1 진행과 분리된 localhost 테스트 저장 공간에서 새 늑대 덱 8장을 직접 골랐다. 상인에게서 2등급 나무껍질을 얻고 늑대를 맨 앞에 정렬한 뒤 첫 시련을 승리했다. 생명의 고리를 보상으로 받고 둘째 탐험에서 샘을 선택했다. 둘째 시련에서 양쪽 차례, 늑대·곰 변신, 보호막·집중·다중 타격·재섞기를 관찰했다. 전체 다섯 시련을 다시 완주했다고 주장하지 않는다.

| 실제 확인한 화면 | 결과 |
| --- | --- |
| 320×640 세로 | 시작 선택·야영지·정렬·메뉴·전투 조작 가능. 가로 넘침 없음 |
| 390×640 세로 | 전투 생명 30px·기력 숫자 28px·카드 이름 18px. 카드와 초상화 상세 접근 가능 |
| 390×580 낮은 세로 | 하단 버튼 끝 575px. 핵심 HUD와 카드가 화면 안에 유지됨 |
| 844×390 가로 | 진영 두 개를 좌우 395px로 표시. 하단 버튼 끝 383px. 초상화 버튼 외곽 44px |
| 1280×720 PC | 한쪽 카드와 진영 강조, 큰 수치·그림 표시 확인 |

320×640에서 뽑기·효과·정리 **12개 표본**의 진영·캐릭터·상태·자원·카드 자리·하단 버튼 `offsetTop/clientHeight/clientWidth`가 동일했다. 카드 수는 항상 0~1이며 카드 소유자는 표시 중인 사용 진영과 일치했다. 정리 단계는 양쪽 카드 0개였다. 이는 의도적인 타격 반동·흔들림을 끈 결과가 아니라 문구 때문에 흐름 배치가 변하지 않는지를 측정한 것이다. 모든 카드·상태 조합에서 레이아웃 변동이 없다는 포괄적인 성능 인증은 아니다.

정지 후 생명 **57/47**, 카드 0개가 새로고침 뒤에도 같았다. 초상화의 늑대 능력과 전투 중 2등급 나무껍질을 열었을 때 생명 57/47을 유지했고 관리 동작이 없었다. 상대 덱 → 상대의 1등급 나무껍질 → 닫기에서 상대 덱으로 복귀했다. 도감 왕복도 저장된 전투를 정지 상태로 복구했다. 도감 28종은 목록의 긴 설명 없이 표시됐고 검색·3등급 야생의 신호의 집중 6/선충전 4 및 정확한 설명을 확인했다. 검사 시 브라우저 오류·경고는 없었다.

원본 DOM 표본과 관찰 범위: [tests/quiet-ui-browser-review.json](tests/quiet-ui-browser-review.json). 검증 중 발견한 빈 초상화, SVG 최소 너비 상속, 토큰 높이 충돌, 숨긴 상태의 공간 미예약, 작은 초상화를 덮던 연타 배지를 보정하고 화면을 다시 확인했다. 연타 진행은 초상화를 가리지 않도록 이름 옆에 표시한다.
