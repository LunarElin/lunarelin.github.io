# 카드 가시성·타격감 개선 검증

2026-10-24. **잠정 90/100점**. 기존의 자원 기반 자동 전투·카드·밸런스·v5 저장 형식은 유지하고 카드 사용과 결과 표시를 개선했다. 앞선 세 형태 완주·와이번 생존 조정 기록은 [VERIFICATION.md](VERIFICATION.md)에 보존한다.

## 참고와 적용

Blizzard의 [하스스톤 VFX 제작 설명](https://hearthstone.blizzard.com/en-us/news/22552047/developer-insights-the-art-behind-the-science)에서 효과의 명확한 형태·색과 중요도에 맞춘 크기를 참고했다. [사운드 제작 설명](https://news.blizzard.com/en-us/article/23964694/inside-battle-net-meet-the-sound-team-behind-hearthstones-harmonic-design)에서 카드 사용 흐름과 주문의 성격에 맞춘 소리 구분을 참고했다. 아래 구성은 이 게임의 진영 배치·둥근 그래픽·자동 전투에 맞춰 직접 구현한 것이다. 원작 이미지·음원은 사용하지 않았다.

- 자기 덱에서 자기 사용 영역으로 카드를 뽑고, 카드를 확대·금빛 외곽선·그림자로 강조한 뒤 발사한다. 사용 주체와 카드 이름을 함께 표시한다.
- 이전 4배속의 뽑기 70ms+비행 90ms는 알아보기 어려웠다. 이제 뽑기 최소 140ms·카드 제시 260ms·발사 180ms로 효과 발동 전 580ms를 확보한다. 배속을 높여도 핵심 제시 시간은 유지한다.
- 발톱·화염·번개·독의 투사체와 타격 모양을 구분한다. 방어·회복·기력·변신은 자기 캐릭터 주변의 별도 오라와 짧은 수치로 표시한다.
- 피해 숫자는 기본 36px, 큰 타격 46px이다. 국소 파열·충격파·제한된 파편과 짧은 캐릭터 반동을 사용한다. 화면 전체를 덮는 흰색 섬광은 제거했다.
- 연타·상태 이상·반격·독성 폭발은 규칙이 처리한 순서대로 160ms 간격으로 표시한다. 생명바도 각 타격과 실제 회복에 맞춰 바뀐다. 막은 양은 피해와 구분한다.
- 기존 로컬 Kenney 타격음 네 개와 직접 합성한 준비·속성음을 조합한다. 오디오 활성화·음원 다운로드를 기다리지 않고 전투를 진행한다. 끄기·정지·탭 숨김·이탈 시 소리와 관련 노드를 정리한다.
- 모션 감소에서는 비행·흔들림·반동을 끄고 대상별 피해 합계와 정적 강조를 유지한다. 효과 노드는 최대 56개이며, 효과 타이머와 카드 비행 노드는 정지·단계 변경·이탈 시 정리한다.

## 수정 과정에서 발견한 문제

치명타 뒤 실제 피해가 0인 후속 효과를 방어로 표시하던 문제, 감전·독성 폭발의 표시 순서가 규칙과 달랐던 문제를 수정했다. 순수 규칙은 실제 타격의 보고 배열만 추가하며, 상태를 변경하는 계산 순서는 유지했다.

모바일 효과 칩을 초상화 안쪽으로 옮겨 생명바와 분리했다. 같은 대상의 연속 피해 숫자는 이전 숫자를 교체하고 모션 감소 경로는 합산한다. 음향 버튼으로 사용 전 카드 제시가 사라지는 문제, 느린 음원 요청이 재개를 막는 문제, 앞 타격의 타이머가 뒤 타격의 반동을 조기에 끊는 문제도 수정했다.

## 자동 검증

```powershell
node --check games/wild-oath/game.mjs
node --check games/wild-oath/rules.mjs
node --check games/wild-oath/combat-presentation.mjs
node --test games/wild-oath/tests/rules.test.mjs games/wild-oath/tests/combat-presentation.test.mjs
node games/wild-oath/tests/balance-campaigns.mjs --seeds 100 --compare-baseline
git diff --check -- games/wild-oath
```

- **57/57 통과:** 기존 규칙 41개와 연출 16개. 배속별 최소 시간, 속성 선택, 양측 타격 방향·순서·간격, 원본 이벤트 불변, 모션 감소 합산, 치명타·보호막·반격·감전·독·화상·피로·회복 상한을 포함한다.
- 양측 고정 사례와 자연 탐험 8개에서 모든 행동의 `시작 HP + 실제 회복 - 순차 피해 + 폭발 회복`이 규칙의 최종 HP와 일치했다. 표시용 HP는 생산 상태를 변경하지 않는다.
- 변경 전 규칙과 같은 100개 시드를 9,756행동 비교했다. 추가한 타격 보고 배열을 제외한 상태·기존 이벤트 필드가 전부 일치했다.
- 형태별 기존 고정 정책 100개 시드를 다시 실행했다. 완주는 늑대 71·곰 68·와이번 66으로 기존과 같았다. 총 1,241전투·41,805행동·49,661 저장 왕복을 확인했다. 이는 특정 선택 정책의 시뮬레이션이며 사람의 승률을 뜻하지 않는다.

## 실제 브라우저 플레이

데스크톱 Chromium에서 일반 UI만 사용했다. 사용자 진행과 분리된 localhost 저장 공간에서 이전 모바일 점검의 2시련 탐험부터 와이번 덱을 이어 플레이했다. 카드 지급·HP·승패·저장 상태를 주입하지 않았다.

| 구간 | 승리 직후 내 생명 | 관찰 |
| --- | ---: | --- |
| 2시련 | 39 | PC와 320px에서 카드 확대·공격·보호막 흡수·독성 폭발·회복 확인 |
| 3시련 | 34 | 390px에서 독 투사체·충전 표시, 사용 전 정지·재개 확인 |
| 4시련 | 51 | 844×390 가로 전투, 생명바·하단 버튼·결과 저장 확인 |
| 5시련 | 56 | 390px에서 최종 승리 5/5·자동 변신 5·총 피해 390 확인 |

시련 사이 보상·탐험·회복·카드 구매·출전·일괄 합성을 실제 버튼으로 진행했다. 완료 뒤 새로고침에도 5/5·총 피해 390이 유지됐고, 새 덱 재시작·홈 왕복·게임 재진입도 확인했다.

추가로 새 여정에서 늑대·쌍발톱을 포함한 8장을 무작위 제시에서 고르고, 상인 이벤트가 제시한 2등급 쌍발톱을 앞장으로 지정했다. 실제 두 번째 타격(`beat=2`)에서 첫 타격의 방어 효과와 두 번째 타격의 `−9`, 상대 반동·생명 14가 표시된 프레임을 캡처했다. 이 전투는 생명 1로 승리했다. 실제 타격 관찰 수치와 화면 배치 기록은 [combat-feedback-browser.json](tests/combat-feedback-browser.json)에 보관한다. 모든 다중 타격 경계의 판단은 자동 검증과 코드 검토를 함께 근거로 한다.

- PC 1280×720: 사용 주체·확대 카드·타격·보호막 피해 구분을 확인했다.
- 320×568: 가로 넘침 없음. 확대 카드 약 130×139px, 생명 28px, 피해 숫자 36px, 하단 버튼 영역 563px 이내였다. 효과 칩과 생명 영역이 겹치지 않았다.
- 390×640: 가로 넘침 없음·하단 632px. 카드 자리에서 상대 초상화로 향하는 독 투사체를 확인했다.
- 844×390: 가로 넘침 없음·하단 383px. 진영이 좌우로 나뉘며 생명과 주요 버튼이 화면 안에 있었다.
- 사용 전 상대 카드 제시 단계에서 정지했을 때 생명 69/70·덱 10/11·버림 0/0이 유지됐다. 정지 후 효과·비행·강조 잔여 노드는 0이었고 재개했다. 타격 후 정지·새로고침도 확정된 생명과 덱을 보존했다.
- 실제 DOM 캡처에서 피해·보호막·충전 칩·투사체와 올바른 주체를 확인했다. 브라우저 경고·오류는 0이었다. 효과음을 켠 UI 경로는 실행했지만 실제 스피커 청취 평가는 하지 않았다.

## 부족한 부분과 다음 우선순위

1. 실제 iOS Safari·Android Chrome에서 터치·주소창 변화·모션 감소·오디오 재개·저사양 프레임을 점검한다. 기기별로 효과가 끊기거나 버튼이 가려지는지 확인하고 파편 수와 오디오 동시 발음을 조정한다.
2. 실제 스피커/이어폰에서 기본 음량과 타격·충전음 균형을 조절한다. 현재는 음향 경로와 정리 코드를 검증했으며 소리의 주관적 만족도는 미평가다.
3. 세 번째 추격·동시 상태 이상이 겹친 실전 프레임을 추가 관찰하고 사용자에게 1배속/4배속 인지성을 평가받는다. 필요하면 설정에서 제시 시간·흔들림 강도를 조절할 수 있게 한다.
4. 카드별 삽화 구별을 늘린다. 현재 이름·속성·효과는 구별되지만 같은 형태 그림이 반복되어 덱이 커지면 그림만으로 카드를 찾기 어렵다.
