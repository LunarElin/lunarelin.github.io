# 아트·리소스

- 동물 5종과 나무·잔디·채집 식물: `sprite-gen` 3.7.0의 GPT 이미지 생성 경로로 제작한 독자 이미지. 애니메이션은 원화 → 상태별 단일 행 생성 → 컴포넌트 추출 → 기준점 정렬 → 아틀라스 합성 → 알파·프레임 검증 과정을 거쳤다. 런타임에는 생성 API가 필요하지 않다.
- `runtime-assets.json` version 2: 다섯 동물마다 `front/back/right/left` 네 방향, 총 20개 WebP 아틀라스를 참조한다. 합성 도구의 `manifest.json.frame_layout`에서 프레임 사각형과 원래 재생 시간을 옮겼다. 방향별 대기 2~4·달리기 6·발사 또는 채집 6프레임, 셀 128×128이다. 앞·뒤·양옆은 별도로 생성한 그림이며 왼쪽도 새로 그렸다. 런타임 좌우 반전·동일 그림 복제는 사용하지 않는다.
- 방향 제작: 승인한 단일 포즈 원화에서 앞·뒤·옆 방향 앵커를 만든 뒤, 채집 준비 포즈를 방향별 상태 앵커로 생성하고 준비→접촉→복귀의 단일 행을 제작했다. 왼쪽 행은 오른쪽의 동작 리듬을 참고해 별도로 생성했다. 방향별 원본 행을 정식 `extract/compose/inspect`로 처리했으며, 이미 생성된 행을 재사용할 때도 파이프라인으로 다시 추출·합성했다. 프레임 수를 늘리기 위한 정지 이미지 복제나 임의 고정 폭 자르기는 사용하지 않았다.
- 동작·소지품: 다람쥐는 한 개 꼬리와 도토리 투척, 곰은 빈 앞발을 들어 내려치기, 여우는 열매를 따서 바구니로 가져오기, 래서판다는 대나무 잡아당기기·베기, 참새는 발을 딛고 고개를 숙여 씨앗 쪼기다. 채집 행은 10fps·600ms이며 접촉은 프레임 인덱스 3의 330ms로 맞췄다. 게임의 강화 속도는 이 주기를 같은 비율로 줄인다.
- 크기와 접지: 각 행의 발 기준점은 아래 중앙이다. 방향별 몸 높이와 상태별 준비 포즈의 크기를 측정해 `view.renderScale`과 `animation.renderScale`의 고정 배율로 보정한다. 프레임마다 크기를 바꾸거나 몸을 찌그러뜨리지 않아 웅크리는 동작을 유지한다. 지면 그림자는 발 위치에 고정하며 별도의 몸 전체 들썩임을 겹치지 않는다. 생성 이미지 특성상 미세한 형태 변화와 프레임 간 보간 한계는 남는다.
- `art-validation.json`: 동물 312프레임의 알파 경계·서로 다른 그림·파일 크기·SHA256·방향별 고정 배율을 기록한다. 곰의 오른쪽 대기는 미세한 움직임이 검사 기준보다 조금 작다는 경고(0.0097 < 0.0100)가 있으며, 채집·이동 행의 오류는 없다. 동물 아틀라스 합계는 약 3.98MB, 문서·메타데이터를 포함한 전체 에셋 폴더는 약 4.87MB다. 실제 휴대폰의 시간적 부드러움과 발열은 별도 검증이 필요하다.
- `oak.webp`: 파괴 가능한 나무 표적. 셀 192×192, 대기 2·피격 2·그루터기 1프레임. 상태별 기준점은 뿌리 아래 중앙이다. 그루터기는 별도 행 정규화로 커지므로 기본 나무 크기의 0.55배로 표시해 뿌리 폭을 맞춘다. 검사기의 그루터기 모션 부족 경고는 의도된 단일 정지 프레임에 해당한다.
- `berry.webp`, `bamboo.webp`, `grain.webp`: 빨간 열매 덤불·대나무 군락·황금 씨앗 풀. 각각 따로 생성한 투명 정지 원화다. `sprite-gen gen --trim-alpha`로 자르고 도구의 알파 보존 `resize_cell` 함수로 192×192 셀, 아래 기준선 180px에 맞췄다. 아틀라스 프레임을 임의로 잘라 만든 소스가 아니다.
- 동물·나무·채집 식물 `*.webp`: 생성·합성된 RGBA 이미지를 무손실 WebP로 변환했다. 동료·채집 식물은 투명 픽셀의 RGB도 보존하는 `exact` 옵션을 사용한다.
- `grass.webp`: 지면만 그린 원본에서 `sprite-gen background-tile --axis xy --period 512 --overlap 64`로 만든 양방향 반복 타일. 지면의 대각선 투영과 카메라 이동은 게임에서 처리한다. 2×2 반복을 시각 확인했다. 도구는 내부 퀼트의 국부 색 차이에 검토 경고를 남겼으며 눈에 띄는 반복 경계는 발견하지 못했다.
- `spark.png`: [Kenney Particle Pack](https://kenney.nl/assets/particle-pack) 1.1, CC0. 실제 사용 원본은 `PNG (Transparent)/spark_01.png`. 64×64 이하로 축소했으며 색상은 런타임에서 처리한다. 동봉 라이선스는 `kenney-particles-license.txt`에 보관한다.
- `nunito.ttf`: [Google Fonts / Nunito](https://github.com/google/fonts/tree/main/ofl/nunito)의 `Nunito[wght].ttf`, 수정 없이 로컬 제공. SIL OFL 1.1, `nunito-OFL.txt` 보관. 숫자와 기호에 사용한다.
- 메뉴와 상태 아이콘: 게임 코드에서 작성한 SVG. 화면에는 아이콘과 수치를 표시하고 접근성 이름은 보조 기술에 제공한다.
