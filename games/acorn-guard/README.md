# 도토리 원정대

다람쥐 한 마리로 시작해 숲에서 동료를 만나고, 최대 다섯 동물이 겨울나기 먹이와 재료를 함께 모으는 방치형 웹 게임이다. 봄·여름·가을의 숲길을 지나 겨울 집에 도착하면 모은 재료로 집을 꾸미고 다음 봄으로 출발한다. 동료·개인 성장·집 꾸미기는 해가 바뀌어도 이어진다. HTML·Canvas 2D·ES modules만으로 실행한다.

- 진입: `index.html`, 화면·카메라·입력·오디오: `game.mjs`, 규칙·저장: `rules.mjs`, 방향·동작 시간: `motion.mjs`, 계절·겨울 집 렌더링: `season-render.mjs`, 배치: `styles.css`, 숲 팔레트: `forest-theme.css`, 연간 진행·꾸미기 UI: `year-cycle.css`.
- 경로: `/games/acorn-guard/`, 홈페이지 복귀: `../../`.
- 시점: 35° 경사·45° 회전의 정사영 지면과 화면을 향한 동물·나무 빌보드. 다람쥐의 월드 이동을 카메라가 추적하며 배경·동물·채집물을 상대좌표로 그린다. 화면 깊이에 따라 그리는 순서를 정한다.
- 출처·생성·라이선스: [assets/README.md](assets/README.md). 모든 실행 리소스는 게임 안에서 로컬 제공한다.

## 실행·검증

저장소 루트에서 실행한다. Windows의 기본 Python 서버가 `.mjs`를 `text/plain`으로 제공할 수 있어 동봉 서버는 JavaScript MIME을 명시한다.

```powershell
python games/acorn-guard/tests/serve.py --port 8123
# http://127.0.0.1:8123/games/acorn-guard/
node --check games/acorn-guard/game.mjs
node --check games/acorn-guard/rules.mjs
node --check games/acorn-guard/motion.mjs
node --check games/acorn-guard/season-render.mjs
node --test games/acorn-guard/tests/rules.test.mjs games/acorn-guard/tests/year-cycle.test.mjs games/acorn-guard/tests/motion.test.mjs games/acorn-guard/tests/assets.test.mjs games/acorn-guard/tests/season-render.test.mjs
git diff --check -- index.html portfolio/style.css games/acorn-guard/
```

서버는 Python 3 표준 라이브러리, 기본 규칙·동작·에셋·렌더러 테스트는 Node.js 내장 test runner를 사용한다. 게임 실행에는 패키지 설치가 없다.

화면 코드와 저장·계절·꾸미기 연결은 테스트 폴더의 jsdom 26.1.0으로 별도 검증한다. 테스트 전용 의존성은 그 폴더에만 설치하며 브라우저에 배포되지 않는다. Node 24.19에서 확인했다.

```powershell
npm ci --prefix games/acorn-guard/tests --ignore-scripts
node --experimental-vm-modules --test games/acorn-guard/tests/ui-cycle.test.mjs
```

이 검증은 실제 `game.mjs`와 HTML을 실행하지만 Canvas·이미지 디코딩·레이아웃·시간을 대체한 DOM 시뮬레이션이다. 실제 픽셀 표시·터치·실기기 검증으로 보고하지 않는다. VM Modules의 실험 기능 경고는 테스트 실행에만 해당한다.

## 플레이·아이콘

- ▶ 시작·계속, Ⅱ 일시 정지. 다람쥐는 기본적으로 나무를 찾아 이동하며 도토리를 자동 발사한다. 나무는 움직이거나 공격하지 않는다. 플레이어 체력·접촉 피해·패배는 없다.
- **평소에는 방향 패드를 표시하지 않는다.** 플레이 영역을 누른 자리에서 임시 패드가 나타나고, 드래그 방향으로 다람쥐를 움직인다. 손을 떼면 사라진다. 마우스 드래그와 방향키/WASD도 지원한다.
- 직접 이동은 자동 탐색보다 우선한다. ∞는 다람쥐의 자동 **이동**을 전환한다. 꺼도 사거리 안의 나무에는 자동 발사하고, 합류한 동료들은 주변에서 계속 일한다.
- 나무 위 작은 초록 막대는 내구도, 흰 숫자는 타격 피해다. 내구도가 0이 되면 그루터기·동전·재료 효과가 나타나고 수확 보상을 한 번 지급한다.
- **채집 36회마다 봄→여름→가을로 진행하고 108회에 겨울 집에 도착한다.** 나무·열매·대나무·곡식을 모두 센다. 걷기나 오프라인 시간만으로 계절이 지나가지는 않는다. 상단은 연도·계절·겨울까지의 진행·올해 모은 먹이를 표시한다. 내부 숲 난도는 나무 30그루마다 높아지며 999단계에서 상한을 유지한다.
- 아래 동물 초상화를 누르면 그 동물의 **성장 화면**을 본다. 다람쥐가 이동과 카메라의 기준이며, 성장 화면 선택으로 조종 동물이나 작업 인원을 교체하지 않는다. 합류한 동료는 모두 동시에 일한다.
- 상단은 공유 동전과 선택한 동물의 개인 재료·레벨을 표시한다. 아래 세 강화는 동물마다 달라진다. 큰 수치는 현재 능력이며, 동전·재료 아이콘 옆 수치가 다음 강화 비용이다. 비용 두 종류를 모두 갖춰야 강화한다.
- 도토리+번개는 다람쥐의 도토리 폭풍, 재사용 대기 12초. 키보드는 플레이 영역에 초점을 두고 Space.
- 선물은 최초 한 번 동전 100개. 계절 표시를 누르면 연도·전체 수확·동료 수·집의 포근함 기록을 본다. 설정의 ↻는 동료·성장·동전·계절·집 꾸미기를 유지하고 새 숲길 또는 같은 겨울 집에서 재개한다. 설정의 집 아이콘은 홈페이지로 이동한다.
- 메뉴는 아이콘과 숫자 중심이며 스크린리더용 한국어 이름을 유지한다. 효과음은 기본 꺼짐이다.

## 사계절·겨울 집

봄의 꽃과 연녹색 풀, 여름의 짙은 녹음과 작은 나비, 가을의 황갈색 나무와 낙엽, 겨울의 창백한 지면과 눈으로 점차 변한다. 나무는 같은 프레임·줄기·기준점을 유지한 네 계절 그림을 섞어 전환하고 지면·절벽 색도 보간한다. 마지막 가을 구간에는 눈 덮인 집이 앞쪽에 나타난다. 108번째 채집 후 동물들이 집으로 걸어 들어가고 따뜻한 실내로 전환한다. 감소된 모션 설정에서는 입장 전환을 짧게 한다.

올해 먹이는 수확한 도토리·열매·곡식의 연간 기록이다. 동전 선물·오프라인 보상·기존 저장 이전은 먹이 기록을 늘리지 않는다. 꾸미기에는 각 동물이 실제 보유한 개인 재료를 사용하므로, 같은 재료를 개인 성장과 집 꾸미기에 모두 중복 지출할 수 없다. 겨울에는 채집과 이동을 쉬고, 창밖에 눈이 내리는 집에서 함께 머문다. 굶주림·시간 제한·자원 부족 패배는 없다.

가구나 아래 여섯 아이콘을 누르면 꾸밀 대상을 고른다. 망치로 제작·강화, 팔레트로 세 가지 색상 선택, 눈으로 배치·치우기를 한다. 가구는 정해진 실내 위치에 놓이며 최대 3단계다. 기본 제작 비용은 아래와 같고 다음 단계 비용은 기본값의 2배·3배다. 보유 중인 두 재료를 모두 갖춰야 제작하며 부족하면 아무 재료도 사용하지 않는다.

| 가구 | 첫 제작 비용 |
| --- | --- |
| 포근한 잠자리 | 목재 12 · 곡식 2 |
| 먹이 선반 | 목재 10 · 대나무 4 |
| 폭신한 깔개 | 곡식 6 · 열매 6 |
| 따뜻한 화로 | 목재 18 · 도토리 8 |
| 도토리 등불 | 대나무 6 · 도토리 10 |
| 창가 커튼 | 대나무 8 · 열매 8 |

하트 수치는 배치된 가구 단계의 합인 집의 포근함이다. 꽃+▶ 버튼을 누르면 연도가 하나 올라가고 봄부터 다시 출발한다. 올해 먹이·채집 진행만 새로 시작하며 동료·성장·동전·남은 재료·가구의 단계·색·배치는 유지한다. 꾸미기를 강제하지 않으므로 재료가 부족해도 다음 해로 갈 수 있다. 연도는 9999에서 상한을 유지한다.

## 동료·개인 성장

처음에는 다람쥐만 있다. 전체 수확이 아래 기준에 도달하면 다음 동물이 숲 앞쪽에 등장한다. 다람쥐가 가까이 다가가면 만남 화면이 열리고, 하트 버튼으로 무료 합류시킨다. 순서대로 한 마리씩 만나며 최대 다섯 마리다. 아직 만나지 않은 동물은 잠금과 수확 진행 수로 표시한다.

| 동물 | 만남 기준 | 채집 방식·개인 재료 | 세 가지 강화 |
| --- | ---: | --- | --- |
| 다람쥐 | 처음부터 | 도토리 발사로 나무 수확 → 도토리 | 도토리 힘, 연속 발사, 도토리 주머니 |
| 곰 | 전체 수확 8회 | 나무에 접근해 앞발로 내려치기 → 목재 | 앞발 힘, 연속 내려치기, 울림 범위 |
| 여우 | 전체 수확 25회 | 열매 덤불로 달려가 직접 따기 → 열매 | 열매 따기, 희귀 열매, 열매 바구니 |
| 래서판다 | 전체 수확 50회 | 가까운 대나무와 주변 대나무 베기 → 대나무 | 대나무 베기, 넓게 베기, 새순 |
| 참새 | 전체 수확 85회 | 짧게 달려가 발을 딛고 곡식 쪼기 → 곡식 | 빠른 쪼기, 여러 번 쪼기, 숨은 씨앗 |

각 동물은 개인 경험치·레벨·재료·강화를 가진다. 레벨은 기본 채집 힘을 높이며, 여우는 열매를 따는 속도가 높아진다. 직접 완료한 채집에서 개인 경험치와 재료를 얻으며 동전은 원정대가 공유한다. 강화에도 해당 동물의 재료를 사용한다. 범위 강화의 `100%`는 기본 작업 범위, `/s`는 초당 동작 횟수, `×`는 한 동작의 횟수나 수확 수량이다. 여우의 희귀 열매와 참새의 숨은 씨앗은 추가 재료 발견 확률, 래서판다의 새순은 근처 수확 자리에 대나무가 다시 자랄 확률이다.

합류할 때 첫 작업 대상이 근처에 생성된다. 동료는 다람쥐 주변에서 자신의 채집물을 찾고, 대상을 예약해 다른 동물의 선점으로 작업이 막히는 일을 줄인다. 멀어지면 채집을 멈추고 따라오며 지나치게 떨어졌을 때는 재합류한다. 지나간 채집물은 정리하고 앞으로 나무·열매·대나무·곡식 구역을 계속 생성한다.

## 애니메이션·성능

아트는 굵은 갈색 윤곽선, 작은 점눈과 짧은 팔다리, 넓고 단순한 색면을 사용하는 2D 카툰 스프라이트다. 동물은 황갈색·크림색·적갈색으로 구분하고, 식물은 차분한 녹색·바닥은 옅은 연두색·절벽은 갈색으로 통일한다. 채집 동작과 종별 실루엣은 작은 크기에서도 구분되게 했다. 실제 실행은 Canvas 2D이며 숫자와 터치 영역은 기존 크기를 유지한다.

동물마다 앞·뒤·오른쪽·왼쪽을 따로 그린 네 방향 아틀라스를 사용한다. 각 방향은 대기 2~4장·이동 6장·발사 또는 채집 6장이다. 왼쪽도 별도 생성 이미지이며 런타임 좌우 반전은 사용하지 않는다. `motion.mjs`는 지면과 같은 투영식으로 실제 이동 벡터를 화면 방향으로 바꾼다. 방향 경계에 10° 여유를 두어 대각선 이동의 떨림을 줄이며 정지하면 마지막 방향을 유지한다. 이동 프레임은 실제 이동 거리를 기준으로 진행한다.

발사와 채집은 0.6초의 준비→접촉→복귀 동작이다. 4번째 프레임의 0.33초 지점에 도토리를 놓거나 채집 판정을 수행한다. 속도 강화로 동작 간격이 0.6초보다 짧아질 때 전체 주기를 같은 비율로 줄이며, 시작 당시 속도를 고정해 진행 중인 강화가 접촉 시점을 바꾸지 않는다. 동료는 발을 딛고 복귀 동작을 끝낸 뒤 다음 채집물로 이동한다. 준비 중 대상이 사라지거나 멀어지면 판정을 취소하고, 일단 접촉한 작업은 원래 방향으로 복귀한다. 다람쥐가 직접 움직일 때는 몸의 이동 방향을 우선한다.

곰은 앞발 준비·내려치기·회수, 여우는 몸 숙이기·열매 따기·바구니 회수, 래서판다는 대나무 당기기·베기·회수, 참새는 발을 딛고 고개 숙이기·쪼기·고개 들기를 사용한다. 땅의 그림자는 발 위치에 고정하고, 별도의 몸 전체 흔들림이나 앞으로 미는 효과를 겹치지 않는다. 접촉 순간에 목재 조각·열매·잎·씨앗 효과를 맞춘다. 나무는 대기 2장·피격 2장·그루터기 1장이다. 프레임 좌표·시간·기준점·방향별 고정 크기 보정은 `assets/runtime-assets.json`에 있으며 생성·분리·정렬·합성은 `sprite-gen` 파이프라인으로 수행한다.

Canvas DPR은 2로 제한한다. 동료를 포함한 작업자 5마리, 채집물 36개, 발사체 90개, 효과 120개, 대나무 재성장 예약 10개, 그루터기 50개, 동전 효과 60개로 제한한다. HUD는 최대 초당 10번 갱신하고 꾸미기 패널은 선택·소유·재료가 바뀔 때만 다시 만든다. 계절 무늬·눈·낙엽은 고정 개수와 월드 좌표로 그린다. 겨울 집·가구 이미지는 겨울에 가까워질 때, 저장된 겨울 집은 불러올 때 로드한다. 숨겨진 탭·초점 이탈 시 입력을 해제하고 일시 정지한다. 숨겨진 탭에서는 렌더를 중지하며 복귀 후 ▶로 이어간다. 페이지 이탈 시 저장·오디오·렌더·ResizeObserver를 정리하고 뒤로가기 캐시 복귀를 처리한다. 감소된 모션 설정에서는 장식 흔들림을 줄인다.

아트 교체 시 모듈·manifest URL과 `artRevision`의 이미지 버전을 함께 올려 이전 캐시의 그림이 새 화면과 섞이지 않게 한다. 아트 버전은 저장 형식과 독립적이며 동료·개인 성장·숲 진행을 초기화하지 않는다.

## 저장·호환

- 진행 키: `acorn-guard:v4`, JSON `version: 4`. 모집 순서, 선택한 성장 화면, 각 동물의 레벨·경험치·재료·세 강화, 공유 동전, 전체·나무 수확 수, 현재·최고 숲, 현재 숲 나무 수확 수, 이동 기록, 자동 이동, 저장 시각에 더해 연도·올해 채집·먹이 종류별 기록·겨울 집 여부·가구별 단계·색·배치를 보관한다.
- v4가 없거나 파싱할 수 없으면 `acorn-guard:v3`, `v2`, `v1` 순서로 읽으며 이전 키를 삭제하지 않는다. v3의 동료·개인 성장·재료·동전·숲 기록은 그대로 이전하고 새 연간 진행만 1년째 봄·0회로 시작한다. 이전 수확을 올해 먹이로 중복 지급하지 않는다. v2/v1의 기존 개인 레벨·경험치와 공격·속도·수입 강화는 다람쥐의 성장으로 이전한다. v1의 체력 강화는 도토리 주머니로 이전한다.
- 이전 버전의 동물 선택은 다람쥐 중심의 새 원정대로 전환한다. 처음에는 다람쥐만 모집된 상태이며, 유지한 수확 수에 맞춰 동료를 순서대로 만날 수 있다. 개인 재료는 새 채집으로 얻는다.
- 모집 목록은 정해진 순서와 수확 조건을 검증하고 최대 다섯 종으로 복구한다. 미모집 동물의 개인 성장은 기본값으로 처리한다. 연간 채집은 0~108회이며 108회일 때만 겨울 집으로 복구한다. 가구는 알려진 여섯 종류·0~3단계·0~2색상으로 복구한다. 미지원 버전·동물, 손상된 JSON·개인 성장, 음수·비정상 수치는 기본값 또는 허용 범위로 복구한다.
- 설정 키: `acorn-guard:settings:v1`. 효과음과 최초 보급 수령 여부.
- 5초마다, 강화·성장 화면 선택·모집·메뉴 열기·페이지 이탈 시 저장한다. 실시간 좌표·채집물 내구도·진행 중 작업은 저장하지 않고 재접속 시 저장한 숲 진행률에서 새 채집 구역을 만든다.
- 오프라인 보상은 숲 진행과 동료 수에 따른 **동전만** 분 단위로 지급하며 최대 8시간이다. 개인 재료·경험치를 대신 채집하지 않는다. 불러올 때 시간을 즉시 소비하여 정상 저장 환경에서 중복 수령을 막는다.
- 다른 게임의 저장은 읽거나 지우지 않는다. 저장 실패에도 현재 플레이는 가능하다. 저장소 접근 거부·용량 부족일 때 영구 저장과 재접속 보상 중복 방지는 보장할 수 없다.

## 검증 범위

규칙 테스트는 한 마리 시작·순차 만남·모집 조건·다섯 마리 동시 채집, 개인 성장, 보상 단회 지급, 자동 탐색·직접 이동·재합류를 확인한다. 연간 주기 테스트는 사계절 경계·겨울 도착 단회 처리·겨울 채집 중단·가구 비용의 원자적 지출·색과 배치·다음 봄의 보존·v4 저장 및 이전 저장 복구·동료 만남 보존을 확인한다. 동작 테스트는 네 방향·작업 방향 고정·속도별 접촉 프레임을 확인한다. 에셋 검사는 네 방향과 계절 나무의 실제 WebP 프레임·알파·크기·로컬 참조·6MB 예산을 검사한다. 렌더러 테스트는 계절 색의 연속성·가구 터치 영역·월드 무늬의 접지·Canvas 상태 균형을 확인하며 실제 픽셀 렌더링 검증과 구분한다.

브라우저 확인은 데스크톱과 모바일 크기 에뮬레이션으로 구분한다. 최근 확인 환경·관찰·잠정 평가는 [tests/browser-review.json](tests/browser-review.json)에 기록한다. 실제 iOS Safari·Android Chrome의 터치·주소창·노치와 장시간 발열·배터리는 별도 실기기 검증이 필요하다. 자동 테스트를 사람의 재미 평가나 실기기 검증으로 대신하지 않는다.
