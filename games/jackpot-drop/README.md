# Jackpot Drop

스프링으로 구슬을 쏘는 핀볼 로그라이트입니다. 처음 닿은 핀은 켜지고 일반·금 핀은 두 번째 접촉에 깨집니다. 철문이 있는 단계에서는 일반 구슬을 먼저 주차해 점수를 저금하고, 쇠 구슬로 문을 부숴 함께 떨어뜨릴 수 있습니다. 목표 점수를 넘기면 강화 카드를 고르고, 8단계를 통과하면 무한 모드가 이어집니다.

## 실행

- 공개 경로는 [포트폴리오에서 플레이](https://lunarelin.github.io/games/jackpot-drop/)입니다.
- 로컬에서는 [index.html](index.html)을 직접 열거나 Windows에서 [Play.bat](Play.bat)을 실행합니다. 저장소 루트를 정적 HTTP로 제공할 때는 `/games/jackpot-drop/`을 엽니다. 설치나 빌드 과정이 없습니다.
- 터치는 보드를 누른 채 충전하고 손을 떼서 발사합니다. 금색 구간에서 떼면 퍼펙트 발사입니다. 비행 중 보드를 누르면 누르는 동안 2배속으로 진행하고, 정산 중 보드를 탭하면 즉시 끝납니다. 발사대 오른쪽 탄창을 탭해 구슬을 고릅니다. 상단 **정지**를 누르면 보드 안에서 계속하거나 처음부터 시작할 수 있습니다.
- 키보드는 **Space** 또는 **Enter**를 눌렀다 떼서 발사합니다. 비행 중 **Shift**를 누르면 2배속으로 진행하고, 정산 중 **Space** 또는 **Enter**를 누르면 즉시 끝납니다. 방향키로 구슬을 고릅니다. 강화 화면에서는 방향키와 **Enter** 또는 숫자 **1–3**으로 카드를 고릅니다. **Esc**로 일시 정지·계속, **M**으로 음소거를 전환합니다.
- 페이지가 가려지면 시뮬레이션과 소리가 멈추고 충전이 초기화됩니다. 화면이 보이는 동안 받은 포인터 취소는 손을 뗀 동작으로 처리합니다.

## 유지관리와 검증

- `src/rules.js`는 보드·충돌·점수·강화 규칙을, `src/game.js`는 라운드 상태 전이를 담당합니다. `src/render.js`, `src/input.js`, `src/main.js`에서 화면과 입력을 연결합니다.
- [tests.html](tests.html)에서 규칙·상태 전이 자동 검사의 기대값과 관측값, `PASS n / m`을 확인할 수 있습니다. 저장소 루트에서는 `node --test "games/jackpot-drop/tests/*.test.cjs"`로 같은 검사를 실행합니다. 테스트는 Node 표준 라이브러리만 사용합니다.
- `?seed=11`로 같은 시드를 재현합니다. `?start=2`부터 `?start=8`까지는 해당 단계부터 연습하며 기록에는 반영되지 않습니다.
- 브라우저의 `localStorage` 키 `jackpotDrop.v2`에 최고 점수, 최고 단계, 완료한 런 수, 음소거 설정을 저장합니다. 기존 키와 형식을 유지합니다. 저장소가 차단됐거나 데이터가 손상된 경우에도 플레이할 수 있습니다.

## 리소스

보드와 이펙트는 Canvas로 그리고, 소리는 Web Audio로 합성합니다. 글꼴은 브라우저의 시스템 글꼴을 사용합니다.
