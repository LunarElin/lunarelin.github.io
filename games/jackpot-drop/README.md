# Jackpot Drop

보드 위쪽 포에서 한 발에 구슬 하나를 쏘는 20단계 핀볼 캠페인입니다. 1단계를 넘기면 열리는 쇠 구슬로 닿은 벽 한 장을 부수고 JACKPOT으로 가는 길을 열 수 있습니다. 쇠 벽 한 장을 부수면 핀 점수에 200, 단계 배수에 1이 더해집니다. 일부 보드의 움직이는 발판은 구슬을 옆으로 밀어냅니다. 발 사이에 고르는 카드 중 WAVE BALL은 남은 구슬 하나를 좌우로 물결치며 떨어지는 구슬로 바꿉니다. ×5 칸에 착지하면 그때의 배수에 따라 세 가지 잭팟 분수 중 하나가 터집니다. 금 핀에서 모은 코인으로 영구 강화를 사고, 목표에 못 미친 단계는 재도전합니다. 8단계를 넘기면 지도에서 별도 **무한 모드**를 시작할 수 있습니다.

## 실행

- 공개 경로는 [포트폴리오에서 플레이](https://lunarelin.github.io/games/jackpot-drop/)입니다.
- 로컬에서는 [index.html](index.html)을 직접 열거나 Windows에서 [Play.bat](Play.bat)을 실행합니다. 저장소 루트를 정적 HTTP로 제공할 때는 `/games/jackpot-drop/`을 엽니다. 설치나 빌드 과정이 없습니다.
- 보드를 누른 채 좌우로 끌어 조준한 뒤 손을 떼면 그 각도로 발사합니다. 1단계의 금색 발사 가이드는 노릴 곳을 알려 줍니다. 비행 중 보드를 누르는 동안 2배속으로 진행하고, 정산 중 탭하면 즉시 끝납니다. 오른쪽 탄창을 탭하면 장전 구슬이 바뀝니다. 상단 **정지** 메뉴에서 스테이지 지도를 열거나 캠페인을 다시 시작할 수 있습니다.
- 키보드는 **←/→**로 조준하고 **Space** 또는 **Enter**를 눌렀다 떼서 발사합니다. **↑/↓**로 장전 구슬을 고릅니다. 비행 중 **Shift**로 2배속, 정산 중 **Space** 또는 **Enter**로 건너뛰기, **Esc**로 일시 정지·계속, **M**으로 음소거를 전환합니다. 강화 카드는 방향키와 **Enter** 또는 숫자 **1–3**으로 고릅니다.
- 상점에서는 숫자 **1–5**로 강화하고 **Enter**, **Space** 또는 **R**로 재도전합니다. 지도는 방향키와 **Enter**로 조작합니다. 무한 모드 결과에서 **Enter**로 다시 시작하거나 **G**로 지도를 엽니다.
- 일시 정지 메뉴의 **처음부터**에서 다시 시작을 확인하면 코인과 영구 강화가 0이 되고 1단계로 돌아갑니다. 클리어·최고 기록, 무한 모드 해금, 음소거 설정은 이어집니다.
- 페이지가 가려지면 시뮬레이션과 소리가 멈추고 조준이 취소됩니다. 브라우저가 포인터 입력을 취소할 때도 조준만 취소됩니다.

## 유지관리와 검증

- `src/rules.js`는 보드·충돌·점수·강화 규칙을, `src/game.js`는 라운드 상태 전이를 담당합니다. `src/render.js`, `src/input.js`, `src/main.js`에서 화면과 입력을 연결합니다.
- [tests.html](tests.html)에서 규칙·상태 전이 자동 검사의 기대값과 관측값, `PASS n / m`을 확인할 수 있습니다. 저장소 루트에서는 `node --test "games/jackpot-drop/tests/*.test.cjs"`로 같은 검사를 실행합니다. 테스트는 Node 표준 라이브러리만 사용합니다.
- `?seed=11`로 같은 시드를 재현합니다. `?start=2`부터 `?start=20`까지는 해당 캠페인 단계, `?endless=1`은 무한 모드 연습입니다. 연습 판의 진행은 저장하지 않습니다.
- `jackpotDrop.v3`에 코인, 영구 강화, 캠페인의 시드·단계·도전 번호, 최고 기록, 무한 모드 해금과 음소거 설정을 저장합니다. 페이지를 다시 열면 해당 도전을 기본 랙과 보드로 다시 시작합니다. 이전 저장의 `campaign.up`과 도전 중 고른 카드는 읽지 않습니다. 저장이 차단된 환경에서도 플레이할 수 있습니다.

## 리소스

보드와 이펙트는 Canvas로 그리고, 소리는 Web Audio로 합성합니다. 글꼴은 브라우저의 시스템 글꼴을 사용합니다.
