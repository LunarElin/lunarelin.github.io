# Jackpot Drop

스프링으로 한 발에 구슬 하나를 쏘는 20단계 핀볼 캠페인입니다. 첫 단계의 깔때기는 잭팟 위치를 안내합니다. 이후의 V자 쇠 벽은 일반 구슬을 모아 두고, 쇠 구슬에 닿으면 철문과 함께 부서집니다. 분열이나 게이트에서 생긴 구슬은 서로 튕깁니다. 금 핀에서 모은 코인으로 영구 강화를 사고, 목표에 못 미친 단계는 새 배치에서 재도전합니다. 8단계를 넘기면 스테이지 지도에서 별도 **무한 모드**를 시작할 수 있습니다.

## 실행

- 공개 경로는 [포트폴리오에서 플레이](https://lunarelin.github.io/games/jackpot-drop/)입니다.
- 로컬에서는 [index.html](index.html)을 직접 열거나 Windows에서 [Play.bat](Play.bat)을 실행합니다. 저장소 루트를 정적 HTTP로 제공할 때는 `/games/jackpot-drop/`을 엽니다. 설치나 빌드 과정이 없습니다.
- 터치는 보드를 누른 채 충전하고 손을 떼서 발사합니다. 금색 구간에서 떼면 퍼펙트 발사입니다. 비행 중 보드를 누르는 동안 2배속으로 진행하고, 정산 중 탭하면 즉시 끝납니다. 발사대 오른쪽 탄창을 탭하면 장전 구슬이 바뀝니다. 상단 **정지** 메뉴에서 스테이지 지도를 열거나 캠페인을 다시 시작할 수 있습니다.
- 키보드는 **Space** 또는 **Enter**를 눌렀다 떼서 발사합니다. 비행 중 **Shift**로 2배속, 정산 중 **Space** 또는 **Enter**로 건너뛰기, **Esc**로 일시 정지·계속, **M**으로 음소거를 전환합니다. 방향키로 탄창의 장전 구슬을 고릅니다. 강화 카드는 방향키와 **Enter** 또는 숫자 **1–3**으로 고릅니다.
- 상점에서는 숫자 **1–5**로 강화하고 **Enter**, **Space** 또는 **R**로 재도전합니다. 지도는 방향키와 **Enter**로 조작합니다. 무한 모드 결과에서 **Enter**로 다시 시작하거나 **G**로 지도를 엽니다.
- 페이지가 가려지면 시뮬레이션과 소리가 멈추고 충전이 초기화됩니다. 화면이 보이는 동안 받은 포인터 취소는 손을 뗀 동작으로 처리합니다.

## 유지관리와 검증

- `src/rules.js`는 보드·충돌·점수·강화 규칙을, `src/game.js`는 라운드 상태 전이를 담당합니다. `src/render.js`, `src/input.js`, `src/main.js`에서 화면과 입력을 연결합니다.
- [tests.html](tests.html)에서 규칙·상태 전이 자동 검사의 기대값과 관측값, `PASS n / m`을 확인할 수 있습니다. 저장소 루트에서는 `node --test "games/jackpot-drop/tests/*.test.cjs"`로 같은 검사를 실행합니다. 테스트는 Node 표준 라이브러리만 사용합니다.
- `?seed=11`로 같은 시드를 재현합니다. `?start=2`부터 `?start=20`까지는 해당 캠페인 단계, `?endless=1`은 무한 모드 연습입니다. 연습 판의 진행은 저장하지 않습니다.
- `jackpotDrop.v3`에 코인, 영구 강화, 캠페인 체크포인트, 최고 기록, 무한 모드 해금과 음소거 설정을 저장합니다. 페이지를 다시 열면 그 단계를 처음부터 이어 합니다. 이전 v3 기록의 다중 장전 필드는 무시하고, 캠페인과 랙은 이어서 사용합니다. 저장이 차단된 환경에서도 플레이할 수 있습니다.

## 리소스

보드와 이펙트는 Canvas로 그리고, 소리는 Web Audio로 합성합니다. 글꼴은 브라우저의 시스템 글꼴을 사용합니다.
