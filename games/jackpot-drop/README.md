# Jackpot Drop

스프링을 당겨 구슬을 쏘는 핀볼 로그라이트입니다. 핀과 범퍼를 이용해 점수를 쌓고 하단의 ×5 잭팟 칸을 노립니다. 목표 점수를 넘기면 강화 카드를 받아 다음 보드로 이동합니다. 8단계를 통과하면 무한 모드가 이어집니다.

## 실행

- 공개 경로는 [포트폴리오에서 플레이](https://lunarelin.github.io/games/jackpot-drop/)입니다.
- 로컬에서는 저장소 루트를 정적 HTTP 서버로 제공한 뒤 `/games/jackpot-drop/`을 엽니다. 진입 파일은 [index.html](index.html)입니다. 설치나 빌드 과정이 없습니다.
- 터치는 보드나 **발사**를 누른 채 충전하고 손을 떼서 발사합니다. 금색 구간에서 떼면 퍼펙트 발사입니다. 도구를 얻으면 **구슬**과 **스프링**에서 바꿉니다. **정지** 메뉴에서 계속하거나 처음부터 다시 시작할 수 있습니다.
- 키보드는 **Space** 또는 **Enter**를 눌렀다 떼서 발사합니다. 좌우로 구슬, 상하로 스프링을 고릅니다. 방향키와 **Enter** 또는 숫자 **1–3**으로 강화 카드를 고릅니다. **Esc**로 일시 정지하고 **M**으로 음소거합니다.
- 페이지가 가려지면 시뮬레이션과 소리가 멈춥니다. 화면 이탈이나 취소 동작으로 끊긴 충전은 발사되지 않습니다.

## 유지관리와 검증

- `src/rules.js`는 보드·충돌·점수·강화 규칙을, `src/game.js`는 라운드 상태 전이를 담당합니다. `src/render.js`, `src/input.js`, `src/main.js`에서 화면과 입력을 연결합니다.
- 저장소 루트에서 `node --test "games/jackpot-drop/tests/*.test.cjs"`로 규칙과 상태 전이를 검증합니다. 테스트는 Node 표준 라이브러리만 사용합니다.
- `?seed=11`로 같은 시드를 재현합니다. `?start=2`부터 `?start=8`까지는 해당 단계부터 연습하며 기록에는 반영되지 않습니다.
- 브라우저의 `localStorage` 키 `jackpotDrop.v2`에 최고 점수, 최고 단계, 완료한 런 수, 음소거 설정을 저장합니다. 기존 키와 형식을 유지합니다. 저장소가 차단됐거나 데이터가 손상된 경우에도 플레이할 수 있습니다.
