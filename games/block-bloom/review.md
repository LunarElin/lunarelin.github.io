## 수정한 핵심 결함

- 반 칸 경계에서 정수 프리뷰를 화면 위치의 기준으로 재사용해, 수평 1px 입력에 수직 10~12px가 튀는 경로를 재현했습니다. 실제 소수 좌표를 유지하고 직사각형의 접촉·접촉 해제 시각을 판정하도록 분리했습니다. 빠른 한 번의 입력에서도 장애물 모서리를 벗어난 즉시 해당 축의 나머지 이동을 이어갑니다.
- 최초 8px의 정지 구간을 없애고 작은 이동부터 따라오게 했습니다. 합쳐진 포인터 표본을 순서대로 계산하고 화면 변환은 프레임당 한 번만 적용합니다. 손을 떼면 100ms 안착하며, 안착 중 다시 잡아도 현재 표시 위치를 유지합니다. 동작 줄이기와 취소·일시 정지·이탈 정리를 검증했습니다.
- 실제 블록 전체 폭이 출구 밖에 걸쳐도 반올림한 위치만 보고 탈출하던 판정을 수정했습니다. 합성은 실제 정렬 범위에 머무르는 접촉 구간만 누름으로 계산하고, 반대 입력은 다른 벽에 막혀도 이전 누름을 취소합니다. 직교 축의 작은 손떨림이나 포인터 이벤트 분할에 따라 합성 결과가 바뀌던 사례도 수정했습니다.
- 드래그의 시작·끝 위치로 한 축만 선택하던 처리를 이동 경로의 연속 판정으로 바꿨습니다. 누른 채 상하좌우로 꺾거나 되돌아올 수 있고, 빈 공간에서는 두 축을 함께 따라갑니다. 드래그 도중 DOM과 포인터 캡처를 유지하고 장애물 충돌을 검사합니다. 한 제스처의 전체 경로를 한 번에 되돌리며, 취소·원위치 복귀는 이동을 소비하지 않습니다. 타이머는 드래그 시작 시점으로 돌아가지 않습니다.
- 트리플 이어하기에서 부분 색상을 버리면 이후 3개 조합을 완성할 수 없었습니다. 수집 블록을 구조함에 보존하고 이후 색상과 함께 매칭합니다. 이전 저장에서 이미 사라진 나머지와 빈 보드도 복구합니다.
- 탭을 바꾸거나 뷰포트를 변경할 때 드래그 잔상이 남거나 다른 칸으로 이동할 수 있었습니다. 포인터 캡처와 변환을 취소하고 보드를 다시 맞춥니다.
- 페이지 이탈 시 남던 실행 자원을 정리하고 bfcache 복귀 시 중복 타이머를 방지합니다. 다른 판으로 넘어가면 이전 힌트 예약도 취소합니다.
- 프리즈가 이동 되돌리기 기록을 차지하던 동작을 제거했습니다. 시작 버튼 전에는 시간이 흐르지 않습니다.
- 긴 상점 화면에서도 닫기 버튼을 유지하고, 팝업 종류를 바꾸면 위에서 읽도록 스크롤을 초기화합니다. 결과와 실패 화면에서도 홈으로 나갈 수 있습니다.

## 검증 구분

- **규칙·연속 충돌·DOM:** `node --test games/block-bloom/rules.test.mjs games/block-bloom/tests/drag.test.mjs games/block-bloom/tests/ui.test.mjs` — 54개 통과. 작은 이동·두 축 점프 재현·다양한 블록 모양·8방향 모서리 접촉 해제·실제 출구 정렬·합성 접촉/반전/누름·포인터 입력 분할·프레임 갱신·최종 입력 반영·안착 중 재선택 회귀를 포함합니다.
- **보조 수치 검토:** 고정 시드 720개 보드, 139,586개 입력, 305회 종료 판정에서 시각 관통·입력량 초과 점프·반 칸 초과 프리뷰 오차·잘못된 출구·원본 상태 변이 없음. 별도 692개 경로를 1·4·50회로 나눈 38,060개 입력에서 위치·정수 배치·합성·종료 결과 불일치 없음. 이는 수치 모델 확인이며 실제 기기 성능이나 재미 평가가 아닙니다.
- **실제 데스크톱 Chromium:** 1280×720에서 스크롤·잘림 없이 HUD·보드·아이템 표시, 주요 숫자 38px. 클릭·드래그·상점·도움말·재시작·홈 이동 확인.
- **모바일 뷰포트:** 320×568에서 전 모드 검사. 추가로 375×667, 390×667, 390×844 검사 및 높이 변화 전후 보드 위치 데이터 보존 확인. 320px 숫자 30px, 390px 숫자 32px, 아이템 이름 18px.
- **대체 글꼴:** 별도 로컬 서버에서 `.woff2`를 의도적으로 404 처리. 320×568에서 모드명·아이템 이름의 실제 경계와 줄바꿈 확인.
- **이번 연속 드래그 수정:** 실제 Chromium 1280×720에서 짧은 이동 후 원래 칸 안착, 대각선 이동, 장애물 옆으로 미끄러지는 이동 확인. 320×568 및 390×667에서 대각선 역방향 드래그와 크기 변경 후 보드 보존, 스크롤·44px 미만 버튼 없음, 글꼴 로딩·브라우저 오류 없음을 확인했습니다. 한 번 누른 채 여러 차례 꺾는 경로·합쳐진 포인터 표본·다중 포인터·touch 포인터 타입은 DOM 이벤트 검증이며 실제 손가락 경로 검증은 아닙니다.
- **미검증:** 실제 휴대폰 Safari·Android Chrome, 노치·주소창의 실물 동작, 진동·오디오 지연, 저사양 기기의 피버 FPS와 장시간 메모리, 타 사용자에게 느껴지는 재미. 실제 결제·광고 SDK는 연결하지 않은 데모입니다.
