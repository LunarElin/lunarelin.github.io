## 변경과 저장 호환

- 모든 신규 스테이지와 구형 생성기 판에서 승강기 효과가 동작하지 않습니다. 버튼·발판·Space 단축키·전용 기믹 그림·효과·도움말·현재 기능 문구를 제거했습니다. `elevate`는 오래된 모듈 소비자를 위한 이동 없는 호환 함수로만 남깁니다.
- 스테이지 번호와 진도는 유지합니다. 7판은 `생성기 연습` 복습판이며 골드를 아래로 밀어 왼쪽 출구 높이에 맞춘 뒤 탈출합니다. 10판은 생성기+얼음, 12판은 생성기+열쇠 조합입니다. 이후 반복 조합에도 승강기가 없습니다.
- 배치 버전 1/2와 저장 키는 유지합니다. 구형 승강기 메타데이터를 검증 단계에서 받아 현재 보드와 되돌리기 기록을 정규화하므로 진행 보드가 새 판으로 초기화되지 않습니다. 블록 좌표·시간·코인·아이템·스테이지 진도를 보존합니다. 과거 인증 경로의 승강기 동작은 일반 아래 이동으로 치환합니다.
- 7판의 구형 실습 0단계(골드 y=2)는 아래 이동 안내, 1단계(이미 y=4)는 왼쪽 탈출 안내로 이어지고 2단계는 자유 플레이를 유지합니다. 가이드도 실습의 실제 유효한 이동을 우선 추천합니다.
- 아래로 정렬한 뒤 한 번의 드래그 안에서 다시 출구 높이 위로 돌아가면 세로 실습으로 복귀합니다. 가로 이동 안내만 남아 진행이 막히는 상태를 방지하며 규칙·DOM 회귀를 추가했습니다.

## 검증 구분

- **규칙·캠페인·연속 충돌·DOM:** `node --test games/block-bloom/rules.test.mjs games/block-bloom/tests/campaign.test.mjs games/block-bloom/tests/drag.test.mjs games/block-bloom/tests/ui.test.mjs` — **84개 통과**. 기본 1,200개·캠페인 1,260개 해답·시드 재현과 초기 조합 1,000개 검사, 1~12판 DOM 버튼 완주, 구형 승강기 저장·가이드·무효 API·Space·드래그 반전·되돌리기·재시작·저장 복구를 포함합니다. 시드가 겹치므로 검사 수를 고유 보드 수로 합산하지 않습니다.
- **실제 Chromium 플레이:** 320×568에서 7판의 골드를 아래·왼쪽 두 번의 실제 드래그로 탈출시키고 남은 보드와 공급 블록을 버튼으로 클리어했습니다. 10·12판도 아이템 없이 인증 경로의 버튼 입력으로 완주했습니다. 7판은 PC에서 다시 전체 5/5 클리어를 확인했습니다. 이는 정답 경로를 참고한 동작 확인이며 신규 사용자의 자발적 풀이 결과가 아닙니다.
- **구형 저장 브라우저 확인:** 승강기 사용 직후의 7판 실습 1단계를 복구해 골드 좌표 33.3333%·66.6667%, 987코인과 새 왼쪽 안내를 확인했습니다. Space로 좌표가 바뀌지 않고 새로고침 후에도 같은 판을 유지했습니다. 일반 왼쪽 이동으로 실습 완료 시 1/5 탈출·02:58·987코인이 표시됐습니다. 세 단계 전체 복구·가이드 완주와 구형 history의 undo·reload는 DOM 검증입니다.
- **화면·이동:** 320×568, 390×667, PC 1280×720에서 승강기 버튼·발판·현재 기능 문구 없음, 글꼴 로딩·읽기 크기·44px 터치 영역·문서 넘침 없음. 홈으로 나간 뒤 게임 재진입 시 8판 설명 대기를 유지했습니다. 검사 탭의 브라우저 오류·경고는 없었습니다.
- **기존 기능 회귀:** 작은 이동·네 방향 전환·장애물 모서리·실제 출구 폭·합성 누름·취소·안착·멀티 포인터·시간 보호·승패·아이템·경제·저장·자원 정리·bfcache 테스트를 함께 실행했습니다. 이전 1~12판 실제 브라우저 확인 이력은 앞선 커밋의 검토 기록에 남습니다.
- **미검증:** 실제 휴대폰 Safari·Android Chrome, 손가락의 복잡한 연속 경로, 노치·주소창 실물 동작, 진동·오디오 지연, 저사양 피버 FPS·장시간 메모리·배터리, 신규 사용자의 재미·학습 효과·장기 난이도. 실제 결제·광고 SDK는 데모 범위 밖입니다.
