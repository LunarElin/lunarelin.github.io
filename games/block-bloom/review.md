## 난이도와 학습 흐름

- 기존 첫판은 8블록·점유 16~22칸이었고, 5개 시드의 인증 경로 73~123회·가이드 경로 57~99회였습니다. 새 첫판은 블록 2개를 각각 같은 색 출구로 보내며 실제 두 번의 드래그로 완료했습니다. 경로 수치는 최단 해답이나 사람의 난이도 점수가 아닙니다.
- 첫 7판은 고정 학습 배치입니다. 전체 블록은 2·3·4·4·6·4·5개, 실습은 2·2·3·2·3·3·2단계입니다. 새 기믹을 만날 때 작은 보드로 다시 시작하고 남은 블록으로 스스로 적용합니다. 합성·수집·공급량 차이 때문에 모든 판의 블록 수를 일률적으로 늘리지는 않습니다.
- 현재 단계의 실제 블록을 탈출·합성하거나 승강기로 이동해야 진도가 진행됩니다. 실습 중에는 시계·빙결·피버 시간과 아이템 소비를 보호합니다. 지정 블록·방향을 강조하고, 손떨림은 안내 축으로 따라오게 하며 잘못된 선택·다른 방향·취소는 진도를 소비하지 않습니다. 완료 후 아이템과 자유 이동·타이머를 복귀시킵니다.
- 8~12판은 배운 기믹의 조합을 6·6·8·9·10개 블록으로 시작합니다. 첫 조합은 1×1만 사용합니다. 초기 공급은 2개이며 이후 조합 순환에서 공급·블록·모양·섞기를 늘립니다.
- 블록을 줄인 뒤에도 일부 조합의 생성 경로가 길었습니다. 8~12에서는 같은 보드로 돌아오는 왕복을 제거하고 목표 이동량 30·30·40·45·50칸 안의 첫 후보를 선택합니다. 최대 24개가 모두 목표를 넘으면 그중 가장 짧은 것을 선택합니다. 무한 탐색이나 모든 시드의 강제 상한은 아닙니다.
- 200개 시드씩 총 1,000개 조합판 검사에서 인증 이동량의 최대는 30·15·39·45·50칸, 평균은 약 21.12·14.42·24.82·38.69·40.49칸이었습니다. 시드 1001의 가이드 경로는 8판 64→19회, 11판 104→41회로 줄었습니다. 이 수치는 생성 품질 검사이며 사람의 풀이 시간·재미·최단 해답을 뜻하지 않습니다.

## 저장과 입력 회귀

- 새 배치는 `layoutVersion:2`입니다. 기존 캠페인의 버전 없는 저장은 1로 보존하여 진행 중인 보드·힌트·같은 배치 재시작을 유지합니다. 다음 판부터 새 구성이 적용됩니다. 구형 모드 저장의 진행 보드·코인·아이템·설정과 캠페인 합류 정책도 유지합니다.
- `lessonIndex`를 이동 스냅샷·저장과 함께 보존합니다. 실습 중 새로고침·탭 복귀는 같은 단계로, 실습 직후 되돌리기는 이전 실제 단계로, 재시작은 해당 배치의 첫 단계로 복귀합니다. 마지막 실습 전 대기 시간이 자율 플레이 첫 틱에 몰려 차감되지 않습니다.
- 마우스·touch 타입 포인터·방향 버튼·키보드·승강기·Space·아이템 경로의 제한을 검사합니다. 학습 종료 후 기존 연속 드래그·방향 전환·장애물 충돌·합성 누름·안착·취소를 유지합니다.
- 실제 연출 중 문서 폭이 378~379px로 커지던 것을 발견했습니다. 파편과 손 안내를 플레이 영역 안에 유지해 320px 폭에서도 가로 넘침을 막았습니다. 트리플 108개 파티클이 보이는 상태에서도 문서 크기 320×568을 확인했습니다.

## 검증 구분

- **규칙·캠페인·연속 충돌·DOM:** `node --test games/block-bloom/rules.test.mjs games/block-bloom/tests/campaign.test.mjs games/block-bloom/tests/drag.test.mjs games/block-bloom/tests/ui.test.mjs` — **78개 통과**. 기본 1,200개와 캠페인 1,260개 보드 해답·재현, 별도 초기 조합 1,000개 검사, 실제 승강기 인증 경로·실습 진도·시간·저장·기존 버전 재현을 포함합니다. 조합 검사에는 앞선 시드와 겹치는 사례가 있으므로 세 수를 고유 보드 수로 합산하지 않습니다.
- **실제 데스크톱 Chromium 플레이:** 320×568에서 1~7판을 순서대로 완주했습니다. 1판은 두 번의 드래그, 2판은 열쇠·같은 색 일반 블록·남은 블록 드래그, 4판은 실제 반 칸 누름 합성을 확인했습니다. 다른 동작은 실제 블록·방향·승강기 버튼으로 수행했습니다. 4판 합성 직후 새로고침에서 `2/2`와 숫자 4·시간 보호가 유지됐습니다.
- **조합 플레이:** 같은 Chromium에서 고정 시드의 8~12판을 아이템 없이 버튼으로 모두 완주했습니다. 열쇠·얼음·트리플·추가 공급과 완료 판정을 확인했습니다. 검증은 인증 경로를 참고한 동작 확인이며, 처음 접한 플레이어가 혼자 이해하고 푼 결과가 아닙니다.
- **화면:** 모든 실습 문구의 높이가 22 또는 44px로 56px 안내 줄 안에 들어왔습니다. 320px에서 보드 폭 268~270px, 390×667에서 340px, PC 1280×720에서 384px. 검사한 화면의 필수 버튼·블록은 44px 이상이며 문서 스크롤·경고·브라우저 오류 없음. 홈 복귀 후 재진입에서 13판 설명 대기 진도를 확인했습니다.
- **미검증:** 실제 휴대폰 Safari·Android Chrome, 실제 손가락의 복잡한 경로, 노치·주소창 실물 동작, 진동·오디오 지연, 저사양 피버 FPS·장시간 메모리·배터리, 사용자 학습 효과·재미·난이도 균형. 실제 결제·광고 SDK는 연결하지 않은 데모입니다.

## 다음 개선 우선순위

1. **실기기 호환:** iPhone Safari와 Android Chrome에서 손가락 입력·주소창·안전 영역·오디오 재개를 확인해 에뮬레이션에서 놓치는 버튼 가림과 입력 실패를 줄입니다.
2. **학습과 난이도:** 신규 사용자의 첫 7판 안내 이해·8판 첫 조합 실패·힌트 소모를 관찰해 기믹 순서와 보드 선택 목표를 조정합니다. 현재 경로 검사만으로 학습 효과나 재미를 보장할 수 없습니다.
3. **저사양 연출:** 실제 기기의 피버 프레임·메모리를 측정해 파편·블러·동시 음성 수를 조정합니다.
