# BLOCK BLOOM · 블록 블룸

`Block Out! — Color Sort Puzzle`의 핵심 색상 탈출 규칙과 광택·돌기형 블록 표현을 참고한 독립 HTML5 퍼즐입니다. 하나의 스테이지 진도를 따라 새 기믹을 배우고 조합합니다. 원본 자산·코드·레벨을 복사하지 않았습니다. [레퍼런스와 수익화 설계 노트](design.html).

## 실행

빌드나 런타임 패키지 설치 없이 [공개 게임](https://lunarelin.github.io/games/block-bloom/) 또는 정적 HTTP 서버에서 `games/block-bloom/`을 엽니다. 저장소 루트에서 다음 미리보기를 실행하면 `.mjs`와 글꼴 MIME 타입도 설정됩니다.

```powershell
python games/block-bloom/tests/serve.py --port 4174
```

`http://127.0.0.1:4174/games/block-bloom/`에 접속합니다. `--no-font`는 글꼴 실패 검증 전용 옵션입니다. 실행에는 외부 라이브러리나 웹 폰트 연결이 필요하지 않습니다.

## 조작과 스테이지

- 블록을 누른 채 마우스·손가락 경로를 따라 상하좌우로 연속 이동합니다. 작은 움직임부터 두 축을 함께 따라가고, 장애물 옆을 미끄러지다 모서리를 벗어나면 막혔던 방향도 즉시 재개합니다. 손을 떼면 100ms 동안 가까운 칸에 안착합니다. 동작 줄이기 설정에서는 즉시 맞춥니다. 한 번의 드래그는 이동·되돌리기 1회이며, 원위치 복귀·취소는 이동을 소비하지 않습니다.
- 블록 선택 후 방향키·WASD·화면 화살표로도 이동합니다. 출구에 블록 전체 폭을 맞추고 같은 색 출구 밖으로 한 번 더 밉니다. 기호 ● ◆ ✦ ▲로 색을 구별할 수도 있습니다.
- 모드를 고르는 화면 없이 스테이지를 순서대로 진행합니다. 클리어하면 다음 기믹을 예고하고, 다음 스테이지로 넘어가면 해당 기믹의 그림·설명·팁을 먼저 보여줍니다. `시작` 전에는 시간과 보드 입력이 멈추며, 새로고침해도 설명 대기를 유지합니다. 일시 정지 메뉴에서는 재시작·설정·일일 선물·별 보상·홈 복귀를 선택합니다.
- 1~7스테이지는 작은 고정 학습 보드에서 시작합니다. 1~6판에서는 강조한 실제 블록을 손·화살표와 짧은 안내에 따라 움직여 새 기믹을 한 번 직접 수행하고, 7판에서는 생성기를 복습합니다. 안내한 블록과 이동 축으로 목표를 달성해야 다음 안내로 넘어갑니다. 실습 중에는 시간과 아이템 사용을 보호하며, 실습을 마치면 남은 보드를 자유롭게 풉니다. 실습 중단·새로고침 후에도 같은 단계에서 이어갑니다.
- 컬러 탈출: 같은 색 출구로 모든 블록 탈출.
- 트리플 도크: 탈출한 블록을 7칸 도크에 수집, 같은 색 3개 자동 제거. 7번째 칸에서 매칭이 일어나면 매칭을 먼저 판정합니다.
- 머지 2048: 같은 색·숫자 블록에 맞춰 접촉한 채 반 칸만큼 더 밀어 합성. 실제 옆축 정렬 오차 0.2칸 이내에서 누름을 계산하며, 반대 방향 입력으로 취소합니다. 숫자 4 이상만 탈출.
- 키 & 락: 각 색 열쇠 블록이 먼저 탈출하면 해당 출구 개방.
- 아이스 브레이크: 얼음 블록은 움직일 수 있지만 다른 블록 2개가 탈출해 두 겹을 벗겨야 출구를 통과합니다.
- 생성기: 초기 보드를 비운 뒤 대기 블록을 하나씩 공급합니다. 학습판은 2개부터 시작하며 이후 스테이지의 공급량은 난도에 맞춰 증가합니다.

| 스테이지 | 이번 판의 기믹 | 전체 블록 |
| --- | --- | ---: |
| 1 | 같은 색 출구로 보내는 컬러 탈출 | 2 |
| 2 | 열쇠로 색상별 출구 잠금 해제 | 3 |
| 3 | 열쇠 + 두 겹 얼음 | 4 |
| 4 | 같은 색·숫자의 합성 | 4 |
| 5 | 7칸 수집함의 같은 색 3개 매칭 | 6 |
| 6 | 추가 블록을 내보내는 생성기 | 4 |
| 7 | 생성기 연습 | 5 |
| 8 | 수집함 + 열쇠 | 6 |
| 9 | 합성 + 얼음 | 6 |
| 10 | 생성기 + 얼음 | 8 |
| 11 | 수집함 + 열쇠 + 얼음 | 9 |
| 12 | 생성기 + 열쇠 | 10 |

전체 블록 수는 생성기 대기를 포함합니다. 6·7·10·12판의 생성기 대기는 2개입니다. 1~7판은 240초, 8~12판은 210초, 이후는 180초이며 실습 중에는 차감하지 않습니다.

8스테이지부터는 배운 기믹을 낮은 밀도에서 조합합니다. 8~12판은 인증 경로에서 같은 보드로 돌아오는 왕복을 제거하고, 목표 이동량 안에 드는 첫 배치를 최대 24개 후보에서 선택합니다. 24개가 모두 목표를 넘으면 그중 가장 짧은 경로를 사용합니다. 목표는 순서대로 30·30·40·45·50칸이며 최단 해답이나 실제 풀이 시간의 보장은 아닙니다. 첫 조합인 8판은 1×1 블록만 사용합니다. 13스테이지부터는 8~12의 조합을 순환하고, 같은 조합이 다시 나올 때 블록 수와 생성기 공급량을 늘립니다. 수집은 3개 묶음으로 최대 12개, 합성은 세 쌍에서 네 쌍으로, 일반 블록은 최대 12개, 생성기 대기는 2→3→4개로 증가합니다. 섞는 이동 수도 단계적으로 늘리고, 18판부터 2×2 블록을 추가합니다. 매 판 현재 기믹을 다시 설명하며, 이미 배운 기믹의 응용을 새 기믹이라고 표시하지 않습니다. 첫 7개 학습판은 시드와 관계없이 같은 기본 배치를 사용하고, 이후 조합판은 시드로 생성합니다. 무한히 서로 다른 배치 수나 모든 판의 체감 난도 증가를 보장하는 시스템은 아닙니다.

## 아이템·보상

해머(선택 블록), 프리즈(20초 타이머 보호), 가이드 빔(다음 이동), 리와인드(직전 이동), 마그넷(선택 색 전체) 5종을 실습 후 자유 플레이에서 즉시 사용합니다. 실습 중에는 아이템 대신 현재 조작 안내를 표시하고 아이템을 소비하지 않습니다. 해머·마그넷은 먼저 아이템을 누른 뒤 블록을 선택할 수도 있습니다. 길게 누르면 소비 없이 효과를 설명합니다. 유효하지 않은 사용은 소비하지 않습니다. 되돌리기는 시간을 복원하지 않고 사용한 아이템도 환불하지 않으며, 시간만 정지하는 프리즈는 이동 기록에 넣지 않습니다.

초기 350 코인, 클리어 보상 90~130 코인, 일일 100 코인, 누적 별 3·9·18 보상, 1회 무료 스타터 번들, 400 코인 오로라 보드를 제공합니다. 별은 남은 시간 65초 초과면 3개, 25초 초과면 2개, 그 이하면 1개입니다. 이어하기는 보드 유지·45초 추가·수집 블록 구조함 보관, 비용 120/180 코인, 한 판 최대 2회입니다. 구조함의 색은 새 수집 블록과 함께 3개씩 매칭되어 조합이 사라지지 않습니다.

실제 결제·실제 광고·외부 분석 전송은 없습니다. 광고 보상 버튼은 데모이며 일일 선물과 지급 제한을 공유합니다. 한국 시간 자정 기준, 이 브라우저의 저장 기록으로 판정합니다. 상품 구성·부스터·이어하기·재방문 보상의 수익화 가설과 실제 운영 시 필요한 서버 검증은 제작 노트에 구분해 기록했습니다.

## 생성·저장·연출

- 첫 7개 학습판은 기믹의 목표 동작과 짧은 해답을 직접 배치하며, 7판은 일반 블록 이동과 생성기 공급을 복습합니다. 이후에는 블록 삽입과 유효한 이동을 역순으로 기록해 해답을 가진 보드를 생성합니다. 합성 기본 배치, 트리플 색 묶음, 열쇠·빙결의 선행 조건, 생성기 공급을 해답에 포함합니다. 스테이지 기믹 조합과 힌트도 같은 생성 경로를 재현합니다. 생성 해답 길이는 최단 해답이나 실제 사용자의 풀이 시간과 다릅니다.
- 드래그의 실제 소수 좌표와 정수 규칙 프리뷰를 분리합니다. 이동 구간의 충돌·접촉 해제 시각을 계산해 벽 관통과 축 점프를 막고, 출구는 실제 블록 전체 폭을 판정합니다. 지원 브라우저의 합쳐진 포인터 표본도 순서대로 처리하며 변환은 애니메이션 프레임마다 한 번만 씁니다. 안착 도중 다시 잡으면 현재 보이는 위치에서 이어집니다. 취소·일시 정지·크기 변경·이탈 시 예약 프레임과 안착 애니메이션을 정리합니다. 저장에는 확정한 정수 위치만 남깁니다.
- 힌트는 생성 경로의 반복 상태를 건너뛰고, 경로 밖에서는 제한된 탐색으로 가까운 탈출 또는 합성을 찾습니다. 임의의 교착 보드까지 풀어주는 완전 탐색기는 아닙니다. 길을 찾지 못하면 아이템을 소비하지 않습니다.
- `localStorage`의 `block-bloom:v1`에 스테이지 진도(`profile.stage`)·진행 보드·실습 단계·코인·아이템·설정·되돌리기 기록을 저장합니다. 새 보드는 `layoutVersion: 2`이며, 기존 캠페인의 배치 버전이 없는 저장은 버전 1의 보드를 유지합니다. 버전별 생성 경로를 남겨 기존 보드의 힌트와 같은 배치 재시작을 재현합니다. 승강기는 새 판과 기존 진행 판에서 모두 제거했습니다. 저장 복구 시 현재 보드와 되돌리기 기록의 승강기 정보만 제거하고 블록 좌표·남은 시간·재화를 보존합니다. 7판의 기존 실습 대기는 블록을 아래로 밀어 출구 높이를 맞춘 뒤 왼쪽으로 탈출하는 일반 이동 안내로 이어집니다. 이미 위치를 옮긴 판은 해당 좌표에서 이어가고, 실습을 마친 판은 자율 플레이를 유지합니다. 이전 인증 경로의 승강기 동작은 일반 아래 이동으로 바꿔 힌트·재시작에서도 승강기를 요구하지 않습니다. 완료 보상과 다음 스테이지 진도를 결과 창 전에 한 번에 저장해 새로고침 중복 지급을 막습니다. 구형 모드별 저장의 경제·설정·유효한 진행 보드는 보존합니다. 진행 중이던 판은 실제 기믹 설명을 확인하고 마저 끝낸 뒤 캠페인 진도에 합류하며, 구형 저장의 캠페인 진도는 1에서 시작합니다. 이전 저장의 구조함 필드와 버려진 색의 나머지, 이미 빈 구형 보드의 완료도 복구합니다. 저장 차단·손상 시 새 판으로 플레이할 수 있으며 다른 기기와 동기화하지 않습니다.
- 파편·충격파·출구 잔상·보드 흔들림·점수 팝업·연속 탈출 콤보·피버·절차적 Web Audio 효과음·지원 기기 진동. 4초 이내 콤보, 5콤보부터 10초 피버·점수 2배입니다.
- 파티클 180개 상한과 오디오 노드 정리, 설정·시스템 동작 줄이기, 모달·숨겨진 탭에서 시간·연출 정지, 키보드·색상 기호를 지원합니다. 탭 전환 시 드래그를 취소하고, 페이지 이탈 시 타이머·효과·오디오·리스너를 정리합니다. bfcache 복귀는 시계를 한 개만 재개합니다. HUD는 바뀐 숫자만 갱신합니다.
- 모바일 우선 한 화면 배치, 동적 뷰포트·안전 영역, HUD 30~38px·행동 이름 18~22px·효과 설명 16px, 44px 이상 터치 영역을 제공합니다. 글꼴과 Kenney 아이콘의 출처·라이선스·사용 파일·가공 내용은 [리소스 안내](assets/README.md)에 있습니다.

## 검증

규칙 검증은 설치 없이 실행합니다.

```powershell
node --test games/block-bloom/rules.test.mjs games/block-bloom/tests/campaign.test.mjs games/block-bloom/tests/drag.test.mjs
```

DOM 통합 검증은 테스트 전용 의존성을 사용합니다. Node.js 24 권장.

```powershell
cd games/block-bloom/tests
pnpm install --frozen-lockfile
pnpm test
```

규칙·캠페인·연속 충돌·DOM 검증: 기본 규칙의 1,200개 보드와 스테이지별 조합의 전체 해답·시드 재현, 작은 학습 보드·실제 목표 동작 후 안내 진행·시간 보호·잘못된 입력과 아이템 소비 차단·실습 중 새로고침·되돌리기, 배치 버전별 힌트·재시작 호환, 순차 진도·기믹 설명 대기·다음 스테이지·구형 저장 전환, 충돌·출구 폭·잘못된 출구, 합성·열쇠·빙결·7번째 매칭, 생성기·기존 승강기 저장 복구, 힌트 종료, 아이템·경제·보상, 구조함 이어하기·구형 저장 복구, 네 방향 전환·작은 이동·장애물 가장자리·모서리 접촉 해제·입력 분할 일관성·실제 출구 정렬·합성 누름과 반전·원위치 복귀·취소·되돌리기·다중 포인터 차단·빠른 대각선 충돌·합쳐진 포인터 표본·프레임당 갱신·안착 중 재선택·다른 입력과의 경합, 페이지 이탈·bfcache 복귀, 길게 누르기·비동기 힌트 취소, HUD 중복 갱신 억제, 파일·포트폴리오 연결.
