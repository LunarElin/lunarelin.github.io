레퍼런스에서 확인한 것

Block Out! — 공식 App Store 페이지의 소개와 스크린샷을 참고했습니다. 색상 블록을 같은 색 출구로 밀어내는 규칙, 제한 시간, 돌기 있는 광택 블록과 어두운 입체 보드, 생성기와 승강기가 핵심 표현입니다. 원본 이미지·코드·레벨은 사용하지 않고 CSS와 SVG로 새 그래픽을 제작했습니다. 원작의 모든 특수 기믹이나 레벨을 동일하게 재현한 제품은 아닙니다.

한 판을 깨면, 다음 기믹을 배우기

모드 선택을 없애고 하나의 스테이지 진도로 연결했습니다. 클리어 결과에서 다음 기믹을 예고하고, 다음 스테이지의 그림·설명·팁을 확인한 뒤 시작합니다. 설명을 읽는 동안에는 시간과 보드 입력을 멈추며, 새로고침해도 설명 대기를 유지합니다.

도입 스테이지기믹새로운 판단
1컬러 탈출출구 폭과 블록 크기, 통로를 여는 순서
2열쇠같은 색 열쇠를 먼저 탈출시켜 출구 개방
3열쇠 + 얼음다른 블록 두 번 탈출로 얼음을 깨며 선행 조건 해결
4숫자 합성같은 색·숫자를 밀어 합성, 4 이상부터 탈출
5트리플 도크탈출 순서로 7칸 수집함을 관리, 같은 색 3개 매칭
6생성기첫 보드를 비운 뒤 공급되는 추가 블록까지 탈출
7생성기 + 승강기중앙 두 발판의 빈 목적지로 이동하는 선택 추가

8~12스테이지는 수집함·열쇠·얼음·합성·생성기·승강기의 검증 가능한 조합을 소개합니다. 13스테이지부터는 이 조합을 순환하며 난도를 높이고, 매 판 현재 기믹을 다시 설명합니다. 모든 기믹을 무조건 누적하거나 새 기믹을 무한히 추가하는 구조는 아닙니다. 상세 구성은 게임 README에 기록했습니다.

손끝에 남는 피드백

블록은 돌기·광택·측면 그림자를 가진 CSS 입체 표현입니다. 드래그 중에도 경로 충돌을 검사하고, 성공한 탈출에는 출구 방향 잔상·블록 색 파편·확장 충격파·점수 팝업·보드 흔들림을 겹칩니다. 합성·얼음 파괴·트리플에는 별도 문구를 연결했습니다. Web Audio 합성음은 이동·막힘·탈출·합성·프리즈·클리어를 구분하고, 콤보에 따라 음높이가 올라갑니다.

4초 이내 연속 탈출로 콤보를 쌓고, 5콤보에 10초 피버와 점수 2배를 제공합니다. 파티클 수와 오디오 출력 수명을 제한하며, 동작 줄이기·효과음·진동 설정을 지원합니다. 색상 기호와 키보드 조작을 함께 제공하고, 팝업 또는 숨겨진 탭에서는 시간을 멈춥니다.

생성과 보상 검증

빈 보드에 출구 쪽에서 블록을 삽입하고 유효한 이동만 섞은 뒤, 그 과정을 역순으로 기록합니다. 수집함은 색상 묶음 순서를 유지하고, 열쇠·얼음은 선행 조건이 만족되는 순서로 배치합니다. 합성은 합성 가능한 기본 배치에서 섞고, 생성기는 추가 공급까지 해답에 포함합니다. 스테이지의 기믹 조합과 힌트도 같은 생성 경로를 재현합니다. 새 보드의 해답을 검사하며, 플레이어의 다른 선택이 만든 교착까지 막는 시스템은 아닙니다.

클리어 보상과 다음 스테이지 진도는 결과 창을 열기 전에 한 번에 저장합니다. 저장된 완료 상태를 다시 열어도 보상과 진도를 중복 지급하지 않습니다. 구형 저장의 코인·아이템·설정·유효한 진행 보드는 보존하고, 진행 중인 판을 끝내면 순차 캠페인에 합류합니다. 규칙·캠페인·DOM 검증 실행법과 구체적인 범위는 README에 기록했습니다.
