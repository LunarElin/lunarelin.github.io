레퍼런스에서 확인한 것

Block Out! — 공식 App Store 페이지의 소개와 스크린샷을 참고했습니다. 색상 블록을 같은 색 출구로 밀어내는 규칙, 제한 시간, 돌기 있는 광택 블록과 어두운 입체 보드, 생성기 표현을 참고했습니다. 원본 이미지·코드·레벨은 사용하지 않고 CSS와 SVG로 새 그래픽을 제작했습니다. 원작의 모든 특수 기믹이나 레벨을 동일하게 재현한 제품은 아닙니다.

설명을 읽고, 직접 한 번 따라 하기

모드 선택을 없애고 하나의 스테이지 진도로 연결했습니다. 클리어 결과에서 다음 기믹을 예고하고, 다음 스테이지의 그림·설명·팁을 확인한 뒤 시작합니다. 첫 7판은 블록 수와 동선을 줄인 고정 학습 보드입니다. 강조된 실제 블록에 손·화살표와 짧은 안내를 표시하고, 플레이어가 해당 동작을 수행해야 다음 안내로 넘어갑니다. 실습 중에는 시간과 아이템 소비를 보호하고, 실습이 끝나면 남은 보드를 자유롭게 풀도록 합니다. 설명 대기와 진행 중인 실습 단계는 새로고침해도 유지합니다.

8스테이지부터는 배운 기믹을 낮은 보드 밀도에서 조합합니다. 첫 조합은 작은 1×1 블록만 사용하고, 8~12판은 같은 보드로 되돌아가는 왕복을 제거한 인증 경로와 최대 24개 후보 선택으로 지나치게 긴 배치를 줄입니다. 이후 블록 수·섞는 이동 수·생성기 공급량을 늘려 선택의 부담을 단계적으로 추가합니다. 13스테이지부터는 8~12의 조합을 순환하며 난도를 높이고, 매 판 현재 기믹을 다시 설명합니다. 모든 기믹을 무조건 누적하거나 새 기믹을 무한히 추가하는 구조는 아닙니다. 생성 수치는 난도 조절 수단이며, 실제 체감 난도와 학습 효과는 사용자 플레이테스트로 확인해야 합니다. 상세 구성은 게임 README에 기록했습니다.

손끝에 남는 피드백

블록은 돌기·광택·측면 그림자를 가진 CSS 입체 표현입니다. 드래그 중에도 경로 충돌을 검사하고, 성공한 탈출에는 출구 방향 잔상·블록 색 파편·확장 충격파·점수 팝업·보드 흔들림을 겹칩니다. 합성·얼음 파괴·트리플에는 별도 문구를 연결했습니다. Web Audio 합성음은 이동·막힘·탈출·합성·프리즈·클리어를 구분하고, 콤보에 따라 음높이가 올라갑니다.

4초 이내 연속 탈출로 콤보를 쌓고, 5콤보에 10초 피버와 점수 2배를 제공합니다. 파티클 수와 오디오 출력 수명을 제한하며, 동작 줄이기·효과음·진동 설정을 지원합니다. 색상 기호와 키보드 조작을 함께 제공하고, 팝업 또는 숨겨진 탭에서는 시간을 멈춥니다.

생성과 보상 검증

첫 7개 학습판은 시드와 관계없이 같은 기본 배치를 사용하며, 목표 동작과 짧은 해답을 직접 구성합니다. 이후 조합판은 빈 보드에 출구 쪽에서 블록을 삽입하고 유효한 이동만 섞은 뒤 그 과정을 역순으로 기록합니다. 수집함은 색상 묶음 순서를 유지하고, 열쇠·얼음은 선행 조건이 만족되는 순서로 배치합니다. 합성은 합성 가능한 기본 배치에서 섞고, 생성기는 추가 공급까지 해답에 포함합니다. 스테이지의 기믹 조합과 힌트도 같은 배치 버전·생성 경로를 재현합니다. 생성 해답 길이는 최단 해답이나 사람의 풀이 시간과 다르며, 플레이어의 다른 선택이 만든 교착까지 막는 시스템은 아닙니다.

새 학습·조합 보드는 배치 버전 2를 사용합니다. 기존 캠페인의 버전이 없는 저장은 버전 1의 진행 보드를 그대로 유지하고, 같은 배치의 힌트·재시작을 재현합니다. 승강기는 새 판과 기존 진행 판에서 모두 제거했습니다. 현재 블록 좌표·시간·재화를 보존하면서 저장과 되돌리기 기록의 승강기 정보를 정리합니다. 7판 실습을 기다리던 저장은 블록을 아래로 밀어 출구 높이를 맞춘 뒤 왼쪽으로 탈출하는 일반 이동 안내로 이어지고, 이미 이동한 판은 해당 좌표에서 계속합니다. 이전 인증 경로의 승강기 동작도 일반 아래 이동으로 바꿔 힌트와 재시작에서 해당 기능을 요구하지 않습니다. 클리어 보상과 다음 스테이지 진도는 결과 창을 열기 전에 한 번에 저장해 중복 지급을 막습니다. 구형 저장의 코인·아이템·설정·유효한 진행 보드도 보존하며, 진행 중인 판을 끝내면 순차 캠페인에 합류합니다. 실습의 유효·무효 입력, 단계 진행과 시간 보호, 해답·이전 저장 복구·기존 배치 호환을 포함한 규칙·캠페인·DOM 검증 실행법은 README에 기록했습니다.
