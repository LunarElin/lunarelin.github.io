# NEON ARK · 네온 아크

색상 탑승·교통 정리를 **탐사대 3명 → 탐사정 1대 → 행성 1개**로 연결한 HTML5 로그라이크 퍼즐입니다. 적 HP·공격력·레이저·군인 설정을 제거했습니다. 제한된 도크와 회항으로 9개 항로를 완주합니다. [배경 분석과 현행 설계](design.html).

## 진입·실행

- 진입 파일 `index.html`, 경로 `/games/neon-ark/`. 홈페이지에서 진입하고 `../../#play`로 복귀합니다.
- 런타임 설치·빌드·외부 라이브러리는 없습니다. `.mjs`를 JavaScript MIME으로 제공하는 저장소 루트 정적 서버를 사용합니다.

```powershell
python -c 'import http.server; http.server.SimpleHTTPRequestHandler.extensions_map.update({".mjs":"text/javascript"}); http.server.ThreadingHTTPServer(("127.0.0.1",4175),http.server.SimpleHTTPRequestHandler).serve_forever()'
```

접속: `http://127.0.0.1:4175/games/neon-ark/`.

## 현행 규칙 v3

- 6×5 격납고에서 화살표 앞이 빈 탐사정만 도크로 이동합니다. 먼저 앞을 막는 다른 색 탐사정을 보관해야 할 수 있습니다. 막힌 방향 탭은 이동·선체를 소모하지 않습니다.
- 탐사대는 대기열 맨 앞부터 같은 색 탐사정에 탑승합니다. 정원은 항상 3명입니다. 만석 탐사정 1대가 출항해 행성 1개를 조사합니다. `조사 행성 = 출항 탐사정`, `행성 투입 탐사대 = 조사 행성 × 3`. 마지막 도착까지 연출한 뒤 모든 행성 조사 시에만 강화 선택을 엽니다.
- 기본 도크는 3칸. 자동 탑승·출항을 처리한 뒤에도 도크가 전부 차 있으면 즉시 항로 실패입니다. 비상 이탈로 **선체 −1**, 보상 없음, 실패 되돌리기 불가. 선체 0이면 원정이 종료됩니다. 실패한 보드와 도크를 화면에 남겨 원인을 확인할 수 있습니다.
- 회항(되돌리기)은 기본 **항로당 1회**입니다. 직전의 **출항 없는 정박**만 취소합니다. 출항한 탐사정·완료 행성·실패는 되돌릴 수 없습니다. 사용 횟수는 과거 스냅샷 밖의 현재 값에서 누적하며 새로고침·같은 항로 재도전으로 회복되지 않습니다.
- 진행 중 `중단 · 선체 −1`은 실제 비용을 설명한 뒤 확정합니다. 이미 실패한 항로의 재도전은 추가 비용 없이 같은 배치로 돌아가지만, 줄어든 선체와 사용한 회항 횟수는 유지됩니다. 클리어한 판의 재시작과 보상 중복 획득은 불가합니다.
- 항로별 탐사정 수는 9→12→15→18→21대, 이후 21대입니다. 초반에는 단순 탑승을 익히며, 이후 2~3대에 걸쳐 섞인 대기열을 사용합니다. 제거 가능한 순서와 탑승 우선순위가 달라 임시 정박과 경로 확보가 필요합니다. 모든 생성 판은 **강화 없는 도크 3칸·회항 0회로 클리어 가능한 해법**을 가집니다. 임의 이동의 성공을 보장하지는 않습니다.
- 9개 항로 완주가 한 원정의 끝입니다. 1~8항로 클리어마다 무작위 강화 최대 3개를 제시하고 설명 확인 후 하나를 확정합니다. 9항로는 원정 완료 화면을 표시합니다. 새 원정은 다른 배치, 기본 빌드·선체 3으로 시작하고 기록은 유지합니다.
- 연속 출항은 조사 점수에만 보너스를 줍니다. 행성당 기본 1,000점, 연쇄 단계당 +100점(최대 +400점). 점수는 행성 조사 개수·성공 조건·탐사대 정원을 바꾸지 않습니다.

## 누적 강화

| 강화 | 실제 퍼즐 효과 | 최대 선택 |
| --- | --- | --- |
| 도크 확장 | 정박 도크 3→4→5칸 | 2회 |
| 관측 배열 | 보이는 대기열 6→9→12→15명 | 3회 |
| 긴급 회항 | 항로당 되돌리기 1→2→3회 | 2회 |
| 선체 보강 | 최대·현재 선체 각각 +1. 완전 회복 아님 | 3회, 최대 선체 6 |

선택은 미리보기이며 확정 전에는 적용되지 않습니다. 각 강화는 발동 조건·현재→강화 후 수치·사용 예시를 제공합니다. 후보·선택 상태를 저장하고 최대치에 도달한 후보를 제외합니다. 누적 빌드 항목에서도 설명을 다시 확인할 수 있습니다. 사용형 아이템·재화·상점·결제·광고는 없습니다.

## 저장·입력·연출

- 저장 키 `neon-ark:v3`. 원정·선체·실패 상태·사용한 회항 횟수·직전 정박 스냅샷·보상 선택을 저장합니다. 출항 결과는 애니메이션 전에 확정 저장하고 표시 카운터는 행성 도착 때 갱신합니다. 새로고침으로 실패를 취소하거나 회항 횟수를 되찾을 수 없습니다.
- v2 또는 v1의 효과음 설정과 최고 항로를 별도 `legacyBest` 기록으로 가져옵니다. 전투 버전의 항로·공격 강화·적 HP는 새 탐사 규칙과 맞지 않아 항로 1의 새 원정으로 시작합니다. 이전 저장 키는 삭제하거나 수정하지 않습니다. 탐사 기록과 전투 버전 기록을 섞지 않습니다. 저장 불가 시 세션 내 플레이를 지원합니다.
- 클릭/터치, Tab과 Enter/Space. 시간 제한 없음. 출항 연출 중 중복 입력은 잠시 막습니다. 정지·탭 숨김·페이지 이탈 시 대기 효과를 정리하고 확정된 조사 결과를 표시합니다. OS 동작 줄이기에서는 지연과 파티클 없이 같은 결과를 즉시 표시합니다.
- 탐사정 자체가 엔진 궤적을 남기며 행성으로 이동하고, 도착 시 관측 링·별 입자·`+1 행성 · 3명`을 표시합니다. 레이저·적 타격·폭발·가짜 피해 숫자는 없습니다. 비상 이탈은 선체 표시·실패 안내·붉은 경고 진동으로 표현합니다. 효과 노드는 최대 100개, 각 1초 내 정리합니다.

## UI·글꼴

- 한글 게임 글꼴 Jua를 로컬 `assets/fonts/Jua-Regular.ttf`로 제공합니다. 원본 배포처와 SIL OFL 1.1 라이선스는 `assets/fonts/CREDITS.md`, `OFL-Jua.txt`에 보관합니다. 외부 웹 폰트 요청은 제거했습니다.
- 주요 수치는 28~38px, 상태 이름은 18~22px, 조작 버튼은 18~22px, 설명은 16px, 보조 안내는 14px 이상입니다. 색상 기호·픽토그램은 별도 아이콘 크기를 사용합니다. 버튼 터치 영역은 최소 44×44px입니다.
- 플레이 화면은 목표·선체·탑승·도크·격납고·회항·귀환을 짧게 표시합니다. 점수·강화·기록은 보드 아래 또는 PC 옆에 배치합니다. 상세 규칙은 도움말, 비용은 확인 창, 강화 효과는 선택 상세 화면에 유지합니다. 320px·390px 세로 화면과 PC에서 확인합니다.
- 포트폴리오 전체의 향후 UI 기준은 루트 `AGENTS.md`의 공통 UI 지침을 따릅니다.
