- Official source: https://github.com/google/fonts/tree/main/ofl/jua
- Download: https://raw.githubusercontent.com/google/fonts/main/ofl/jua/Jua-Regular.ttf
- License: SIL Open Font License 1.1; original text in OFL-Jua.txt.
- Downloaded 2026-10-20. Locally converted on 2026-10-21 from the original TTF to `Jua-Regular.woff2` with FontTools 4.67.0 and Brotli 1.2.0. No subsetting, glyph edits, family rename or metrics changes.
- The WOFF2 preserves all 2,520 glyphs, 2,519 Unicode mappings, outlines and horizontal metrics from the original. Its size is 369,236 bytes (original TTF: 2,119,352 bytes; 82.6% smaller). The TTF is omitted from the game to avoid redundant payloads.
- The conversion tools are temporary authoring tools, not game runtime dependencies. The font and original license are served locally; no external font request is required.
