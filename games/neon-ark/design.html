02 / DIAGNOSIS, WITH CONFIDENCE LEVELS

먼저 구매 신뢰, 다음으로 반복 구매의 이유.

관측 또는 가설근거와 해석네온 아크의 대응
P0 · 구매 신뢰 손상이슈 존재 확인 / 영향 규모 미확인스토어 업데이트에 광고 제거 구매 후 광고 노출 수정, 번들 표시 불일치 수정이 명시됩니다. 구매 신뢰를 약화했을 가능성이 있습니다.상품 설명과 실제 지급을 같은 데이터로 구성. 운영 시 영수증 검증·복원·중복 지급 방지 우선.
P0 · 난도와 공정성 인식리뷰에서 확인 / 불가능 여부 미검증레벨 34의 주차 공간과 추가 자원 요구에 대한 불만이 있습니다. 리뷰는 구매 압박 인식의 근거이며 레벨이 실제로 불가능하다는 증명은 아닙니다.기본 도크 3칸 해법을 갖는 보드 생성. 제한 회항과 선체 비용 재도전. 강화는 클리어 보상.
P1 · 실패 회피에 치우친 가치설계 가설공개 상품에는 코인·부스터·광고 제거가 있습니다. 더 잘 플레이하고 싶어서 구매하는 동기가 충분한지는 실제 게임·이벤트와 전환 데이터로 검증해야 합니다.탐사정 출항으로 행성을 조사하고, 클리어 강화로 다음 항로의 도크·관측·회항 여유를 바꾸는 성취 동기.
P1 · 장기 반복 동기 부족미확인 가설스토어 설명만으로 콘텐츠 깊이·재방문 구조가 부족하다고 확정할 수 없습니다. D7 잔존율, 회차별 세션 길이와 반복 구매율이 필요합니다.항로마다 도크·관측·회항·선체 강화를 누적 선택. 다음 보드에서 즉시 체감하는 빌드 변화.
P2 · 유입 시장·광고 의존미확인 가설국가별 구매력·유입 채널·광고 빈도에 따라 다운로드와 IAP가 다르게 움직일 수 있습니다. 해당 게임의 코호트 자료는 미확보입니다.국가·OS·유입별 IAP와 광고 매출, 잔존율, D30 ROAS를 함께 비교.

03 / EXPLORATION RULES V3 · 2026.10.20

탐사대 3명, 탐사정 1대, 행성 1개.

01경로 확보·임시 정박→02동색 탐사대 3명 탑승→03탐사정 출항·행성 조사→04전부 조사 후 강화 선택

적 HP·공격력·레이저와 군인 설정을 제거했습니다. 조사 완료 행성 수는 출항한 탐사정 수와 같고, 행성에 투입된 탐사대 수는 그 세 배입니다. 탐사정이 실제로 행성에 도착할 때 카운터를 갱신합니다. 마지막 도착이 끝나야 클리어 보상으로 넘어갑니다.

화살표 앞이 빈 탐사정만 도크로 이동합니다. 대기열은 맨 앞부터 같은 색 탐사정에 탑승합니다. 후반에는 2~3대에 걸쳐 대기열이 섞이며, 다음에 탈 탐사정 앞을 막는 다른 색 탐사정을 먼저 빼서 임시 정박해야 합니다. 기본 도크 3칸으로 가능한 해법을 만들되, 임의 순서의 성공을 보장하지 않습니다.

도크 포화는 즉시 실패합니다.

자동 탑승과 출항을 모두 처리한 뒤에도 모든 도크가 차 있으면 비상 이탈합니다. 선체 −1, 보상 없음, 실패 되돌리기 불가. 실패한 보드와 도크는 화면에 남깁니다. 선체가 0이면 원정 종료입니다. 출항 연쇄는 점수에만 보너스를 주며 조사 개수나 성공 조건을 바꾸지 않습니다.

회항은 기본 항로당 1회. 직전의 출항 없는 정박만 취소합니다. 이미 출항한 탐사정·완료한 행성·실패는 되돌릴 수 없습니다. 사용 횟수는 새로고침과 같은 항로 재도전으로 회복되지 않습니다. 진행 중 탐사를 중단해도 선체 1을 소모하며 비용을 먼저 설명합니다. 이미 실패한 판의 재도전은 줄어든 선체와 회항 사용 횟수를 유지합니다.

탐사정 9→12→15→18→21대, 이후 21대. 총 9개 항로 완주가 한 원정의 목표입니다. 1~8항로는 강화 선택, 9항로는 원정 완료로 연결됩니다.

04 / PASSIVES THAT CHANGE THE PUZZLE

강화는 다음 판단의 여유를 바꾼다.

⊞

도크 확장

정박 공간 3→4→5칸. 경로를 막는 탐사정을 보관할 여유.

⌁

관측 배열

보이는 대기열 6→9→12→15명. 이후 탑승 색상을 미리 확인.

↶

긴급 회항

항로당 회항 한도 1→2→3회. 출항과 실패는 취소 불가.

⬡

선체 보강

최대·현재 선체 각각 +1. 최대 선체 6. 완전 회복 아님.

클리어마다 무작위 후보 최대 세 개 중 하나를 골라 누적합니다. 최대치에 도달한 후보는 제외합니다. 카드 선택은 미리보기이며 현재→강화 후 수치, 실제 퍼즐 예시, 유지 기간을 읽고 확정합니다. 후보와 선택 상태를 저장해 새로고침으로 바꾸거나 중복 적용할 수 없게 합니다.

사용형 아이템·재화·상점·결제·광고는 없습니다. 공격 피해만 높이는 강화는 제거했습니다. 새 원정은 항로 1과 기본 빌드에서 다른 배치로 시작합니다.
