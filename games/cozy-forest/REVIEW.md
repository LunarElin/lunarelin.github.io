# 2026-10-21 전체 화면 검토

이 문서는 화면 개편 시점의 기록입니다. 이후 후반 플레이·밸런스 수정과 최신 평가는 [BALANCE.md](BALANCE.md)를 참조합니다.

최신 루트 `AGENTS.md` 기준으로 Cozy Forest의 화면·입력·규칙·저장·자산·수명 관리를 검토했습니다. 다른 게임이나 홈페이지의 소스는 수정하지 않았습니다.

## 발견 사항과 수정

- 작은 글씨와 3열 웹페이지형 플레이 화면을 세로 게임 화면으로 교체했습니다. 기록·홈·제작 프롬프트는 일시 정지 메뉴, 아이템 설명은 도감으로 이동했습니다. 아이템은 계속 보드에서 직접 사용합니다.
- Jua 한글 글꼴을 로컬로 제공하고, 수치·상태·버튼을 키웠습니다. Kenney 버튼·별 아이콘·효과음을 실제 적용하고 출처와 동봉 라이선스를 보관했습니다.
- 피버 누적 점수와 시간을 보드 바깥으로 옮겼습니다. 큰 점수·광선·충격파는 유지하면서 임시 이펙트 노드를 112개로 제한하고 예약 타이머·프레임을 추적해 정리합니다.
- 탭을 숨기거나 페이지를 떠날 때 실행 루프와 오디오를 중단하고, 복귀 후에는 일시 정지 상태에서 재개하도록 했습니다. BFCache 복원 시 중복 루프 생성을 막았습니다.
- 미완료 무한 산책 기록도 즉시 저장합니다. 손상된 활성 판의 빈 보드·누락된 해답 ID·불일치한 아이템 사용 수·범위를 벗어난 값은 복구 대상에서 제외합니다. 정상 version 2 저장 형식과 프로필 이관은 유지합니다.
- Windows 기본 정적 서버에서 `.mjs`가 `text/plain`으로 반환되는 문제를 확인했습니다. 표준 라이브러리 기반의 MIME 지정 서버를 추가했습니다.
- 제작 프롬프트의 교정된 본문은 유지하고 글씨·버튼 크기와 공통 스타일 변경에 따른 문서 배치를 보완했습니다.

## 실제 확인한 근거

### 규칙·DOM 통합

총 **23개 통과**: 규칙 11개, DOM 12개. 생성 배치 1,000개·임의 선택 후 재배치 150개 해답, 아이템 5종, 수업 6개 수료, 매칭 우선 포화 판정, 무효·중복 입력, 콤보·피버·시간 보호, 실패·재시작, 보상 중복 방지, 저장 복구·구버전·차단, BFCache·숨김·모달 정지, 효과 상한과 제거, 프롬프트 복사와 권한 거부 대체 동작을 확인했습니다.

변경한 JavaScript 구문 검사와 대상 경로의 `git diff --check`를 수행했습니다. 새 폰트의 게임 한글 문자는 누락이 없었고, HTTP에서 모듈·폰트·이미지·효과음 응답을 확인했습니다.

- 새로고침 뒤 진행 보드와 피버 복구, 도감 열기·닫기, 수업 선택, 제작 프롬프트 왕복, 게임 → 홈 → 게임 진입을 확인했습니다. 브라우저 경고·오류 로그는 관찰되지 않았습니다.

## 부족한 부분과 개선 우선순위

1. **실기기 호환성:** iOS Safari·Android Chrome에서 주소창 접힘, 노치·하단 안전 영역, 회전, 앱 전환·뒤로 가기, 오디오 재개·진동을 확인해야 합니다. 기기별 UI 잘림이나 소리 차이가 남아 있을 가능성이 있어 다음 검증의 최우선입니다.
2. **후반 난도와 재미:** 에이전트가 초반을 직접 플레이했지만 사람의 재미 평가는 아닙니다. 실제 플레이어의 10~20단계 실패 지점·선택 시간·아이템 사용 시점을 관찰해 가려짐과 시간·피버 보상량을 조정하는 것이 다음 기획 작업입니다.
3. **저사양 성능:** 60마리 배치와 피버 연속 매칭에서 프레임·메모리·발열을 측정해야 합니다. 끊김이 관찰되면 파티클 수·SVG 재렌더링 범위를 먼저 줄입니다. 현재 노드 상한과 데스크톱 무오류를 모바일 성능 보장으로 해석하지 않습니다.
