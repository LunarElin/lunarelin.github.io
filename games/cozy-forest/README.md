# 포근포근 숲 · Cozy Forest

모바일과 PC에서 터치·클릭으로 플레이하는 정적 HTML5 동물 트리플 매칭 퍼즐입니다. v2에서는 아이템이 동물 타일과 함께 보드에 등장하고, 우측 패널은 설명만 제공합니다. 기존 작은 머지와 독립된 게임이며, 홈페이지 게임 영역에 진입 버튼을 추가했습니다. 런타임에 패키지 설치, 외부 이미지, 외부 폰트, 서버 API가 필요하지 않습니다.

## 실행

저장소 루트에서 실행합니다.

```powershell
python -m http.server 8765
```

접속: `http://localhost:8765/games/cozy-forest/`

GitHub Pages 배포 시 경로: `https://lunarelin.github.io/games/cozy-forest/`

별도 빌드 없이 저장소 루트와 함께 GitHub Pages에 배포할 수 있습니다. ES 모듈을 사용하므로 HTML 파일을 더블클릭하는 대신 HTTP로 열어야 합니다.

## 장르 선택 근거

조사일: 2026-10-17. 오늘의 미국 iOS 하이브리드 캐주얼 매출 1위를 확정할 수 있는 공개 실시간 자료는 확보하지 못했습니다. 따라서 현재 1위라고 단정하지 않습니다.

공개된 [Sensor Tower의 미국 iOS 2025년 4분기 하이브리드 캐주얼 매출 분석](https://sensortower.com/blog/2025-q4-ios-top-5-hybridcasual-games-revenue-us-642f199ae1714cfff12984cb)에서 Match Factory!의 주간 매출은 연말 약 245만 달러로, 제시된 5개 게임 중 가장 높습니다. [미국 App Store의 공식 게임 설명](https://apps.apple.com/us/app/match-factory/id6449094229)은 같은 오브젝트를 세 개 모으는 트리플 매칭, 제한 시간, 부스터를 핵심으로 소개합니다. 이 구조를 참고해 동물 일러스트와 겹친 타일 보드로 재구성했습니다. 원작의 3D 물리 구현이나 자산을 복제하지 않습니다.

## 규칙과 모드

- 위에 겹치는 타일이 없는 동물을 선택하면 7칸 바구니에 들어갑니다. 같은 동물 3마리는 자동 구조됩니다. 매칭을 먼저 처리한 뒤 바구니 포화를 판정합니다.
- **아이템은 보드에 등장합니다.** 동물과 같은 겹침 규칙을 따르며, 위의 타일을 치워야 선택할 수 있습니다. 누르면 즉시 발동하고 사라집니다. 바구니 칸을 차지하지 않으며 아이템을 세 개 모을 필요도 없습니다.
- 우측은 아이템 5종의 설명과 발견 상태를 보여줍니다. 가방에서 꺼내 쓰는 기능과 구매 기능은 없습니다. 모바일에서는 아이템 설명 버튼으로 해당 영역에 이동합니다.
- **끝없는 산책:** 동물 30~60개, 동물 4~8종, 동물층 최대 3겹으로 점진적으로 어려워집니다. 매번 아이템 3~5개를 추가합니다. 상한 난도 이후에도 새 배치를 계속 생성합니다.
- 실제 제거 가능한 타일 순서를 구한 뒤 동물을 세 마리씩 배정합니다. 아이템의 실제 발동까지 포함해 생성 순서대로 풀 수 있는지를 검증합니다. 임의의 잘못된 선택까지 승리를 보장하지는 않습니다.
- 모든 동물을 구조하면 성공합니다. 남은 선택 아이템은 스테이지와 함께 정리됩니다. 시간 만료 또는 바구니 포화 시 재도전하며 목숨 제한은 없습니다.
- **숲속 학교:** 기본 규칙 1개 + 아이템 5종 실습 = 6개 수업. 각 수업의 아이템이 보드에 등장하고 실제로 눌러야 수료할 수 있습니다. 구조 바구니 수업은 동물 2마리가 바구니에 담긴 상태로 시작합니다. 시간 초과 시 시간을 보충합니다.
- 기본 매칭 300점. 6초 이내 연속 매칭에 콤보 보너스가 붙으며 회당 최대 300점이 추가됩니다. 아이템 발견은 100점, 피버 중 발견은 200점입니다.
- 빠른 매칭 4번으로 **12초 피버**: 매칭 점수 2배, 제한 시간 정지, 매칭당 제한 시간 +2초. 피버 진입을 일으킨 매칭은 일반 배율이며, 진입 이후의 매칭부터 2배입니다. 6초 이상 매칭하지 않으면 게이지가 서서히 줄어듭니다.
- 스테이지 완료 시 도토리 30~60개, 첫 수업 수료 시 도토리 10개를 수집합니다. 도토리는 기록용입니다. 클리어 보상은 결과 연출 전에 저장하므로 즉시 새로고침해도 보존되며 중복 지급하지 않습니다.

## 보드 아이템 5종

| 아이템 | 누르면 발동하는 효과 |
| --- | --- |
| 당근 자석 | 바구니부터 같은 동물 3마리를 즉시 구조 |
| 살랑 바람 | 바구니의 쌍부터 맞출 수 있도록 동물 재배치. 바구니 한 칸만 남고 모두 다른 동물이라면 1마리를 숲으로 복귀시킨 뒤 재배치 |
| 눈꽃 시계 | 15초 제한 시간 정지 |
| 구조 바구니 | 바구니 동물 최대 3마리를 숲 맨 위로 복귀. 비어 있으면 시간 +5초 |
| 별사탕 | 즉시 12초 피버 또는 진행 중 피버를 12초로 갱신 |

보드에서 발견하고 바로 쓰는 흐름에 맞춰 구제·재배치·시간 확보·피버의 역할을 구분했습니다. 모든 아이템은 한 번만 발동하며, 아이템 선택은 동물 수에 영향을 주지 않습니다. 자석이 동물을 구조할 때만 구조 수가 3 증가합니다.

## 이펙트와 피버

- 동물 선택: 터치 링, 바구니로 날아가는 타일, 착지 애니메이션, 효과음과 지원 기기 진동.
- 일반 매칭: 35개 파티클, 별 모양 파편, 충격파, 큰 콤보·점수 팝업, 화면 흔들림, HUD 점수 확대.
- 피버 진입: 큰 FEVER / ×2 타이포그래피, 85개 파티클, 더 큰 화면 흔들림.
- 피버 진행: 회전 광선, 반짝이는 별, 변화하는 테두리와 게이지, 떠오르는 별빛. 보드 상단에 소수점 카운트다운과 이번 피버의 누적 점수가 계속 표시됩니다.
- 피버 중 매칭: 65개 파티클과 큰 충격파, FEVER BONUS ×2와 실제 가산 점수·TIME +2s, 전용 고음 화음, 보드의 따뜻한 섬광과 강한 진동.
- 피버 마지막 3초는 상태 바 색이 바뀌며, 종료 시 누적 점수를 알려줍니다. 일시 정지·모달·숨겨진 탭에서는 피버 시간과 지속 애니메이션도 멈춥니다.
- 이펙트 노드는 상한을 두고 만료 후 제거합니다. `prefers-reduced-motion`에서는 흔들림·광선·별빛·파티클·이동 연출과 진동을 줄이고 피버 상태와 점수 정보는 유지합니다.

## 조작·저장·제작 프롬프트

- 터치와 마우스는 단일 `click` 경로입니다. Tab·방향키로 타일 이동, Enter로 선택, Esc로 일시 정지합니다. 가려진 타일은 입력에서 제외합니다.
- Web Audio 효과음은 사용자 입력에서 생성하며 소리 버튼과 일시 정지 설정에서 끌 수 있습니다. 진동은 지원 기기에서만 동작합니다.
- 화면 폭에 따라 3열 데스크톱, 2열 태블릿, 세로 모바일 레이아웃을 사용합니다. 동물·배경·아이콘은 외부 의존성이 없는 SVG입니다.
- `localStorage` 키 `cozy-forest:v1`을 유지하고 저장 내용의 게임 버전을 2로 구분합니다. 보드·발견한 아이템·바구니·시간·피버 누적 점수·기록·수료 상태를 동작 시, 플레이 중 5초마다, 페이지를 떠날 때 저장합니다.
- 이전 버전의 최고 점수·도착한 숲·도토리·소리 설정은 보존하고, 기존 11개 수료 기록을 대응하는 6개 수업으로 옮깁니다. 이전 버전에서 플레이 중이던 한 판은 보드 아이템이 포함된 새 배치로 시작하며 안내를 표시합니다.
- 저장 차단이나 손상된 기록에서도 새 게임을 플레이할 수 있습니다. 다른 브라우저나 기기로 동기화하지 않습니다.
- 게임 하단의 **이 게임을 만든 프롬프트**에서 `prompts.html`을 엽니다. 최초 제작 요청, 아이템 배치 수정, 검증·커밋, 이펙트 강화 요청을 의도는 유지하며 오타·띄어쓰기·문장 흐름을 다듬은 정리본으로 보여줍니다. 프롬프트 복사를 지원하며 권한이 없으면 텍스트를 선택해 직접 복사할 수 있습니다.

## 파일

- `index.html`, `styles.css`: 반응형 화면과 접근성 마크업
- `rules.mjs`: DOM과 독립된 생성·선택·매칭·아이템·시간·저장 검증
- `art.mjs`, `icon.svg`: 외부 의존성이 없는 벡터 그래픽
- `game.mjs`: 입력·연출·사운드·모달·저장·보상
- `prompts.html`, `prompts.css`, `prompts.js`: 제작 프롬프트 정리본과 복사
- `rules.test.mjs`, `tests/ui.test.mjs`: 규칙 및 DOM 통합 검증

## 검증

Node.js 24 이상 권장. 규칙 검증은 설치 없이 실행합니다.

```powershell
node --test games/cozy-forest/rules.test.mjs
```

DOM 통합 검증까지 실행하려면 테스트 전용 폴더에만 의존성을 설치합니다. 게임 실행에는 필요하지 않습니다.

```powershell
cd games/cozy-forest/tests
npm install
npm test
```

21개 규칙·DOM 통합 검증 통과:

- 실제 보드 아이템 효과를 포함한 1,000개 스테이지 해답과 시드 재현
- 가려진 동물·아이템, 무효 입력, 종료 후 입력, 중복 클릭 방지
- 마지막 칸 매칭 우선 처리, 포화 패배, 아이템의 바구니 비점유, 동물 수 보존
- 아이템 5종의 즉시 발동과 구조 바구니의 빈 바구니 보완 효과
- 바구니 한 칸 남은 재배치와 임의 선택 뒤 재배치 150개 사례의 해답
- 콤보·피버 진입·2배 점수 누적·시간 보호·만료
- 6개 수업의 실제 버튼 입력·아이템 발견·졸업
- 클리어 직후 새로고침 보상 보존과 중복 지급 방지
- 혼합 보드 저장·복구, 이전 버전 기록 전환, 저장 손상·차단 처리
- 피버 지속 별빛·카운트다운·누적 점수·매칭 효과·효과음 경로·노드 상한과 정리
- 모달·숨겨진 탭의 시간 정지, 동작 줄이기 설정
- 로컬 자산·프롬프트 링크·SVG 구문·프롬프트 정리본의 요청 의도 유지·복사 성공과 권한 거부 시 대체 동작

**검증 한계:** 앞선 검증에서 브라우저 도구의 로컬 URL 접근이 보안 정책으로 거부되었습니다. 이번 변경도 규칙·DOM 통합 검증을 수행했으며 실제 브라우저의 화면 배치·프레임 성능·휴대폰 실기기·Safari 사운드·진동은 확인하지 못했습니다. DOM 검증은 실제 렌더링이나 효과음 재생을 증명하지 않습니다.
