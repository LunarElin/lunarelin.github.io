# 포근포근 숲 · Cozy Forest

설치 없이 터치·클릭으로 플레이하는 HTML5 동물 트리플 매칭 퍼즐입니다. 게임별 코드·자산·저장은 이 폴더에서 독립적으로 관리합니다. 런타임 패키지 설치나 외부 이미지·폰트·API가 필요하지 않습니다.

## 실행

저장소 루트에서 Python 표준 라이브러리 서버를 실행합니다. 기존 서버가 같은 포트를 사용하면 먼저 확인하고 재사용하거나 다른 포트를 지정합니다.

```powershell
python games/cozy-forest/tests/serve.py
# 다른 포트: python games/cozy-forest/tests/serve.py --port 8766
```

- 로컬: http://127.0.0.1:8765/games/cozy-forest/
- 공개: https://lunarelin.github.io/games/cozy-forest/
- 진입 파일: `index.html`. ES 모듈을 사용하므로 파일 더블클릭 대신 HTTP로 엽니다.
- 서버는 저장소 루트를 제공하고 `.mjs`를 `text/javascript`로 응답합니다. Windows의 기본 MIME 연결에 영향을 받지 않습니다.

## 플레이와 모드

- 위에 타일이 없는 밝은 동물을 눌러 7칸 바구니에 담습니다. 같은 동물 3마리는 자동 구조됩니다. 마지막 칸의 매칭을 먼저 처리한 뒤 포화를 판정합니다.
- 금빛 아이템은 동물과 함께 보드에 등장합니다. 가려진 타일을 치운 뒤 누르면 한 번 발동하고 사라집니다. 바구니 칸은 사용하지 않습니다. **도감**에서 효과를 확인합니다. 바구니가 5칸 이상 차고 남은 구제 아이템이 모두 가려졌다면 기존 아이템 하나가 맨 위로 올라옵니다. 직접 눌러야 사용되며 개수·점수는 추가되지 않습니다. PC 도감은 우측에 열리며, 플레이 화면에는 상시 설명 패널이 없습니다.
- **수업:** 기본 매칭과 아이템 5종을 직접 쓰는 6개 수업. 해당 아이템을 실제로 사용해야 수료하며, 제한 시간이 끝나면 60초를 보충합니다.
- **무한 산책:** 동물 30~60개·4~8종·최대 3겹, 아이템 3~5개. 3스테이지마다 동물이 6마리 늘어 16단계부터 60마리, 4스테이지마다 종류가 늘어 17단계부터 8종입니다. 난도 상한 이후에도 새 배치를 계속 만듭니다. 생성한 배치에는 해답 순서가 있지만 임의 선택은 바구니 포화로 이어질 수 있습니다.
- 바구니가 가득 차거나 무한 산책의 시간이 끝나면 실패합니다. 재도전은 같은 시드, 새 배치는 새 시드입니다. 클리어하면 다음 숲과 도토리를 받습니다. 도토리는 수집 기록이며 구매 기능은 없습니다.
- 8초 안의 연속 매칭은 콤보를 올립니다. 매칭마다 피버 게이지 +25%이며 충전은 감소하지 않습니다. 4회 매칭마다 16초 피버: 점수 2배·제한 시간 정지, 매칭마다 피버 +2초(한 피버에서 합계 최대 +6초)입니다. 매칭으로 제한 시간을 추가하지 않습니다. 후반 제한 시간은 42마리를 초과하는 수색 시간을 보충하고, 60마리 스테이지에서 최저 197초를 유지합니다.

| 아이템 | 즉시 효과 |
| --- | --- |
| 당근 자석 | 바구니의 쌍부터 같은 동물 3마리 구조. 구조할 동물이 없으면 시간 +5초 |
| 살랑 바람 | 바구니의 쌍부터 맞출 수 있도록 남은 동물 재배치. 마지막 한 칸만 남고 모두 다른 동물이면 먼저 한 마리 복귀 |
| 눈꽃 시계 | 15초간 제한 시간 정지. 피버 중에는 대기 후 사용 |
| 구조 바구니 | 바구니 동물 최대 3마리를 맨 위로 복귀. 비어 있으면 시간 +5초 |
| 별사탕 | 즉시 16초 피버. 진행 중에는 +8초, 남은 시간 최대 24초 |

## 화면·연출·수명 관리

- 세로 화면은 HUD → 보드 → 바구니 → 피버 → 메뉴 순서입니다. 짧은 가로 화면에서는 보드와 조작부를 나란히 놓습니다. 홈·기록·설정·제작 프롬프트는 일시 정지 메뉴에 있습니다.
- 그래픽은 밝은 하늘색·에메랄드 숲, 동물별 선명한 색, 금빛 아이템과 분홍·보라 피버로 구성합니다. SVG 하이라이트·아랫면과 CSS 접촉 그림자로 입체감을 유지하며, 가려진 타일은 채도를 보존하고 명도로 구분합니다.
- 한글 Jua 글꼴을 로컬 WOFF2로 제공합니다. 주요 수치 28~36px, 메뉴 18~20px, 본문 16px, 보조 안내 14px입니다. 타일·버튼에는 두께·밝은 면·접촉 그림자와 눌림 반응을 적용했습니다.
- 터치 링·착지·매칭 충격파·큰 점수 팝업·HUD 반동을 표시합니다. 일반/피버/큰 폭발의 파티클은 각각 24/40/60개이며, 이동 타일·별빛을 포함한 임시 노드 상한은 112개입니다.
- 피버는 큰 진입 문구·광선·별빛·보드 섬광·강한 매칭 반응을 표시합니다. 누적 점수와 소수점 카운트다운은 바구니 아래에 표시해 보드를 가리지 않습니다. 동작 줄이기 설정에서는 움직임·진동을 줄이며 상태와 점수는 유지합니다.
- Kenney 효과음은 사용자 입력 뒤 재사용하는 오디오 2개로 재생합니다. Ogg 미지원 브라우저는 Web Audio 합성음을 사용합니다. 합성음 노드는 종료 시 연결을 해제합니다.
- 모달에서는 시간·지속 연출과 효과음을 멈춥니다. 숨겨진 탭과 페이지 이탈 시 타이머·예약 효과·애니메이션 프레임·오디오를 정리합니다. 탭 복귀와 BFCache 복원은 일시 정지에서 시작하며, 계속을 눌러야 진행합니다.
- 마우스와 터치는 같은 클릭 경로입니다. Tab·방향키로 타일 이동, Enter 선택, Esc 일시 정지도 지원합니다.

## 저장·호환

`localStorage` 키는 **`cozy-forest:v1`**, 활성 판의 형식은 **version 2**를 유지합니다. 프로필과 활성 판을 동작 시·플레이 중 5초마다·페이지 이탈 시 저장합니다. 미완료 무한 산책의 점수도 최고 기록에 반영하며, 클리어 보상은 결과 연출 전에 한 번만 기록합니다.

기존 최고 점수·도착한 숲·도토리·소리·진동 설정을 보존합니다. 과거 11개 수료 기록은 대응하는 6개 수업으로 옮기고, version 1의 진행 판은 새 배치로 시작합니다. 새 피버 연장량 필드는 기존 저장에 없으면 0으로 취급합니다. 기존 판의 보드·잔여 시간은 유지하고 복구 시에도 위기 아이템 노출을 검사합니다. 손상된 활성 판은 총수·좌표·아이템 사용·해답 ID 등을 검증해 제외하되 유효한 프로필은 보존합니다. 저장 차단 시에도 기본 플레이가 가능합니다. 기기 간 동기화는 지원하지 않습니다.

## 파일·출처

- `rules.mjs`: 생성·선택·매칭·아이템·시간·저장 검증. `game.mjs`: 입력·화면·연출·메뉴·저장 연결.
- `art.mjs`, `icon.svg`: 직접 제작한 동물·배경·아이콘 SVG. `styles.css`: 화면과 애니메이션.
- `assets/`: 실제 사용하는 Kenney UI·효과음과 Jua 글꼴. 팩·원본 파일·라이선스·가공 내역은 [자산 안내](assets/README.md)를 참조합니다.
- `prompts.html`·`prompts.css`·`prompts.js`: 기존 제작 요청의 의도를 보존한 교정본과 복사 기능. 메뉴의 제작 프롬프트에서 엽니다.
- [화면 구조 검토](REVIEW.md), [후반 밸런스 검토](BALANCE.md), [선명한 그래픽 개편·현재 자체 평가](GRAPHICS.md): 검증 근거와 한계.

## 검증

Node.js 24 이상을 권장합니다. 규칙 검증은 설치 없이 실행합니다.

```powershell
node --check games/cozy-forest/game.mjs
node --check games/cozy-forest/rules.mjs
node --check games/cozy-forest/art.mjs
node --test games/cozy-forest/rules.test.mjs
```

DOM 통합 검증은 `tests/package.json`에 지정된 테스트 의존성만 해당 폴더에 설치합니다. 게임 실행에는 필요하지 않습니다.

```powershell
cd games/cozy-forest/tests
npm install
npm test
```

규칙 17개·DOM 15개, 총 32개 검증이 있습니다. 생성 배치 1,000개, 재배치 150개, 아이템 5종, 수업 6개, 피버·보상·저장 손상·구버전 이관·탭 복귀·이펙트 상한·프롬프트 복사를 포함합니다. 브라우저 화면 검증은 자동 테스트와 별도로 수행합니다. 이번에는 데스크톱 브라우저의 모바일 크기 에뮬레이션까지 확인했으며, 실제 iOS Safari·Android Chrome 기기와 저사양 기기의 프레임·발열·진동은 미검증입니다.

후반 재현 도구는 로컬 서버의 `/games/cozy-forest/tests/playtest.html`입니다. 스테이지·시드를 지정해 실제 게임을 열며, 해당 로컬 주소의 저장만 교체합니다. 공개 사이트에서는 비활성화됩니다. 진단용 자동 정책은 가려진 동물·해답을 읽지 않고 열린 타일과 바구니만 선택합니다.

```powershell
node games/cozy-forest/tests/balance.mjs
```

10·20·50단계, 입력 간격 2.5·4초, 시드 1~100을 비교합니다. 사람의 승률·재미·실제 기기 성능을 측정하는 도구는 아닙니다. 상세 수치와 수동 재현 결과는 `BALANCE.md`를 참조하세요.
