# 포근포근 숲 · Cozy Forest

모바일과 PC에서 터치·클릭으로 플레이하는 정적 HTML5 동물 트리플 매칭 퍼즐입니다. 기존 작은 머지와 독립된 게임이며, 홈페이지 게임 영역에 진입 버튼을 추가했습니다. 런타임에 패키지 설치, 외부 이미지, 외부 폰트, 서버 API가 필요하지 않습니다.

## 실행

저장소 루트에서 실행합니다.

```powershell
python -m http.server 8765
```

접속: `http://localhost:8765/games/cozy-forest/`

GitHub Pages 배포 시 경로: `https://lunarelin.github.io/games/cozy-forest/`

별도 빌드 없이 저장소 루트와 함께 GitHub Pages에 배포할 수 있습니다. ES 모듈을 사용하므로 HTML 파일을 더블클릭하는 대신 HTTP로 열어야 합니다.

## 장르 선택 근거

조사일: 2026-10-17. 오늘의 미국 iOS 하이브리드 캐주얼 매출 1위를 확정할 수 있는 공개 실시간 자료는 확보하지 못했습니다. 따라서 현재 1위라고 단정하지 않습니다.

공개된 [Sensor Tower의 미국 iOS 2025년 4분기 하이브리드 캐주얼 매출 분석](https://sensortower.com/blog/2025-q4-ios-top-5-hybridcasual-games-revenue-us-642f199ae1714cfff12984cb)에서 Match Factory!의 주간 매출은 연말 약 245만 달러로, 제시된 5개 게임 중 가장 높습니다. [미국 App Store의 공식 게임 설명](https://apps.apple.com/us/app/match-factory/id6449094229)은 같은 오브젝트를 세 개 모으는 트리플 매칭, 제한 시간, 부스터를 핵심으로 소개합니다. 이 구조를 참고해 동물 일러스트와 겹친 타일 보드로 재구성했습니다. 원작의 3D 물리 구현이나 자산을 복제하지 않습니다.

## 규칙과 모드

- 위에 겹치는 타일이 없는 밝은 동물을 선택하면 바구니에 들어갑니다. 같은 동물 3마리는 자동으로 제거됩니다.
- 기본 바구니는 7칸입니다. 세 번째 동물의 매칭을 먼저 처리하고, 이후 바구니가 가득 찼는지 판정합니다.
- 모든 동물을 구조하면 스테이지 성공, 제한 시간 종료 또는 바구니 포화 시 재도전합니다. 목숨이나 재도전 횟수 제한은 없습니다.
- **끝없는 산책:** 매번 생성되는 스테이지. 30~60개 타일, 최대 3겹, 동물 4~8종으로 점진적으로 난도가 올라갑니다. 충분히 진행한 뒤에는 상한 난도에서 새로운 배치를 계속 만듭니다.
- 생성기가 실제로 선택 가능한 타일 제거 순서를 먼저 구하고, 그 순서에 동물을 세 마리씩 배정합니다. 최초 배치는 아이템 없이도 풀 수 있습니다. 플레이 중의 잘못된 선택까지 승리를 보장하지는 않습니다.
- **숲속 학교:** 기본 규칙 1개 + 아이템 10종 실습 = 총 11개 수업. 해당 아이템을 실제로 사용해야 수료할 수 있습니다. 아이템은 수업에서 무제한 무료이며 수업 순서는 자유롭게 선택할 수 있습니다. 튜토리얼은 시간 초과 시 시간을 보충합니다.
- 매칭 기본 점수 300점. 6초 안에 이어서 매칭하면 콤보가 올라가며 회당 최대 300점이 추가됩니다.
- 빠르게 매칭 4번으로 게이지 100%를 채우면 **12초 피버**: 점수 2배, 제한 시간 정지, 피버 중 매칭당 제한 시간 +2초. 6초 넘게 매칭하지 않으면 게이지가 서서히 줄어듭니다.
- 스테이지 완료 시 도토리 30~60개와 순환 아이템 1개를 받습니다. 첫 수업 수료 시 도토리 10개를 받습니다. 최초 도토리 150개, 각 아이템 3개를 제공합니다. 실제 결제는 없습니다.

## 조작·연출·저장

- 단일 `click` 입력 경로로 터치와 마우스의 중복 처리를 방지합니다. 키보드 Tab·방향키로 이동, Enter로 선택, Esc로 일시 정지할 수 있습니다.
- SVG 동물 8종, 숲 배경, 아이템 아이콘을 직접 그렸습니다. 카드 이동·바구니 착지·색종이 파티클·점수 팝업·화면 흔들림·피버 플래시를 제공합니다.
- Web Audio 효과음은 첫 동물 선택 같은 사용자 동작에서 생성됩니다. 소리 버튼과 일시 정지 설정에서 끌 수 있습니다. 진동은 지원 기기에서만 동작합니다.
- `prefers-reduced-motion`에서는 큰 애니메이션과 진동을 줄입니다. 타일에 동물 이름을 제공하고 가려진 타일은 입력에서 제외합니다.
- 화면 폭에 따라 3열 데스크톱, 2열 태블릿, 세로 모바일 레이아웃으로 바뀝니다. 모바일 가방 버튼은 아이템 영역으로 이동합니다.
- 도움말·아이템·수업 목록·일시 정지 창과 숨겨진 탭에서는 시간이 흐르지 않습니다.
- `localStorage` 키 `cozy-forest:v1`에 보드·바구니·남은 시간·점수·가방·도토리·수료 기록을 저장합니다. 동작 시, 플레이 중 5초마다, 페이지를 떠날 때 저장합니다. 다시 열면 이어서 플레이합니다. 목표 선택 같은 일시적인 UI 상태는 복구하지 않습니다.
- 저장 차단이나 손상된 기록에서도 새 게임을 플레이할 수 있습니다. 다른 기기나 다른 브라우저로 기록이 동기화되지는 않습니다.

## 파일

- `index.html`, `styles.css`: 반응형 화면과 접근성 마크업
- `rules.mjs`: DOM과 독립된 생성·선택·매칭·아이템·시간·저장 검증
- `art.mjs`, `icon.svg`: 외부 의존성이 없는 벡터 그래픽
- `game.mjs`: 입력·연출·사운드·모달·저장·보상
- `rules.test.mjs`, `tests/ui.test.mjs`: 규칙 및 DOM 통합 검증

## 검증

Node.js 22 이상 권장. 규칙 검증은 설치 없이 실행합니다.

```powershell
node --test games/cozy-forest/rules.test.mjs
```

DOM 통합 검증까지 실행하려면 테스트 전용 폴더에만 의존성을 설치합니다. 게임 실행에는 필요하지 않습니다.

```powershell
cd games/cozy-forest/tests
npm install
npm test
```

18개 검증 통과:

- 1,000개 단계의 초기 배치 해답, 시드 재현, 가려진 타일·무효 입력·종료 후 입력
- 마지막 칸 매칭 우선 처리와 포화 패배, 동물 수와 종류 보존
- 아이템 10종, 무효 사용 미차감, 바구니 상한
- 콤보·피버 진입·2배 점수·동결·시간 만료
- 임의 선택 뒤 재배치 150개 사례의 해답
- 바구니 한 칸만 남았을 때 기존 쌍 우선 재배치, 모두 다른 동물일 때 소모 없이 구조 아이템 안내
- 11개 수업의 실제 버튼 입력·아이템 실습·졸업과 수료 조건
- 아이템 구매, 스테이지 보상 1회 지급, 다음 단계 해금
- 새로고침 복구, 저장 손상·차단, 숨겨진 탭과 모달 시간 정지
- HTML 로컬 자산 연결, 홈페이지의 두 게임 링크, SVG 구문

**검증 한계:** 브라우저 도구의 로컬 URL 접근이 보안 정책으로 거부되어 실제 브라우저 렌더링·화면 캡처·휴대폰 실기기 터치·Safari 효과음·진동은 확인하지 못했습니다. DOM 검증은 화면 배치나 실제 사운드 재생을 증명하지 않습니다. 사람의 난도·재미·리텐션 플레이테스트도 미수행입니다.
