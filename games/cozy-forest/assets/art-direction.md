# 선명한 장난감 숲 · 2026-10-28

적용 스킬: `router` → `create-game-assets` + `game-ui-ux`. 기존의 HTML5 DOM·SVG·CSS 렌더링을 유지합니다. 색감 선택은 사용자에게 위임받은 PD 판단으로 정하고, 실제 게임 크기에서 확인합니다.

## 시각 기준

- 2D 정면 동물 얼굴, 둥근 실루엣과 깨끗한 벡터 경계. 귀·무늬·입 모양으로 색 없이도 종을 구분합니다.
- 왼쪽 위 광원, 밝은 윗면·색 있는 아랫면·접촉 그림자로 장난감 같은 두께를 표현합니다. 동물의 원래 비율과 타일 위치·입력 영역은 유지합니다.
- 배경은 하늘색 `#64d7ff`, 에메랄드 `#25c987`, 연두 `#8de65e`. 꽃·구름은 보드 가장자리에 두고 중앙 타일의 정보 밀도를 높이지 않습니다.
- 동물은 분홍·주황·카라멜·보라·초록·노랑·흰색/남색·꿀색으로 묶고, 흰빛 하이라이트와 진한 남색 얼굴선을 공유합니다.
- 동물 타일은 흰 윗면과 동물별 옅은 색, 아이템은 금빛으로 구분합니다. 가려진 타일도 채도를 유지하고 밝기·겹침·입력 비활성 상태로 구분합니다.
- HUD는 밝은 청록/흰 표면과 진한 글씨, 주요 확인은 파랑, 보조 행동은 노랑, 위험은 산호색을 사용합니다. 색상 외에도 문구·아이콘·외곽선을 유지합니다.
- 피버는 분홍·보라 프레임과 노란 광선·점수. 평상시의 초록 숲과 구분하면서 타일의 얼굴은 계속 읽혀야 합니다.

## 기술·통합 기준

- 동물 SVG: 96×96 viewBox, 아이콘: 36×36, 배경: 900×760, favicon: 96×96. 모두 해상도 독립 벡터이며 새 래스터 파일은 만들지 않습니다.
- `rules.mjs`의 동물·아이템 색 메타데이터 → `art.mjs`의 SVG 및 `game.mjs` 타일 CSS 변수 → `styles.css`의 재질·HUD로 연결합니다. 규칙·배치·점수·저장 스키마는 변경하지 않습니다.
- Kenney 원본 PNG·효과음과 Jua 글꼴을 재사용합니다. PNG 파일은 수정하지 않고 버튼 표시의 CSS 채도·밝기만 조정합니다.
- 기존 효과 노드 상한 112개·애니메이션 수명·동작 줄이기 설정을 유지합니다. 배경에 새 반복 애니메이션·외부 요청·큰 텍스처를 추가하지 않습니다.
- 모바일 320~390px 세로, PC, 짧은 가로 화면에서 원래 글씨 크기·44px 이상 입력 영역·안전 영역·모달 조작을 확인합니다. 일반/가려짐/위기/피버/도감/일시 정지를 함께 확인합니다.

자산 목록은 `art-manifest.json`, 라이선스는 `README.md`와 각 라이선스 파일에 있습니다. 실제 화면·검증 결과와 자체 평가는 게임 폴더의 `GRAPHICS.md`에 기록합니다.

## 채택한 시각 목표

390×844 화면의 20단계(시드 20261021)에서 새 팔레트를 검토하고 채택했습니다. 일반 보드·피버·도감과 320px 화면을 함께 확인했습니다. 결과 이미지는 별도 검증 산출물로 보관하고 배포 파일에는 추가하지 않습니다.
