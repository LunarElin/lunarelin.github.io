# 후반 플레이·아이템·피버 밸런스 검토

2026-10-21. 실제 게임 버튼으로 후반을 플레이하고, 일정한 입력 간격의 진단을 별도로 비교했습니다. 자동 정책과 데스크톱 브라우저 관찰을 사람의 재미·실기기 검증과 구분합니다.

## 직접 플레이에서 확인한 문제

- 기존 20단계, 시드 `20261021`: 60마리 구조로 클리어. 빠른 매칭에서는 피버 보호와 제한 시간 추가가 겹쳐 시간 압박이 거의 사라졌습니다.
- 기존 50단계, 시드 `20261022`: 39/60 구조 후 바구니 포화. 사용하지 않은 당근 자석이 가려져 구제할 수 없었습니다.
- 소스·규칙 검토에서는 자석이 쌍 대신 마지막 한 마리를 우선하는 경우, 피버와 눈꽃이 동시에 소모되어 보호 시간이 겹치는 경우를 재현했습니다.
- 기존 생성은 11단계에 60마리, 13단계에 8종에 도달한 뒤 시간만 계속 줄어들었습니다. 4초마다 선택하는 진단에서는 10·20·50단계 모두 시간 초과가 지배적이었습니다.

노출은 아이템을 새로 지급하거나 자동 사용하지 않습니다. 점수·구조 수·동물 수를 바꾸지 않고 기존 타일의 높이와 해답 순서만 조정합니다. 모두 사용했다면 추가 구제는 없습니다. 아이템 선택과 포화 실패는 유지합니다.

도감·도움말·피버 팝업을 실제 규칙에 맞췄습니다. 위기 타일의 강조, 구조 신호, 눈꽃 대기, 피버 연장을 표시합니다. 문구 확인 중 바구니 아래 안내와 피버 영역의 겹침도 발견해 높이를 조정했습니다. 새 한글을 포함하도록 Jua 부분 추출본을 갱신했습니다.

저장 키·version 2는 유지합니다. 새 `feverExtension`은 과거 저장에 없으면 0으로 취급합니다. 기존 진행 보드와 잔여 시간·기록·아이템 사용은 유지하며, 복구 시에도 위기 노출을 검사합니다.

50단계의 최종 플레이는 노출 직전까지 기존과 같은 열린 타일 우선 선택을 사용했습니다. 화면·저장 복구 검토를 위해 중간에 일시 정지·새로고침했고, 이후 남은 21마리를 구조했습니다. 에이전트의 조작·화면 검토 시간은 일정하지 않으므로 수동 플레이의 잔여 시간과 점수를 전후 속도 비교에 사용하지 않았습니다. 숨겨진 해답이나 가려진 동물 종류를 선택 판단에 사용하지 않았습니다.

## 반복 가능한 자동 진단

`node games/cozy-forest/tests/balance.mjs`로 재현합니다. 각 조건의 시드는 1~100, 100판입니다. 선택 정책은 열린 동물과 바구니의 짝, 위기 구제, 45초 이하의 눈꽃, 피버 6초 이하의 별사탕을 우선합니다. 해답·가려진 종류·다음 상태를 읽지 않습니다. 각 선택 전에 지정한 시간이 실제 규칙의 `tick`으로 흐릅니다.

전후 같은 정책을 사용했습니다. 아래는 **자동 정책의 클리어 수**이며 사람의 승률이 아닙니다. 10단계는 성장 곡선 변경으로 마릿수·종류가 달라졌습니다. 20·50단계는 같은 시드의 60마리·8종 보드를 사용합니다. 정책의 아이템 사용 시점은 남은 시간·피버에 따라 달라지므로, 입력 간격이 길다고 클리어 수가 반드시 감소하지는 않습니다.

| 단계 | 선택 간격 | 기존 클리어 | 변경 후 클리어 | 기존 → 변경 후 시간 초과 | 피버 중 매칭 비중 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 10 | 2.5초 | 78/100 | 84/100 | 0 → 0 | 17% → 34% |
| 10 | 4초 | 0/100 | 88/100 | 94 → 0 | 4% → 20% |
| 20 | 2.5초 | 53/100 | 64/100 | 0 → 0 | 16% → 34% |
| 20 | 4초 | 0/100 | 78/100 | 91 → 0 | 3% → 19% |
| 50 | 2.5초 | 54/100 | 64/100 | 0 → 0 | 16% → 34% |
| 50 | 4초 | 0/100 | 79/100 | 97 → 0 | 2% → 20% |

변경 후에도 후반 자동 정책의 21~36판은 바구니 포화로 실패합니다. 시간만으로 패배하는 비중을 낮추고 아이템과 짝 선택의 비중을 높였습니다.

- 규칙 17개·DOM 15개, **총 32개 통과**. 생성 1,000판 해답, 재배치 150판에 더해 느린 매칭 충전, 연장 상한·별사탕 중첩, 눈꽃 소수점 경계, 자석 쌍 우선, 노출 시 동물·아이템 보존, 기존 6칸 저장 복구와 HUD·멈춤·저장을 검증했습니다.
- 320×568·390×844·1440×900·640×360 브라우저 렌더링 확인. 최소 타일 폭은 각각 45·58·75·54px, 메뉴 높이는 48px입니다. 새 안내 문구는 가로 넘침이 없고 피버 영역과 3.6px 이상 떨어집니다. 폰트 로딩과 새 한글 포함을 확인했습니다.
- 실제 iOS Safari·Android Chrome, 주소창·노치·진동·오디오 재개, 저사양 기기 프레임·발열은 미검증입니다. 사람 대상 후반 플레이 데이터도 없습니다.
