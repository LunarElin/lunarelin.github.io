# 2026-10-28 그래픽 업데이트

요청: 탁한 색감을 선명한 모바일 게임 색감으로 변경. 적용 스킬은 `router`, `create-game-assets`, `game-ui-ux`입니다. 기존 HTML5·SVG·CSS 구조를 유지하고 기존 원본을 직접 수정했습니다.

## 변경

- 올리브·베이지 위주 배경을 하늘색·에메랄드·연두 숲과 밝은 모래 길로 변경했습니다. 구름·꽃은 가장자리에 배치해 중앙의 동물 타일과 경쟁하지 않게 했습니다.
- 동물 8종을 분홍·주황·카라멜·보라·초록·노랑·흰색/남색·꿀색으로 정리했습니다. 얼굴의 흰 하이라이트·아랫면 음영·눈 반짝임을 보강하고 기존 귀·무늬·비율을 유지했습니다.
- 흰 동물 타일에 종별 옅은 색과 선명한 아랫면을 적용했습니다. 가려진 타일은 과도한 탈색을 줄이고 밝기·깊이·입력 비활성 상태로 구분합니다. 아이템은 금빛 표면과 색 있는 아이콘으로 유지합니다.
- HUD·메뉴·모달을 청록/흰색 표면과 진한 글씨로 통일했습니다. 하단 도감·수업·도움말은 파랑·초록·노랑, 확인 행동은 파랑으로 구분합니다. 글씨 크기·배치·터치 영역은 유지했습니다.
- 피버는 분홍·보라 프레임, 노란 광선과 점수, 선명한 파편 색으로 변경했습니다. 효과 개수·수명·노드 상한 112개·동작 줄이기는 유지합니다.
- 기존 Kenney PNG는 그대로 사용하고 상단 버튼의 CSS 채도·밝기를 조정했습니다. 새 래스터 이미지·폰트·런타임 의존성은 추가하지 않았습니다.
- HTML·모듈·스타일·favicon의 버전을 `20261028-colors`로 맞춰 이전 색상과 새 색상이 캐시로 섞이지 않게 했습니다.

아트 방향과 기술 프레임은 [아트 기준](assets/art-direction.md), 자산별 크기·상태·출처는 [목록](assets/art-manifest.json), 기존 무료 자산 라이선스는 [자산 안내](assets/README.md)를 참조합니다.

## 검증 근거

- 기존 규칙·DOM 통합 테스트 **32개 통과**. 생성 1,000판 해답·재배치 150판·아이템·피버·저장·구버전 호환·탭 복귀·효과 정리 등을 포함합니다. 변경한 JS/MJS 구문과 SVG 구문을 검사했습니다.
- 동일한 10·20·50단계/시드 1~100/2.5·4초 입력 진단의 결과가 그래픽 수정 전후 완전히 같았습니다. 동물·아이템의 색 메타데이터만 변경했고 생성·점수·시간·난도·저장 규칙을 바꾸지 않았습니다. 진단 수치를 사람의 승률로 해석하지 않습니다.
- 브라우저에서 20단계(시드 20261021)를 직접 플레이해 **60/60 구조·20,940점**으로 완료했습니다. 판단에는 열린 타일과 바구니만 사용했습니다. 별사탕 → 토끼 3마리 입력에서 피버·600점 가산·누적 점수·광선·파편을 확인했습니다.
- 일반/가려진 타일·피버·일시 정지·도감·클리어 화면을 실제 렌더링에서 확인했습니다. 브라우저 경고·오류 로그는 관찰되지 않았습니다.
