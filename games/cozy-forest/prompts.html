01 / INITIAL REQUEST

처음 제작 요청

1. 게임 추가: 기존 게임인 ‘작은 머지(3 Merge)’와 별도로 신규 게임을 하나 추가해 주세요.
2. 플랫폼과 테마: HTML5 기반으로 모바일에서도 플레이할 수 있는 귀여운 동물 테마의 퍼즐 게임을 제작해 주세요.
3. 핵심 규칙: 현재 미국 App Store의 하이브리드 캐주얼 게임 중 매출이 가장 높은 게임을 조사하고, 해당 게임의 핵심 플레이 방식을 참고해 주세요. 카지노나 포커 등의 장르도 가능합니다.
4. 아이템과 스테이지: 아이템을 약 10종 구현하고, 각 아이템의 사용법을 배우는 튜토리얼 모드와 반복해서 도전할 수 있는 무한 스테이지를 구성해 주세요.
5. 액션 연출: 플레이어의 행동에 손맛과 타격감이 느껴지도록 연출하고, 피버 모드를 추가해 주세요.
6. 작업 진행: 세부 기획과 구현 방식은 PD의 판단에 맡깁니다. 추가 확인 질문 없이 게임이 완성될 때까지 작업을 진행해 주세요.

02 / BOARD ITEMS

아이템 배치와 프롬프트 공개

1. 아이템 설명은 화면 우측에 배치해 주세요. 아이템은 별도의 가방에서 사용하는 대신 동물 타일과 함께 게임 보드에 등장하도록 구현해 주세요.
2. 아이템 10종을 모두 구현하기 어렵다면, 재미를 높일 수 있는 종류를 선별해 주세요. 최종 개수는 구현 난이도와 재미를 고려해 결정해 주세요.
3. 게임 제작에 사용한 프롬프트를 확인할 수 있는 별도 페이지를 추가해 주세요.

03 / TEST & COMMIT

검증과 커밋 요청

직접 테스트해 기능상의 문제를 확인하고, 문제가 없으면 변경 사항을 Git에 커밋해 주세요.

04 / MORE JUICE

이펙트와 피버 강화

1. 플레이어의 행동에 대한 반응이 확실히 느껴지도록 액션 이펙트의 규모와 강도를 높여 주세요.
2. 피버 모드의 연출을 더 크고 화려하게 표현해 주세요.
3. 피버 진행 중에도 점수 상승과 피버 상태를 분명하게 느낄 수 있도록 점수 연출과 지속 이펙트를 강화해 주세요.
